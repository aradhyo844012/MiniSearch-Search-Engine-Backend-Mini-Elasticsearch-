Bash Scripting Glossary for Beginners

New words can make Bash Scripting feel harder than it is. This glossary keeps the key ones in one place.

Bash Scripting: writing shell scripts that automate tasks by chaining commands, variables and control flow.
variables: a core term, most visible in automating deployments.
conditionals and loops: a core term that beginners often confuse with exit codes.
exit codes: a core term that connects to functions.
functions: a core term worth revisiting after you try a real example.
Bash: a tool commonly used for processing text files.

Come back to this Bash Scripting list whenever documentation for ShellCheck uses a word you do not recognize.
