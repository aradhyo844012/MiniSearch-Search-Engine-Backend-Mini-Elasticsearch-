A Mini Project Idea Using Database Backups and Recovery

A small project is the fastest way to make Database Backups and Recovery stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Database Backups and Recovery at work on recovering deleted tables. Keep the scope small enough to finish.

Milestones:
1. Read about full and incremental backups and recovery point objective.
2. Set up pg_dump and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as never testing restores.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover migrating servers, or compare mysqldump with AWS Backup.

Finish by recording what surprised you. Writing it down is how knowledge about Database Backups and Recovery turns into something you can show others.
