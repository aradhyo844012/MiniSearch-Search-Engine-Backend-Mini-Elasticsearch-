Font Rendering Glossary for Beginners

New words can make Font Rendering feel harder than it is. This glossary keeps the key ones in one place.

Font Rendering: turning font outlines into readable text on screen.
glyphs: a core term, most visible in web pages.
hinting: a core term that beginners often confuse with anti-aliasing.
anti-aliasing: a core term that connects to kerning.
kerning: a core term worth revisiting after you try a real example.
FreeType: a tool commonly used for operating systems.

Come back to this Font Rendering list whenever documentation for Google Fonts uses a word you do not recognize.
