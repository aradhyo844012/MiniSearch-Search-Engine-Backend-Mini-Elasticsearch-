API Gateways Tips from Experienced Engineers

Engineers who work with API Gateways regularly tend to repeat the same advice. Here it is.

1. When something behaves strangely, revisit authentication before anything else.
2. Make sure you can keep the gateway thin and put business logic in services.
3. Be careful with this one: a single point of failure.
4. Reach for Kong first, and only then evaluate alternatives such as AWS API Gateway.
5. Write down why you chose API Gateways so the next person understands the decision.

None of these tips needs special equipment, and all of them apply to securing public APIs as well as to API Gateways in general.
