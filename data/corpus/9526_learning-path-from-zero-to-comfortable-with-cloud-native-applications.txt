Learning Path: From Zero to Comfortable with Cloud-Native Applications

This path is for a learner who has never studied Cloud-Native Applications before. Move at your own speed.

Stage 1, the basics: read a short definition (Cloud-Native Applications is applications designed from the start to run in the cloud using containers and managed services) and learn containers and microservices.

Stage 2, hands-on: install Kubernetes, follow a tutorial, and build a small example involving web platforms.

Stage 3, depth: study declarative configuration and elastic scaling, then deliberately explore this problem: treating the cloud like a data center.

Stage 4, application: apply Cloud-Native Applications to data-heavy services, compare Docker with Helm, and write up your results.

Stage 5, review: teach Cloud-Native Applications to someone else, and then move on to Twelve-Factor Apps.
