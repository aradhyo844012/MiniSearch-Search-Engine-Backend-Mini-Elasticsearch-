A Practical Checklist for Type Systems

Use this checklist before you rely on Type Systems in a project.

1. Review the core ideas: static and dynamic typing, type inference, generics, and type annotations.
2. Guard against this risk: fighting the type checker.
3. Ask a teammate to review the work, focusing on type inference.
4. Guard against this risk: treating annotations as guarantees at runtime.
5. Write at least one automated test that covers static and dynamic typing.
6. Confirm that your team agrees on what Type Systems should accomplish.
7. Document your decisions in the project README.
8. Guard against this risk: overusing any types.
