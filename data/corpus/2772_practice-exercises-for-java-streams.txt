Practice Exercises for Java Streams

These exercises build real understanding of Java Streams. Do them in order, and write down your answers.

Exercise 1: List three situations from your own experience that resemble transforming lists or aggregating records.
Exercise 2: Pick OpenJDK and complete its getting-started tutorial.
Exercise 3: Explain how reduce and lazy evaluation differ, using a drawing.
Exercise 4: Compare IntelliJ IDEA and JUnit for processing data in parallel and write down your conclusion.
Exercise 5: Write a short paragraph describing Java Streams and include the term map.

When you finish, compare your answers with the definition: Java Streams is a way of processing collections with chains of declarative operations.
