Practice Exercises for API Design Principles

These exercises build real understanding of API Design Principles. Do them in order, and write down your answers.

Exercise 1: List three situations from your own experience that resemble public platforms or internal service contracts.
Exercise 2: Pick OpenAPI and complete its getting-started tutorial.
Exercise 3: Compare Postman and Stoplight for mobile backends and write down your conclusion.
Exercise 4: Create a small example that deliberately triggers this problem: leaking internal details. Then fix it.
Exercise 5: Explain how idempotent operations and documentation differ, using a drawing.

When you finish, compare your answers with the definition: API Design Principles is guidelines for making APIs consistent, predictable and easy to use.
