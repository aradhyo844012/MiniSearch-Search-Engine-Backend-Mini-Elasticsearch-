Questions to Ask About Dependency Vulnerabilities in Code Review

Reviewing code that involves Dependency Vulnerabilities is easier with a short list of questions. Keep these in mind as you read the diff.

- Does this change respect CVE identifiers, or does it work around it?
- Could we automate update pull requests?
- Have we considered ignoring transitive dependencies?
- Would a test catch never updating if it appeared later?
- Does the code handle the case of auditing projects correctly?
- Is Dependabot used consistently, or are we mixing approaches?

Good reviews of work on Dependency Vulnerabilities are specific, kind and focused on transitive dependencies, not on personal style.
