Combining Code Editors and IDEs with Reading Documentation in One Project

Real projects rarely use one idea in isolation. This article shows how Code Editors and IDEs and Reading Documentation can work together in a single project.

Code Editors and IDEs is tools for writing, navigating and debugging code. Reading Documentation is the skill of finding accurate answers in official guides and references.

Imagine a project that involves daily development and learning new libraries. Code Editors and IDEs brings syntax highlighting, while Reading Documentation brings search.

A sensible plan is to start with VS Code for the Code Editors and IDEs part and MDN Web Docs for the Reading Documentation part, and to keep the two sides connected through a small, well-tested interface.

Be prepared for combined risks: ignoring keyboard shortcuts on one side, and skipping the overview on the other.

Picture the whole as a well-organized workbench, working alongside reading the manual before assembling the furniture.

Two habits help: first, learn the shortcuts for the actions you repeat most; second, check that the documentation version matches your installed version.
