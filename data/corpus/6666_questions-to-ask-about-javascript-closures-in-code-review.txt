Questions to Ask About JavaScript Closures in Code Review

Reviewing code that involves JavaScript Closures is easier with a short list of questions. Keep these in mind as you read the diff.

- Have we considered loop variables captured by mistake?
- Is Chrome DevTools used consistently, or are we mixing approaches?
- Would a test catch memory leaks from long-lived closures if it appeared later?
- Is captured variables clear to someone reading the code for the first time?
- Does this change respect lexical scope, or does it work around it?
- Could we use let instead of var inside loops?

Good reviews of work on JavaScript Closures are specific, kind and focused on function factories, not on personal style.
