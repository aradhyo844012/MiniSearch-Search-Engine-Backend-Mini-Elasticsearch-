A Mini Project Idea Using LSM Trees

A small project is the fastest way to make LSM Trees stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows LSM Trees at work on write-heavy databases. Keep the scope small enough to finish.

Milestones:
1. Read about memtable and sorted string tables.
2. Set up RocksDB and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as read amplification.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover time-ordered data, or compare LevelDB with Apache Cassandra.

Finish by recording what surprised you. Writing it down is how knowledge about LSM Trees turns into something you can show others.
