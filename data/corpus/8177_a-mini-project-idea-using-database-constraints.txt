A Mini Project Idea Using Database Constraints

A small project is the fastest way to make Database Constraints stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Database Constraints at work on preventing bad data. Keep the scope small enough to finish.

Milestones:
1. Read about primary keys and foreign keys.
2. Set up PostgreSQL and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as skipping constraints for speed.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover protecting relationships, or compare SQLite with ER diagram tools.

Finish by recording what surprised you. Writing it down is how knowledge about Database Constraints turns into something you can show others.
