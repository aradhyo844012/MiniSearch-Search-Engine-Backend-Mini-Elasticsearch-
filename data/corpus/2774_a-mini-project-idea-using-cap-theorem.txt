A Mini Project Idea Using CAP Theorem

A small project is the fastest way to make CAP Theorem stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows CAP Theorem at work on choosing database types. Keep the scope small enough to finish.

Milestones:
1. Read about consistency and availability.
2. Set up Apache Cassandra and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as treating it as a three-way menu.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover designing multi-region services, or compare etcd with ZooKeeper.

Finish by recording what surprised you. Writing it down is how knowledge about CAP Theorem turns into something you can show others.
