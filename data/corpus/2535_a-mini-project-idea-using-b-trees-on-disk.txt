A Mini Project Idea Using B-Trees on Disk

A small project is the fastest way to make B-Trees on Disk stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows B-Trees on Disk at work on database indexes. Keep the scope small enough to finish.

Milestones:
1. Read about pages and branching factor.
2. Set up PostgreSQL and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as random writes on fragmented pages.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover file system directories, or compare SQLite with MySQL InnoDB.

Finish by recording what surprised you. Writing it down is how knowledge about B-Trees on Disk turns into something you can show others.
