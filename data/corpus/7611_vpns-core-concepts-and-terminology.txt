VPNs: Core Concepts and Terminology

This page defines the vocabulary you need to read about VPNs with confidence. The subject itself is encrypted tunnels that connect devices or networks across the public internet.

tunneling: one of the building blocks of VPNs. You should be able to explain it in a single sentence before moving on.
encryption: one of the building blocks of VPNs. Mixing it up with neighboring terms is a common source of confusion.
authentication: one of the building blocks of VPNs. Documentation for WireGuard usually mentions it early.
split tunneling: one of the building blocks of VPNs. You should be able to explain it in a single sentence before moving on.
