Form Validation: Core Concepts and Terminology

This page defines the vocabulary you need to read about Form Validation with confidence. The subject itself is checking user input for correctness before it is accepted.

client-side checks: one of the building blocks of Form Validation. You should be able to explain it in a single sentence before moving on.
server-side checks: one of the building blocks of Form Validation. Mixing it up with neighboring terms is a common source of confusion.
error messages: one of the building blocks of Form Validation. It shows up whenever you work on sign-up forms.
constraint attributes: one of the building blocks of Form Validation. Mixing it up with neighboring terms is a common source of confusion.
