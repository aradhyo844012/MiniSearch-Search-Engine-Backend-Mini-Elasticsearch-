Practice Exercises for npm and Package Registries

These exercises build real understanding of npm and Package Registries. Do them in order, and write down your answers.

Exercise 1: Pick npm and complete its getting-started tutorial.
Exercise 2: Explain how lock files and registries differ, using a drawing.
Exercise 3: Compare Yarn and pnpm for reproducible builds and write down your conclusion.
Exercise 4: Write a short paragraph describing npm and Package Registries and include the term package.json.
Exercise 5: Create a small example that deliberately triggers this problem: unpinned versions. Then fix it.

When you finish, compare your answers with the definition: npm and Package Registries is services and tools for publishing and installing reusable code packages.
