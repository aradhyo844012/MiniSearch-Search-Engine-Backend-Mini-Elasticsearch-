The Trade-offs of JSON

Every design choice has a cost, and JSON is no exception. If you build software for long enough, you will run into JSON. The term refers to a lightweight text format for exchanging structured data between programs.

On the positive side, JSON is well suited to API responses and configuration files. On the other hand, it is not free. Keep these risks in mind: trailing commas; large payloads; losing precision with big numbers. Whether the trade is worth it depends on how much objects and arrays matter to your project.
