Cloud Cost Optimization Glossary for Beginners

New words can make Cloud Cost Optimization feel harder than it is. This glossary keeps the key ones in one place.

Cloud Cost Optimization: the practice of reducing cloud spending while keeping performance and reliability.
right-sizing: a core term, most visible in cutting idle resources.
reserved capacity: a core term that beginners often confuse with tagging.
tagging: a core term that connects to usage reports.
usage reports: a core term worth revisiting after you try a real example.
AWS Cost Explorer: a tool commonly used for budgeting by team.

Come back to this Cloud Cost Optimization list whenever documentation for Infracost uses a word you do not recognize.
