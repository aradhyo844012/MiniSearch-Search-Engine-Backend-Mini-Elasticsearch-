A Mini Project Idea Using Content Security Policy

A small project is the fastest way to make Content Security Policy stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Content Security Policy at work on reducing the impact of XSS. Keep the scope small enough to finish.

Milestones:
1. Read about directives and nonces.
2. Set up browser DevTools and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as allowing unsafe-inline.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover blocking unwanted scripts, or compare CSP Evaluator with Report URI.

Finish by recording what surprised you. Writing it down is how knowledge about Content Security Policy turns into something you can show others.
