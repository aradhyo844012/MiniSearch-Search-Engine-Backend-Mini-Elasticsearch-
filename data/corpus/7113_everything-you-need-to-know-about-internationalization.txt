Everything You Need to Know About Internationalization

This page collects the essentials about Internationalization in one place. In short, Internationalization is designing software so it can be adapted to different languages and regions.

Core concepts:
- locale detection
- translation files
- pluralization
- date and number formatting

Where it is used:
- global products
- multi-language websites
- regional pricing

Common problems:
- hard-coded strings
- text that overflows layouts
- assuming left-to-right text

Tools to know:
- i18next
- the Intl API
- Crowdin

Remember this above all: a stage set where the backdrop can be swapped for each audience is a good way to picture it, and the best habit is to move every user-facing string into translation files from the first day.
