Learning Path: From Zero to Comfortable with Topological Sorting

This path is for a learner who has never studied Topological Sorting before. Move at your own speed.

Stage 1, the basics: read a short definition (Topological Sorting is an ordering of tasks in a directed graph so that every task comes after the tasks it depends on) and learn directed acyclic graphs and in-degree counts.

Stage 2, hands-on: install Python graphlib, follow a tutorial, and build a small example involving build systems.

Stage 3, depth: study Kahn's algorithm and cycle detection, then deliberately explore this problem: ignoring cycles.

Stage 4, application: apply Topological Sorting to course prerequisite planning, compare NetworkX with Make, and write up your results.

Stage 5, review: teach Topological Sorting to someone else, and then move on to Segment Trees.
