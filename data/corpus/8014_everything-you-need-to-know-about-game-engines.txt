Everything You Need to Know About Game Engines

This page collects the essentials about Game Engines in one place. In short, Game Engines is software frameworks that provide graphics, physics, input and tools for building games.

Core concepts:
- scenes
- assets
- scripting
- build pipelines

Where it is used:
- indie games
- simulations
- interactive demos

Common problems:
- choosing an engine by hype
- loading everything at start-up
- ignoring platform limits

Tools to know:
- Unity
- Godot
- Unreal Engine

Remember this above all: a fully equipped workshop with the tools for building a game is a good way to picture it, and the best habit is to build a tiny prototype in two engines before choosing.
