Learning Path: From Zero to Comfortable with SQL Basics

This path is for a learner who has never studied SQL Basics before. Move at your own speed.

Stage 1, the basics: read a short definition (SQL Basics is the core SQL commands for reading and changing data in tables) and learn SELECT and WHERE.

Stage 2, hands-on: install SQLite, follow a tutorial, and build a small example involving reading customer records.

Stage 3, depth: study ORDER BY and INSERT and UPDATE, then deliberately explore this problem: forgetting the WHERE clause on updates.

Stage 4, application: apply SQL Basics to building reports, compare PostgreSQL with DB Browser for SQLite, and write up your results.

Stage 5, review: teach SQL Basics to someone else, and then move on to Database Constraints.
