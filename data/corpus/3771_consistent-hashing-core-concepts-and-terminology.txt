Consistent Hashing: Core Concepts and Terminology

This page defines the vocabulary you need to read about Consistent Hashing with confidence. The subject itself is a way of mapping keys to servers so that adding or removing servers moves very few keys.

hash ring: one of the building blocks of Consistent Hashing. You should be able to explain it in a single sentence before moving on.
virtual nodes: one of the building blocks of Consistent Hashing. Mixing it up with neighboring terms is a common source of confusion.
key placement: one of the building blocks of Consistent Hashing. Documentation for Redis Cluster usually mentions it early.
rebalancing: one of the building blocks of Consistent Hashing. Mixing it up with neighboring terms is a common source of confusion.

Practice using these four terms in sentences about sharded databases. If the sentences feel natural, the vocabulary has stuck.
