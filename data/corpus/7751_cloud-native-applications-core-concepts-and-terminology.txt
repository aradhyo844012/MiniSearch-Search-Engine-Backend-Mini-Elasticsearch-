Cloud-Native Applications: Core Concepts and Terminology

This page defines the vocabulary you need to read about Cloud-Native Applications with confidence. The subject itself is applications designed from the start to run in the cloud using containers and managed services.

containers: one of the building blocks of Cloud-Native Applications. It shows up whenever you work on web platforms.
microservices: one of the building blocks of Cloud-Native Applications. Documentation for Kubernetes usually mentions it early.
declarative configuration: one of the building blocks of Cloud-Native Applications. You should be able to explain it in a single sentence before moving on.
elastic scaling: one of the building blocks of Cloud-Native Applications. It shows up whenever you work on web platforms.

Practice using these four Cloud-Native Applications terms in sentences about data-heavy services. If the sentences feel natural, the vocabulary has stuck.
