Everything You Need to Know About State Management

This page collects the essentials about State Management in one place. In short, State Management is the practice of organizing where an application keeps and updates its data.

Core concepts:
- single source of truth
- actions
- reducers
- derived state

Where it is used:
- large single-page apps
- shared shopping carts
- multi-step form wizards

Common problems:
- putting everything in global state
- duplicated state that drifts apart
- unclear update paths

Tools to know:
- Redux
- Zustand
- Vue Pinia

Remember this above all: a shared whiteboard that everyone updates through the same rules is a good way to picture it, and the best habit is to keep state as close as possible to where it is used.
