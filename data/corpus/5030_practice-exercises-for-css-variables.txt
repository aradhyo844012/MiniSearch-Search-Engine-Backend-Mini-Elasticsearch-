Practice Exercises for CSS Variables

These exercises build real understanding of CSS Variables. Do them in order, and write down your answers.

Exercise 1: Create a small example that deliberately triggers this problem: missing fallbacks. Then fix it.
Exercise 2: List three situations from your own experience that resemble theme switching or design systems.
Exercise 3: Compare Sass and PostCSS for spacing scales and write down your conclusion.
Exercise 4: Explain how inheritance and fallback values differ, using a drawing.
Exercise 5: Pick browser DevTools and complete its getting-started tutorial.

When you finish, compare your answers with the definition: CSS Variables is custom properties that store values such as colors and spacing so they can be reused across styles.
