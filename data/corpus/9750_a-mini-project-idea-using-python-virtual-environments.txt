A Mini Project Idea Using Python Virtual Environments

A small project is the fastest way to make Python Virtual Environments stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Python Virtual Environments at work on keeping projects separate. Keep the scope small enough to finish.

Milestones:
1. Read about venv and pip.
2. Set up venv and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as installing packages globally.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover reproducing setups, or compare pipx with Poetry.

Finish by recording what surprised you. Writing it down is how knowledge about Python Virtual Environments turns into something you can show others.
