Prompt Engineering Quick Reference

A one-screen reminder for Prompt Engineering. Bookmark it and return when the details fade.

What it is: the practice of writing clear instructions and examples to get useful output from language models.
Key terms: instructions, examples, context, and output format.
Typical uses: drafting content, extracting data from text, and building assistants.
Risks: vague requests, missing context, and trusting outputs without verification.
Tools: model playgrounds, LangChain, and evaluation sets.

Mental picture: giving clear directions to a very literal helper.

Habit to build: specify the output format and include one or two examples.
