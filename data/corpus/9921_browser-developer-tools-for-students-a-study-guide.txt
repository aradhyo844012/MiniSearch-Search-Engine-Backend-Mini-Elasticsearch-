Browser Developer Tools for Students: A Study Guide

This study guide prepares you for exams, labs and interviews that cover Browser Developer Tools.

Learning goals:
1. Explain Browser Developer Tools in your own words.
2. Describe the elements panel, the console, the network panel, and the performance profiler.
3. Give examples from debugging layouts and inspecting API calls.
4. Name three problems to watch for.

Start with the definition: Browser Developer Tools is built-in browser panels for inspecting, debugging and measuring web pages. Then draw an X-ray machine for web pages on paper and label the four terms from the goals above.

Self-test questions: Why is editing the page and forgetting to copy the changes a problem? How does the console relate to the network panel? When would you choose Chrome DevTools or Firefox Developer Edition?

Study habit worth keeping: keep the network panel open while testing features.

When you feel ready, compare Browser Developer Tools with Code Formatters and write down three differences.
