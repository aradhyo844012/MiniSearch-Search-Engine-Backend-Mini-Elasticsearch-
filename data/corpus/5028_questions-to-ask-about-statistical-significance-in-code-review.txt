Questions to Ask About Statistical Significance in Code Review

Reviewing code that involves Statistical Significance is easier with a short list of questions. Keep these in mind as you read the diff.

- Would a test catch p-hacking if it appeared later?
- Could we always report the effect size alongside the p-value?
- Have we avoided this problem: ignoring sample size?
- Is the null hypothesis clear to someone reading the code for the first time?
- Does the code handle the case of judging experiment results correctly?
- Have we considered mistaking significance for importance?

Good reviews of work on Statistical Significance are specific, kind and focused on confidence intervals, not on personal style.
