Web Storage: Core Concepts and Terminology

This page defines the vocabulary you need to read about Web Storage with confidence. The subject itself is browser features for keeping small amounts of data on the user's device.

localStorage: one of the building blocks of Web Storage. Mixing it up with neighboring terms is a common source of confusion.
sessionStorage: one of the building blocks of Web Storage. You should be able to explain it in a single sentence before moving on.
cookies: one of the building blocks of Web Storage. It shows up whenever you work on saving user preferences.
IndexedDB: one of the building blocks of Web Storage. You should be able to explain it in a single sentence before moving on.
