Questions to Ask About 5G Networks in Code Review

Reviewing code that involves 5G Networks is easier with a short list of questions. Keep these in mind as you read the diff.

- Is speed test tools used consistently, or are we mixing approaches?
- Could we test real-world coverage rather than trusting peak speeds?
- Have we considered limited coverage on the fastest bands?
- Is latency clear to someone reading the code for the first time?
- Have we avoided this problem: marketing exaggeration?
- Does this change respect spectrum bands, or does it work around it?

Good reviews of work on 5G Networks are specific, kind and focused on network slicing, not on personal style.
