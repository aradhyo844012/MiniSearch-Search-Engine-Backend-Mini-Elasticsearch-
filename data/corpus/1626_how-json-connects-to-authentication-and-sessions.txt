How JSON Connects to Authentication and Sessions

JSON and Authentication and Sessions are closely connected parts of Backend and APIs. Seeing how they fit together helps you learn both faster.

A project involving API responses may also involve logging in to web apps. In such a project, objects and credentials often influence each other.

Start with JSON: the term refers to a lightweight text format for exchanging structured data between programs. Then look at Authentication and Sessions, which refers to the process of proving who a user is and remembering them between requests.

A useful exercise is to take one example, such as configuration files, and explain how session cookies would change the design.

Common problems are shared too. For JSON, watch for this: large payloads. For Authentication and Sessions, watch for this: never expiring sessions. Good APIs are boring, predictable and well documented.

Spend a few hours on each topic, then combine them in one small project using Python json module or Flask-Login.
