System Design Interviews Glossary for Beginners

New words can make System Design Interviews feel harder than it is. This glossary keeps the key ones in one place.

System Design Interviews: discussions in which candidates design a large software system and explain their choices.
requirements: a core term, most visible in preparing for senior roles.
scaling estimates: a core term that beginners often confuse with trade-offs.
trade-offs: a core term that connects to components.
components: a core term worth revisiting after you try a real example.
whiteboard sketches: a tool commonly used for practicing architectural thinking.

Come back to this System Design Interviews list whenever documentation for Excalidraw uses a word you do not recognize.
