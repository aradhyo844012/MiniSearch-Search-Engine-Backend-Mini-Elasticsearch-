A Short History of Functional Programming

Ideas behind Functional Programming developed gradually as engineers ran into practical limits and shared what they learned. The term Functional Programming refers to a style of programming that builds programs from functions and avoids shared mutable state. This article explains the idea in plain language and points out where it fits in real projects.

Reading other people's code is one of the fastest ways to improve as a programmer. A language is easiest to learn by building small projects rather than memorizing syntax.

The vocabulary of Functional Programming is small. Learn pure functions, immutability, higher-order functions, and composition, and most documentation will start to make sense. Sketching composition on paper before coding helps many learners see how the pieces fit.
