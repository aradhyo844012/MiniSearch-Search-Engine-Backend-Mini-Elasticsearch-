Edge Computing Glossary for Beginners

New words can make Edge Computing feel harder than it is. This glossary keeps the key ones in one place.

Edge Computing: processing data close to where it is produced instead of in a distant data center.
edge nodes: a core term, most visible in factory sensors.
latency: a core term that beginners often confuse with bandwidth savings.
bandwidth savings: a core term that connects to synchronization.
synchronization: a core term worth revisiting after you try a real example.
AWS IoT Greengrass: a tool commonly used for video analytics.

Come back to this Edge Computing list whenever documentation for K3s uses a word you do not recognize.
