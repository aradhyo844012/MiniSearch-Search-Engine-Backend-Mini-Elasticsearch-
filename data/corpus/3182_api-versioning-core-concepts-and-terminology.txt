API Versioning: Core Concepts and Terminology

This page defines the vocabulary you need to read about API Versioning with confidence. The subject itself is the practice of evolving an API without breaking existing clients.

version in the URL: one of the building blocks of API Versioning. It shows up whenever you work on public APIs.
header versioning: one of the building blocks of API Versioning. It shows up whenever you work on public APIs.
deprecation: one of the building blocks of API Versioning. Mixing it up with neighboring terms is a common source of confusion.
backward compatibility: one of the building blocks of API Versioning. It shows up whenever you work on public APIs.

Practice using these four terms in sentences about mobile apps that cannot update instantly. If the sentences feel natural, the vocabulary has stuck.
