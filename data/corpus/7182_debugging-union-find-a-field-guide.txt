Debugging Union-Find: A Field Guide

When something goes wrong around Union-Find, resist the urge to guess. Work through the problem in order.

Step 1: reproduce the problem with the smallest possible example.
Step 2: list the usual suspects: forgetting path compression, merging without checking roots, and using it when deletions are required.
Step 3: revisit parent pointers and union operation, since misunderstandings there cause many bugs.
Step 4: use Python lists or similar tools to look inside.
Step 5: write a test that fails because of the bug and passes after the fix.

Many bugs involving Union-Find in work such as detecting connected components come down to the first suspect on the list. Check the simple causes before suspecting anything exotic.

Finally, implement path compression and union by rank together. It prevents a surprising number of repeat problems.
