Dev Containers: Core Concepts and Terminology

This page defines the vocabulary you need to read about Dev Containers with confidence. The subject itself is containerized development environments that every teammate can start in the same way.

devcontainer.json: one of the building blocks of Dev Containers. Documentation for VS Code Dev Containers usually mentions it early.
images: one of the building blocks of Dev Containers. Mixing it up with neighboring terms is a common source of confusion.
mounted folders: one of the building blocks of Dev Containers. Documentation for VS Code Dev Containers usually mentions it early.
extensions: one of the building blocks of Dev Containers. It shows up whenever you work on onboarding new developers.
