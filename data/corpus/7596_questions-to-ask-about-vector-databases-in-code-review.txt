Questions to Ask About Vector Databases in Code Review

Reviewing code that involves Vector Databases is easier with a short list of questions. Keep these in mind as you read the diff.

- Does this change respect embeddings, or does it work around it?
- Would a test catch ignoring recall trade-offs if it appeared later?
- Could we measure recall on a small labeled test set?
- Does the code handle the case of semantic search correctly?
- Have we avoided this problem: oversized vectors?
- Is FAISS used consistently, or are we mixing approaches?

Good reviews of work on Vector Databases are specific, kind and focused on distance metrics, not on personal style.
