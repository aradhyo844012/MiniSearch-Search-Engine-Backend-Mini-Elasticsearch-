Questions to Ask About Consistent Hashing in Code Review

Reviewing code that involves Consistent Hashing is easier with a short list of questions. Keep these in mind as you read the diff.

- Would a test catch uneven load if it appeared later?
- Have we avoided this problem: hot keys?
- Does this change respect hash ring, or does it work around it?
- Could we use many virtual nodes per server to even out the load?
- Is Redis Cluster used consistently, or are we mixing approaches?
- Have we considered too few virtual nodes?

Good reviews of work on Consistent Hashing are specific, kind and focused on key placement, not on personal style.
