The Trade-offs of Linux Command Line

Every design choice has a cost, and Linux Command Line is no exception. When people talk about Linux Command Line, they usually mean a text-based way of controlling a computer using commands and scripts. It appears in almost every serious software project, whether or not developers notice it.

On the positive side, Linux Command Line is well suited to automating tasks and managing servers. On the other hand, it is not free. Keep these risks in mind: running destructive commands carelessly; forgetting quotes around paths; ignoring exit codes. Whether the trade is worth it depends on how much shell and pipes matter to your project.
