A Mini Project Idea Using Event Sourcing

A small project is the fastest way to make Event Sourcing stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Event Sourcing at work on audit trails. Keep the scope small enough to finish.

Milestones:
1. Read about event log and projections.
2. Set up Apache Kafka and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as changing event formats carelessly.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover financial ledgers, or compare EventStoreDB with PostgreSQL.

Finish by recording what surprised you. Writing it down is how knowledge about Event Sourcing turns into something you can show others.
