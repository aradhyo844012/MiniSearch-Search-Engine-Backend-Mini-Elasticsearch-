Practice Exercises for Regression Testing

These exercises build real understanding of Regression Testing. Do them in order, and write down your answers.

Exercise 1: Compare GitHub Actions and Jenkins for refactoring safely and write down your conclusion.
Exercise 2: Pick pytest and complete its getting-started tutorial.
Exercise 3: Create a small example that deliberately triggers this problem: slow suites that nobody runs. Then fix it.
Exercise 4: Explain how test selection and bug reproduction tests differ, using a drawing.
Exercise 5: List three situations from your own experience that resemble protecting releases or verifying bug fixes.

When you finish, compare your answers with the definition: Regression Testing is re-running tests after changes to make sure old features still work.
