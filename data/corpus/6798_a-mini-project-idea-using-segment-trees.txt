A Mini Project Idea Using Segment Trees

A small project is the fastest way to make Segment Trees stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Segment Trees at work on range sum queries. Keep the scope small enough to finish.

Milestones:
1. Read about tree nodes covering ranges and range queries.
2. Set up C++ arrays and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as off-by-one errors in ranges.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover finding minimums in a window, or compare Python lists with Codeforces problem sets.

Finish by recording what surprised you. Writing it down is how knowledge about Segment Trees turns into something you can show others.
