A Mini Project Idea Using Code Formatters

A small project is the fastest way to make Code Formatters stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Code Formatters at work on ending style debates. Keep the scope small enough to finish.

Milestones:
1. Read about style rules and configuration.
2. Set up Prettier and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as reformatting entire files at once.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover cleaner diffs, or compare Black with gofmt.

Finish by recording what surprised you. Writing it down is how knowledge about Code Formatters turns into something you can show others.
