A Mini Project Idea Using Combinatorics

A small project is the fastest way to make Combinatorics stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Combinatorics at work on analyzing algorithms. Keep the scope small enough to finish.

Milestones:
1. Read about permutations and combinations.
2. Set up Python itertools and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as double counting.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover probability, or compare math.comb with SymPy.

Finish by recording what surprised you. Writing it down is how knowledge about Combinatorics turns into something you can show others.
