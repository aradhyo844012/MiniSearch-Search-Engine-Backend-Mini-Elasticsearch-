The Importance of REST APIs in Modern Software

It is easy to underestimate REST APIs until something goes wrong without it. If you build software for long enough, you will run into REST APIs. The term refers to an approach to designing web APIs around resources, URLs and standard HTTP methods.

Good APIs are boring, predictable and well documented.

Typical applications include mobile app backends, integrating services, and public developer platforms. Small projects and large systems both benefit.

Watch out for these problems: inconsistent naming; returning 200 for errors; and no versioning plan.

A solid grasp of REST APIs also makes Caching Strategies easier to understand.

Keep experimenting, keep notes, and revisit REST APIs whenever a new project gives you a reason.
