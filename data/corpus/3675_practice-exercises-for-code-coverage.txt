Practice Exercises for Code Coverage

These exercises build real understanding of Code Coverage. Do them in order, and write down your answers.

Exercise 1: Compare JaCoCo and Istanbul for tracking test progress and write down your conclusion.
Exercise 2: List three situations from your own experience that resemble finding untested code or setting quality gates.
Exercise 3: Write a short paragraph describing Code Coverage and include the term line coverage.
Exercise 4: Create a small example that deliberately triggers this problem: chasing 100 percent. Then fix it.
Exercise 5: Pick coverage.py and complete its getting-started tutorial.

When you finish, compare your answers with the definition: Code Coverage is a measure of how much of the code is run by tests.
