A Mini Project Idea Using Distributed Locks

A small project is the fastest way to make Distributed Locks stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Distributed Locks at work on running scheduled jobs once. Keep the scope small enough to finish.

Milestones:
1. Read about lease times and fencing tokens.
2. Set up Redis and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as locks that never expire.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover protecting shared resources, or compare ZooKeeper with etcd.

Finish by recording what surprised you. Writing it down is how knowledge about Distributed Locks turns into something you can show others.
