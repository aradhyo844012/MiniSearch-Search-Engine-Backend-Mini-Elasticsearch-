Prompt Engineering Glossary for Beginners

New words can make Prompt Engineering feel harder than it is. This glossary keeps the key ones in one place.

Prompt Engineering: the practice of writing clear instructions and examples to get useful output from language models.
instructions: a core term, most visible in drafting content.
examples: a core term that beginners often confuse with context.
context: a core term that connects to output format.
output format: a core term worth revisiting after you try a real example.
model playgrounds: a tool commonly used for extracting data from text.

Come back to this Prompt Engineering list whenever documentation for LangChain uses a word you do not recognize.
