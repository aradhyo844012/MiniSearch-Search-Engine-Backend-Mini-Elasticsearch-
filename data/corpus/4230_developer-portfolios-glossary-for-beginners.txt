Developer Portfolios Glossary for Beginners

New words can make Developer Portfolios feel harder than it is. This glossary keeps the key ones in one place.

Developer Portfolios: a collection of projects and writing that shows what a developer can build.
projects: a core term, most visible in applying for internships.
README quality: a core term that beginners often confuse with live demos.
live demos: a core term that connects to clear descriptions.
clear descriptions: a core term worth revisiting after you try a real example.
GitHub Pages: a tool commonly used for showing skills to recruiters.

Come back to this Developer Portfolios list whenever documentation for Vercel uses a word you do not recognize.
