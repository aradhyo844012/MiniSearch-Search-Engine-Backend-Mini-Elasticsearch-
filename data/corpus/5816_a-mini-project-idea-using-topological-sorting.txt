A Mini Project Idea Using Topological Sorting

A small project is the fastest way to make Topological Sorting stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Topological Sorting at work on build systems. Keep the scope small enough to finish.

Milestones:
1. Read about directed acyclic graphs and in-degree counts.
2. Set up Python graphlib and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as ignoring cycles.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover course prerequisite planning, or compare NetworkX with Make.

Finish by recording what surprised you. Writing it down is how knowledge about Topological Sorting turns into something you can show others.
