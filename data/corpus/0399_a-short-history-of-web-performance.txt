A Short History of Web Performance

Ideas behind Web Performance developed gradually as engineers ran into practical limits and shared what they learned. If you build software for long enough, you will run into Web Performance. The term refers to the practice of making websites load quickly and respond smoothly.

Browser developer tools are the fastest way to understand why a page behaves as it does. Web pages must work across many browsers, devices and network conditions.

Four ideas sit at the heart of Web Performance: page weight, caching, lazy loading, and critical rendering path. Each one builds on the one before it. Understanding caching first often makes lazy loading much easier to reason about.

Web Performance and HTML Semantics are closely related, so learning both gives a fuller picture of Web Development.

In short, careful study of Web Performance pays off. Spend time on page weight and caching, and the rest will follow.
