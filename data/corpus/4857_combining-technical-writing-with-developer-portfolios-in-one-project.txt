Combining Technical Writing with Developer Portfolios in One Project

Real projects rarely use one idea in isolation. This article shows how Technical Writing and Developer Portfolios can work together in a single project.

Technical Writing is explaining technical ideas clearly in writing for a chosen audience. Developer Portfolios is a collection of projects and writing that shows what a developer can build.

Imagine a project that involves documentation and applying for internships. Technical Writing brings audience, while Developer Portfolios brings projects.

A sensible plan is to start with Markdown for the Technical Writing part and GitHub Pages for the Developer Portfolios part, and to keep the two sides connected through a small, well-tested interface.

Be prepared for combined risks: burying the main point on one side, and no explanation of decisions on the other.

Picture the whole as giving directions to a stranger, working alongside a shop window displaying your best work.

Two habits help: first, state the main point in the first two sentences; second, feature a few polished projects rather than many half-finished ones.
