A Practical Checklist for Password Hashing

Use this checklist before you rely on Password Hashing in a project.

1. Guard against this risk: using fast hashes like plain SHA-256.
2. Document your decisions in the project README.
3. Ask a teammate to review the work, focusing on slow hash functions.
4. Write at least one automated test that covers salts.
5. Review how Password Hashing interacts with Phishing Defense.
6. Review the core ideas: salts, slow hash functions, work factors, and verification.
7. Guard against this risk: storing passwords in plain text.
8. Guard against this risk: reusing salts.
9. Pick a tool to start with, such as bcrypt or Argon2.
