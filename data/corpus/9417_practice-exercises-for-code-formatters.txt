Practice Exercises for Code Formatters

These exercises build real understanding of Code Formatters. Do them in order, and write down your answers.

Exercise 1: Pick Prettier and complete its getting-started tutorial.
Exercise 2: Write a short paragraph describing Code Formatters and include the term style rules.
Exercise 3: Compare Black and gofmt for onboarding contributors and write down your conclusion.
Exercise 4: Explain how editor integration and pre-commit hooks differ, using a drawing.
Exercise 5: List three situations from your own experience that resemble ending style debates or cleaner diffs.

When you finish, compare your answers with the definition: Code Formatters is tools that automatically rewrite code to a consistent style.
