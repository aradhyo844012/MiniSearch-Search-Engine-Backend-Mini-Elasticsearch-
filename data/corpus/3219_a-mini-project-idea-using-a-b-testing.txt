A Mini Project Idea Using A/B Testing

A small project is the fastest way to make A/B Testing stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows A/B Testing at work on testing page designs. Keep the scope small enough to finish.

Milestones:
1. Read about control and variant and random assignment.
2. Set up Optimizely and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as stopping tests early.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover comparing ranking algorithms, or compare GrowthBook with statsmodels.

Finish by recording what surprised you. Writing it down is how knowledge about A/B Testing turns into something you can show others.
