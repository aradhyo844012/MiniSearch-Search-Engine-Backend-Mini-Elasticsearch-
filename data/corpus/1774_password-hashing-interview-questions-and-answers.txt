Password Hashing Interview Questions and Answers

Prepare for these questions about Password Hashing.

Q: Explain Password Hashing in simple words.
A: Password Hashing refers to storing passwords as one-way hashes so the originals are never kept. I would add an example involving user login systems.

Q: Which tools have you used?
A: bcrypt, Argon2, and scrypt.

Q: Where would you apply it first?
A: I would start with protecting data after a breach, because it is small enough to test and large enough to show the benefit.

Q: What are the key concepts?
A: salts, slow hash functions, work factors, and verification.

Q: What problems have you seen in practice?
A: using fast hashes like plain SHA-256; reusing salts; and storing passwords in plain text.
