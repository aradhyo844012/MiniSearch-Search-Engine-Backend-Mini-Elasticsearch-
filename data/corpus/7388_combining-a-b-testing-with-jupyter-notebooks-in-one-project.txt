Combining A/B Testing with Jupyter Notebooks in One Project

Real projects rarely use one idea in isolation. This article shows how A/B Testing and Jupyter Notebooks can work together in a single project.

A/B Testing is an experiment that compares two versions of something to see which performs better. Jupyter Notebooks is interactive documents that combine code, results and notes.

Imagine a project that involves testing page designs and exploring data. A/B Testing brings control and variant, while Jupyter Notebooks brings cells.

A sensible plan is to start with Optimizely for the A/B Testing part and JupyterLab for the Jupyter Notebooks part, and to keep the two sides connected through a small, well-tested interface.

Be prepared for combined risks: testing too many variants on one side, and hidden state on the other.

Picture the whole as taste-testing two recipes on randomly chosen guests, working alongside a lab notebook that can run its own experiments.

Two habits help: first, decide the success metric and sample size before you begin; second, restart the kernel and run all cells before sharing.
