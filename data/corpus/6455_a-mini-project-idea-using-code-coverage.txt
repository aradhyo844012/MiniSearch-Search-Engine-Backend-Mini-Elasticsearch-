A Mini Project Idea Using Code Coverage

A small project is the fastest way to make Code Coverage stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Code Coverage at work on finding untested code. Keep the scope small enough to finish.

Milestones:
1. Read about line coverage and branch coverage.
2. Set up coverage.py and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as chasing 100 percent.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover setting quality gates, or compare JaCoCo with Istanbul.

Finish by recording what surprised you. Writing it down is how knowledge about Code Coverage turns into something you can show others.
