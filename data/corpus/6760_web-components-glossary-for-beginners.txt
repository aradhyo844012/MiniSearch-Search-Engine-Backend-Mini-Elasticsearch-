Web Components Glossary for Beginners

New words can make Web Components feel harder than it is. This glossary keeps the key ones in one place.

Web Components: browser-native custom elements with their own markup, style and behavior.
custom elements: a core term, most visible in design system components.
shadow DOM: a core term that beginners often confuse with templates.
templates: a core term that connects to slots.
slots: a core term worth revisiting after you try a real example.
Lit: a tool commonly used for widgets reused across frameworks.

Come back to this Web Components list whenever documentation for Stencil uses a word you do not recognize.
