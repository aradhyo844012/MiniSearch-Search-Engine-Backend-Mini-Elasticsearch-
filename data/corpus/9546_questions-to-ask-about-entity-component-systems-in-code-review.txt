Questions to Ask About Entity Component Systems in Code Review

Reviewing code that involves Entity Component Systems is easier with a short list of questions. Keep these in mind as you read the diff.

- Is components clear to someone reading the code for the first time?
- Does this change respect entities, or does it work around it?
- Could we keep components as plain data?
- Is Bevy used consistently, or are we mixing approaches?
- Does the code handle the case of large simulations correctly?
- Would a test catch components that hold logic if it appeared later?

Good reviews of work on Entity Component Systems are specific, kind and focused on systems, not on personal style.
