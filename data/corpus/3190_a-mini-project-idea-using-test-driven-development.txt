A Mini Project Idea Using Test-Driven Development

A small project is the fastest way to make Test-Driven Development stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Test-Driven Development at work on designing small modules. Keep the scope small enough to finish.

Milestones:
1. Read about red, green, refactor and small steps.
2. Set up pytest and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as writing tests that are too large.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover preventing regressions, or compare JUnit with Jest.

Finish by recording what surprised you. Writing it down is how knowledge about Test-Driven Development turns into something you can show others.
