Dijkstra's Algorithm Tips from Experienced Engineers

Engineers who work with Dijkstra's Algorithm regularly tend to repeat the same advice. Here it is.

1. Write down why you chose Dijkstra's Algorithm so the next person understands the decision.
2. Do not skip priority queue; everything else builds on it.
3. Be careful with this one: using it with negative edge weights.
4. Test the case of route planning early, before the design hardens.
5. Make sure you can stop as soon as the destination is popped from the queue.

None of these tips needs special equipment, and all of them apply to network routing as well.
