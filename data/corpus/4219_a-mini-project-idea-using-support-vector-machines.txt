A Mini Project Idea Using Support Vector Machines

A small project is the fastest way to make Support Vector Machines stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Support Vector Machines at work on text classification. Keep the scope small enough to finish.

Milestones:
1. Read about margin and support vectors.
2. Set up scikit-learn and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as slow training on large data.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover small high-dimensional datasets, or compare LIBSVM with NumPy.

Finish by recording what surprised you. Writing it down is how knowledge about Support Vector Machines turns into something you can show others.
