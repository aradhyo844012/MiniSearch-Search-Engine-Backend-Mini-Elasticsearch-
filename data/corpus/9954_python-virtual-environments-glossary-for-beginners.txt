Python Virtual Environments Glossary for Beginners

New words can make Python Virtual Environments feel harder than it is. This glossary keeps the key ones in one place.

Python Virtual Environments: isolated folders that hold a project's own Python packages.
venv: a core term, most visible in keeping projects separate.
pip: a core term that beginners often confuse with requirements files.
requirements files: a core term that connects to activation.
activation: a core term worth revisiting after you try a real example.
venv: a tool commonly used for reproducing setups.

Come back to this Python Virtual Environments list whenever documentation for pipx uses a word you do not recognize.
