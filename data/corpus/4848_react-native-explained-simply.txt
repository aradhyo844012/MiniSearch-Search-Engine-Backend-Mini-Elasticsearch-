React Native Explained Simply

Here is React Native without the jargon: it is a framework for building mobile apps for several platforms using JavaScript and React.

Think of React Native as one script performed by actors on two different stages. Keep that picture in mind as you read on.

The vocabulary has four main pieces: components, native modules, styling with flexbox, and navigation. You do not need to master them all at once. Start with components, then add native modules.

You will meet React Native in work such as cross-platform apps, rapid prototypes, and sharing code with web teams.

One practical tip is to test on real devices for both platforms.

Once React Native feels comfortable, read about Arduino Basics, which lives in the same neighborhood of ideas.
