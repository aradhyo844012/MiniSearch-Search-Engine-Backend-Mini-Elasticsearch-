Where to Go Next After Learning Code Documentation

You have met the basics of Code Documentation. Here is how to keep the momentum going.

Go wider: read about API Design Principles, which belongs to the same area as Code Documentation (Software Design) and often appears in the same projects.

Go deeper: choose one of README files, docstrings, architecture notes or examples, and study it until you can explain it to a beginner.

Go practical: build something around describing APIs with Sphinx, and note every problem you meet, starting with outdated docs.

Go social: share what you learned. Explaining Code Documentation to others, and hearing their questions, is the quickest way to find the gaps in your knowledge.
