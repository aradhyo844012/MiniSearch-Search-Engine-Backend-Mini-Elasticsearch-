A Mini Project Idea Using Static Analysis

A small project is the fastest way to make Static Analysis stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Static Analysis at work on catching bugs early. Keep the scope small enough to finish.

Milestones:
1. Read about linters and type checkers.
2. Set up ESLint and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as ignoring warnings.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover enforcing team style, or compare Pylint with SonarQube.

Finish by recording what surprised you. Writing it down is how knowledge about Static Analysis turns into something you can show others.
