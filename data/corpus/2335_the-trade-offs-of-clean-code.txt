The Trade-offs of Clean Code

Every design choice has a cost, and Clean Code is no exception. Many students first meet Clean Code in a classroom, but it matters just as much in production systems. The term refers to writing code that other people can read, understand and change easily.

On the positive side, Clean Code is well suited to team projects and long-lived products. On the other hand, it is not free. Keep these risks in mind: cryptic abbreviations; functions that do too much; comments that repeat the code. Whether the trade is worth it depends on how much meaningful names and small functions matter to your project.
