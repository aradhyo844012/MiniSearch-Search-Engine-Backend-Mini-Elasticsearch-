How to Learn Functional Programming in 30 Days

You do not need months to become comfortable with Functional Programming. A focused plan of thirty days is enough to build a solid base. If you build software for long enough, you will run into Functional Programming. The term refers to a style of programming that builds programs from functions and avoids shared mutable state.

Functional Programming and Python Basics are closely related, so learning both gives a fuller picture of Programming.

Week 1: learn pure functions and immutability, and write a one-page summary.
Week 2: practice with Python functools on a small task such as data transformation.
Week 3: build a mini project around concurrent code.
Week 4: review common mistakes such as overusing clever one-liners, and explain Functional Programming to a friend.

In practice you can start with Python functools, then explore JavaScript array methods or Haskell as your needs grow.

With steady practice, Functional Programming will stop feeling abstract and become a tool you reach for naturally.
