Learning Path: From Zero to Comfortable with Test-Driven Development

This path is for a learner who has never studied Test-Driven Development before. Move at your own speed.

Stage 1, the basics: read a short definition (Test-Driven Development is a workflow where you write a failing test first and then write code to make it pass) and learn red, green, refactor and small steps.

Stage 2, hands-on: install pytest, follow a tutorial, and build a small example involving designing small modules.

Stage 3, depth: study test first and fast feedback, then deliberately explore this problem: writing tests that are too large.

Stage 4, application: apply Test-Driven Development to preventing regressions, compare JUnit with Jest, and write up your results.

Stage 5, review: teach Test-Driven Development to someone else, and then move on to API Design Principles.
