A Mini Project Idea Using Regular Expressions

A small project is the fastest way to make Regular Expressions stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Regular Expressions at work on validating input. Keep the scope small enough to finish.

Milestones:
1. Read about character classes and quantifiers.
2. Set up the Python re module and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as catastrophic backtracking.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover searching logs, or compare regex101 with grep.

Finish by recording what surprised you. Writing it down is how knowledge about Regular Expressions turns into something you can show others.
