A Mini Project Idea Using Game Loop

A small project is the fastest way to make Game Loop stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Game Loop at work on running every real-time game. Keep the scope small enough to finish.

Milestones:
1. Read about input handling and the update step.
2. Set up Unity and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as tying logic to frame rate.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover keeping animation smooth, or compare Godot with SDL.

Finish by recording what surprised you. Writing it down is how knowledge about Game Loop turns into something you can show others.
