Debugging NULL Handling in SQL: A Field Guide

When something goes wrong around NULL Handling in SQL, resist the urge to guess. Work through the problem in order.

Step 1: reproduce the problem with the smallest possible example.
Step 2: list the usual suspects: comparing with equals instead of IS NULL, NOT IN with NULLs, and forgetting NULLs in counts.
Step 3: revisit three-valued logic and IS NULL, since misunderstandings there cause many bugs.
Step 4: use PostgreSQL or similar tools to look inside.
Step 5: write a test that fails because of the bug and passes after the fix.

Many bugs involving NULL Handling in SQL in work such as optional fields come down to the first suspect on the list. Check the simple causes before suspecting anything exotic.

Finally, use IS NULL and COALESCE instead of comparing with equals. It prevents a surprising number of repeat problems.
