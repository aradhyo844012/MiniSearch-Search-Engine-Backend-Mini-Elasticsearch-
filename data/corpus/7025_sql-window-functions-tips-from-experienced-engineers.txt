SQL Window Functions Tips from Experienced Engineers

Engineers who work with SQL Window Functions regularly tend to repeat the same advice. Here it is.

1. Do not skip the OVER clause; everything else builds on it.
2. When something behaves strangely, revisit partitions before anything else.
3. Make sure you can start with ROW_NUMBER and LAG on a small table.
4. Reach for PostgreSQL first, and only then evaluate alternatives such as SQLite.
5. Test the case of running totals early, before the design hardens.

None of these tips needs special equipment, and all of them apply to ranking rows as well.
