Game Engines Quick Reference

A one-screen reminder for Game Engines. Bookmark it and return when the details fade.

What it is: software frameworks that provide graphics, physics, input and tools for building games.
Key terms: scenes, assets, scripting, and build pipelines.
Typical uses: indie games, simulations, and interactive demos.
Risks: choosing an engine by hype, loading everything at start-up, and ignoring platform limits.
Tools: Unity, Godot, and Unreal Engine.

Mental picture: a fully equipped workshop with the tools for building a game.

Habit to build: build a tiny prototype in two engines before choosing.
