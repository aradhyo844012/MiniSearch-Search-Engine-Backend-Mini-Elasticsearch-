A Mini Project Idea Using System Calls

A small project is the fastest way to make System Calls stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows System Calls at work on reading and writing files. Keep the scope small enough to finish.

Milestones:
1. Read about user mode and kernel mode and syscall numbers.
2. Set up strace and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as ignoring error codes.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover creating processes, or compare man pages with libc.

Finish by recording what surprised you. Writing it down is how knowledge about System Calls turns into something you can show others.
