npm and Package Registries Glossary for Beginners

New words can make npm and Package Registries feel harder than it is. This glossary keeps the key ones in one place.

npm and Package Registries: services and tools for publishing and installing reusable code packages.
package.json: a core term, most visible in installing JavaScript libraries.
semantic versions: a core term that beginners often confuse with lock files.
lock files: a core term that connects to registries.
registries: a core term worth revisiting after you try a real example.
npm: a tool commonly used for sharing internal packages.

Come back to this npm and Package Registries list whenever documentation for Yarn uses a word you do not recognize.
