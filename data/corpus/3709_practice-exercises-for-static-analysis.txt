Practice Exercises for Static Analysis

These exercises build real understanding of Static Analysis. Do them in order, and write down your answers.

Exercise 1: List three situations from your own experience that resemble catching bugs early or enforcing team style.
Exercise 2: Explain how rule sets and false positives differ, using a drawing.
Exercise 3: Pick ESLint and complete its getting-started tutorial.
Exercise 4: Compare Pylint and SonarQube for improving security and write down your conclusion.
Exercise 5: Write a short paragraph describing Static Analysis and include the term linters.

When you finish, compare your answers with the definition: Static Analysis is automated checking of source code for bugs and style problems without running it.
