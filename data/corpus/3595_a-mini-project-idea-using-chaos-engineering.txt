A Mini Project Idea Using Chaos Engineering

A small project is the fastest way to make Chaos Engineering stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Chaos Engineering at work on testing resilience. Keep the scope small enough to finish.

Milestones:
1. Read about steady state and hypotheses.
2. Set up Chaos Monkey and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as experimenting without safeguards.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover validating failover, or compare Gremlin with LitmusChaos.

Finish by recording what surprised you. Writing it down is how knowledge about Chaos Engineering turns into something you can show others.
