Greedy Algorithms: Core Concepts and Terminology

This page defines the vocabulary you need to read about Greedy Algorithms with confidence. The subject itself is algorithms that build a solution by always taking the locally best choice.

greedy choice property: one of the building blocks of Greedy Algorithms. Mixing it up with neighboring terms is a common source of confusion.
optimal substructure: one of the building blocks of Greedy Algorithms. Mixing it up with neighboring terms is a common source of confusion.
exchange arguments: one of the building blocks of Greedy Algorithms. It shows up whenever you work on interval scheduling.
local versus global optimum: one of the building blocks of Greedy Algorithms. Documentation for pen and paper proofs usually mentions it early.
