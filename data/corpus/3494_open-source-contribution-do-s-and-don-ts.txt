Open Source Contribution Do's and Don'ts

A quick list of habits for working with Open Source Contribution.

Do:
- Learn forks before anything else.
- Try GitHub on a small example.
- Make it a habit to start with documentation fixes or small bugs.
- Test the case of building a portfolio early.

Don't:
- Ignore this: opening huge pull requests.
- Ignore this: ignoring contribution rules.
- Ignore this: expecting instant replies.
- Adopt Open Source Contribution just because it is fashionable.

Most of the Don'ts come from rushing. When you work with Open Source Contribution, a little patience with pull requests pays off more than any clever shortcut.
