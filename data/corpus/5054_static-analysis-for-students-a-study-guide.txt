Static Analysis for Students: A Study Guide

This study guide prepares you for exams, labs and interviews that cover Static Analysis.

Learning goals:
1. Explain Static Analysis in your own words.
2. Describe linters, type checkers, rule sets, and false positives.
3. Give examples from catching bugs early and enforcing team style.
4. Name three problems to watch for.

Start with the definition: Static Analysis is automated checking of source code for bugs and style problems without running it. Then draw a spell checker for code on paper and label the four terms from the goals above.

Self-test questions: Why is ignoring warnings a problem? How does type checkers relate to rule sets? When would you choose ESLint or Pylint?

Study habit: run it in CI so problems never reach the main branch.

When you feel ready, compare Static Analysis with Regression Testing and write down three differences.
