Shaders: Core Concepts and Terminology

This page defines the vocabulary you need to read about Shaders with confidence. The subject itself is small programs that run on the graphics card to control how things are drawn.

vertex shaders: one of the building blocks of Shaders. Documentation for GLSL usually mentions it early.
fragment shaders: one of the building blocks of Shaders. Documentation for GLSL usually mentions it early.
uniforms: one of the building blocks of Shaders. Documentation for GLSL usually mentions it early.
GLSL: one of the building blocks of Shaders. It shows up whenever you work on lighting effects.
