Command Line Productivity Quick Reference

A one-screen reminder for Command Line Productivity. Bookmark it and return when the details fade.

What it is: using shell tools and shortcuts to complete tasks faster.
Key terms: aliases, pipes, history search, and scripts.
Typical uses: automating repetitive tasks, exploring files and logs, and managing servers.
Risks: copying commands without understanding them, dangerous wildcard use, and undocumented scripts.
Tools: bash, tmux, and fzf.

Mental picture: learning the shortcuts on a well-used road.

Habit to build: turn commands you repeat into small scripts.
