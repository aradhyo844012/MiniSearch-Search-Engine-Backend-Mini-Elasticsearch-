How to Learn Object-Oriented Programming in 30 Days

You do not need months to become comfortable with Object-Oriented Programming. A focused plan of thirty days is enough to build a solid base. The term Object-Oriented Programming refers to a style of programming that organizes code into objects that combine data and behavior. This article explains the idea in plain language and points out where it fits in real projects.

Week 1: learn classes and inheritance, and write a one-page summary.
Week 2: practice with Python classes on a small task such as modeling real-world entities.
Week 3: build a mini project around building frameworks.
Week 4: review common mistakes such as deep inheritance chains, and explain Object-Oriented Programming to a friend.

In practice you can start with Python classes, then explore Java or UML tools as your needs grow.

None of this needs special hardware or expensive software. A laptop, curiosity and a few small experiments are enough to get comfortable with Object-Oriented Programming.
