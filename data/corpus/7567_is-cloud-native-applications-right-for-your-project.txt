Is Cloud-Native Applications Right for Your Project?

Before adopting Cloud-Native Applications, ask whether it fits the problem. Remember that Cloud-Native Applications is applications designed from the start to run in the cloud using containers and managed services.

It is a good fit when your work involves web platforms or data-heavy services, and when your team understands containers.

Be cautious when the project is very small, when deadlines leave no room to learn microservices, or when you cannot manage these risks: treating the cloud like a data center, too many services, and ignoring costs.

A simple decision test: write down the problem in one sentence, then check whether declarative configuration and elastic scaling are part of the answer. If they are, Cloud-Native Applications is probably worth a closer look.

If you decide to go ahead, start small with rapidly changing products and design every service to be stateless where possible.
