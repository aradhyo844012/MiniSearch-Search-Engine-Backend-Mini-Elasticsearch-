React Native Glossary for Beginners

New words can make React Native feel harder than it is. This glossary keeps the key ones in one place.

React Native: a framework for building mobile apps for several platforms using JavaScript and React.
components: a core term, most visible in cross-platform apps.
native modules: a core term that beginners often confuse with styling with flexbox.
styling with flexbox: a core term that connects to navigation.
navigation: a core term worth revisiting after you try a real example.
Expo: a tool commonly used for rapid prototypes.

Come back to this React Native list whenever documentation for Metro uses a word you do not recognize.
