Key Terms in Functional Programming Explained

Clear vocabulary makes Functional Programming much easier to learn, so here are the key terms in plain language. If you build software for long enough, you will run into Functional Programming. The term refers to a style of programming that builds programs from functions and avoids shared mutable state.

Every language has idioms that experienced developers recognize at a glance.
