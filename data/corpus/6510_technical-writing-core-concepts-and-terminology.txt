Technical Writing: Core Concepts and Terminology

This page defines the vocabulary you need to read about Technical Writing with confidence. The subject itself is explaining technical ideas clearly in writing for a chosen audience.

audience: one of the building blocks of Technical Writing. Documentation for Markdown usually mentions it early.
structure: one of the building blocks of Technical Writing. Mixing it up with neighboring terms is a common source of confusion.
examples: one of the building blocks of Technical Writing. Documentation for Markdown usually mentions it early.
editing: one of the building blocks of Technical Writing. Documentation for Markdown usually mentions it early.

Practice using these four terms in sentences about blog posts. If the sentences feel natural, the vocabulary has stuck.
