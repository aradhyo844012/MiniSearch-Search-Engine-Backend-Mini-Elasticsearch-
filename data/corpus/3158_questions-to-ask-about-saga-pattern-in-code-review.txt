Questions to Ask About Saga Pattern in Code Review

Reviewing code that involves Saga Pattern is easier with a short list of questions. Keep these in mind as you read the diff.

- Have we avoided this problem: flows that are hard to trace?
- Have we considered missing compensations?
- Is Temporal used consistently, or are we mixing approaches?
- Could we make every step and its compensation idempotent?
- Is compensating actions clear to someone reading the code for the first time?
- Does this change respect local transactions, or does it work around it?

Good reviews of work on Saga Pattern are specific, kind and focused on orchestration, not on personal style.
