Teaching npm and Package Registries to a Teammate

Explaining npm and Package Registries to someone else is one of the best ways to test your own understanding. Use this simple outline.

Start with a picture: a shared parts warehouse with a catalog. Ask your teammate what the picture suggests.

Then give the plain definition: npm and Package Registries is services and tools for publishing and installing reusable code packages. Avoid jargon at this stage.

Walk through an example involving installing JavaScript libraries, naming package.json and semantic versions as they come up.

Ask your teammate to explain lock files in npm and Package Registries back to you. Gaps in their explanation show you what to clarify.

Finish by pointing out a trap, unpinned versions, and suggest this habit: commit your lock file.
