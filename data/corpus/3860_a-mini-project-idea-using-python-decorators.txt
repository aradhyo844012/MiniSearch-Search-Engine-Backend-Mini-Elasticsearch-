A Mini Project Idea Using Python Decorators

A small project is the fastest way to make Python Decorators stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Python Decorators at work on logging calls. Keep the scope small enough to finish.

Milestones:
1. Read about higher-order functions and wrapper functions.
2. Set up functools and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as losing function metadata.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover caching results, or compare Flask routes with pytest fixtures.

Finish by recording what surprised you. Writing it down is how knowledge about Python Decorators turns into something you can show others.
