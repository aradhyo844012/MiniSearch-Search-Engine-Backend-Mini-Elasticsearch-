Python Decorators Tips from Experienced Engineers

Engineers who work with Python Decorators regularly tend to repeat the same advice. Here it is.

1. Test the case of logging calls early, before the design hardens.
2. When something behaves strangely, revisit wrapper functions before anything else.
3. Do not skip higher-order functions; everything else builds on it.
4. Write down why you chose Python Decorators so the next person understands the decision.
5. Make sure you can always apply functools.wraps inside your decorator.

None of these tips needs special equipment, and all of them apply to caching results as well.
