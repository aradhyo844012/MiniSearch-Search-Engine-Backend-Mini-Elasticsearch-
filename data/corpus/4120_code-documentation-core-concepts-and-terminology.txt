Code Documentation: Core Concepts and Terminology

This page defines the vocabulary you need to read about Code Documentation with confidence. The subject itself is written explanations that help others understand and use code.

README files: one of the building blocks of Code Documentation. Mixing it up with neighboring terms is a common source of confusion.
docstrings: one of the building blocks of Code Documentation. You should be able to explain it in a single sentence before moving on.
architecture notes: one of the building blocks of Code Documentation. It shows up whenever you work on onboarding new developers.
examples: one of the building blocks of Code Documentation. You should be able to explain it in a single sentence before moving on.
