JavaScript Closures Tips from Experienced Engineers

Engineers who work with JavaScript Closures regularly tend to repeat the same advice. Here it is.

1. Do not skip lexical scope; everything else builds on it.
2. Write down why you chose JavaScript Closures so the next person understands the decision.
3. Be careful with this one: loop variables captured by mistake.
4. When something behaves strangely, revisit captured variables before anything else.
5. Test the case of keeping private state in modules early, before the design hardens.

None of these tips needs special equipment, and all of them apply to event handlers that need context as well.
