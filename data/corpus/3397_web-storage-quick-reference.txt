Web Storage Quick Reference

A one-screen reminder for Web Storage. Bookmark it and return when the details fade.

What it is: browser features for keeping small amounts of data on the user's device.
Key terms: localStorage, sessionStorage, cookies, and IndexedDB.
Typical uses: saving user preferences, remembering form drafts, and caching small API results.
Risks: storing sensitive data, assuming storage is always available, and hitting size limits.
Tools: browser DevTools, localForage, and Dexie.js.

Mental picture: a sticky note on the fridge that only your household can read.

Habit to build: wrap every read and write in error handling.
