Network Troubleshooting: Core Concepts and Terminology

This page defines the vocabulary you need to read about Network Troubleshooting with confidence. The subject itself is a step-by-step process for finding out why a network connection fails or is slow.

protocol layers: one of the building blocks of Network Troubleshooting. Documentation for ping usually mentions it early.
ping and traceroute: one of the building blocks of Network Troubleshooting. You should be able to explain it in a single sentence before moving on.
DNS checks: one of the building blocks of Network Troubleshooting. Mixing it up with neighboring terms is a common source of confusion.
packet captures: one of the building blocks of Network Troubleshooting. It shows up whenever you work on fixing office connectivity.
