Teaching Cloud-Native Applications to a Teammate

Explaining Cloud-Native Applications to someone else is one of the best ways to test your own understanding. Use this simple outline.

Start with a picture: a plant that grows best in the soil it was designed for. Ask your teammate what the picture suggests.

Then give the plain definition: Cloud-Native Applications is applications designed from the start to run in the cloud using containers and managed services. Avoid jargon at this stage.

Walk through an example involving web platforms, naming containers and microservices as they come up.

Ask your teammate to explain declarative configuration in Cloud-Native Applications back to you. Gaps in their explanation show you what to clarify.

Finish by pointing out a trap, treating the cloud like a data center, and suggest this habit: design every service to be stateless where possible.
