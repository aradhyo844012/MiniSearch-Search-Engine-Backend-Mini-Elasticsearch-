Push Notifications Glossary for Beginners

New words can make Push Notifications feel harder than it is. This glossary keeps the key ones in one place.

Push Notifications: messages sent to a user's device from a server even when the app is closed.
device tokens: a core term, most visible in order updates.
push services: a core term that beginners often confuse with payloads.
payloads: a core term that connects to permissions.
permissions: a core term worth revisiting after you try a real example.
Firebase Cloud Messaging: a tool commonly used for chat alerts.

Come back to this Push Notifications list whenever documentation for Apple Push Notification service uses a word you do not recognize.
