Web Storage Tips from Experienced Engineers

Engineers who work with Web Storage regularly tend to repeat the same advice. Here it is.

1. Reach for browser DevTools first, and only then evaluate alternatives such as localForage.
2. Test the case of saving user preferences early, before the design hardens.
3. Be careful with this one: storing sensitive data.
4. Make sure you can wrap every read and write in error handling.
5. Do not skip localStorage; everything else builds on it.

None of these tips needs special equipment, and all of them apply to remembering form drafts as well.
