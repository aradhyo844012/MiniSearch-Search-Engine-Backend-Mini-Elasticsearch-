Questions to Ask About Video Codecs in Code Review

Reviewing code that involves Video Codecs is easier with a short list of questions. Keep these in mind as you read the diff.

- Could we test playback on the weakest target device?
- Does this change respect frames, or does it work around it?
- Have we considered mismatched codec support?
- Does the code handle the case of streaming services correctly?
- Have we avoided this problem: ignoring hardware decoding?
- Is motion compensation clear to someone reading the code for the first time?

Good reviews of work on Video Codecs are specific, kind and focused on bitrate, not on personal style.
