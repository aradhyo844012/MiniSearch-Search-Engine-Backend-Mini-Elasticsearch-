React Native in 10 Minutes

You have ten minutes, so here is the fast route through React Native.

Minutes 1 and 2, the definition: React Native is a framework for building mobile apps for several platforms using JavaScript and React.

Minutes 3 and 4, the vocabulary: learn components, native modules, styling with flexbox, and navigation.

Minutes 5 and 6, the picture: imagine one script performed by actors on two different stages. That is the intuition.

Minutes 7 and 8, the use cases: skim through cross-platform apps, rapid prototypes, and sharing code with web teams.

Minutes 9 and 10, the traps and the tools: watch for heavy re-renders and poorly tuned lists, then try Expo for a first experiment.

If you have a spare minute, remember to test on real devices for both platforms.
