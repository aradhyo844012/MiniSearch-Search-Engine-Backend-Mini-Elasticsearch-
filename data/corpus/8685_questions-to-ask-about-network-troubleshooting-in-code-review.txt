Questions to Ask About Network Troubleshooting in Code Review

Reviewing code that involves Network Troubleshooting is easier with a short list of questions. Keep these in mind as you read the diff.

- Is ping and traceroute clear to someone reading the code for the first time?
- Would a test catch blaming the application too early if it appeared later?
- Does this change respect protocol layers, or does it work around it?
- Is ping used consistently, or are we mixing approaches?
- Could we work from the bottom layer upward?
- Have we considered changing several things at once?

Good reviews of work on Network Troubleshooting are specific, kind and focused on DNS checks, not on personal style.
