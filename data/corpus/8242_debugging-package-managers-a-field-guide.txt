Debugging Package Managers: A Field Guide

When something goes wrong around Package Managers, resist the urge to guess. Work through the problem in order.

Step 1: reproduce the problem with the smallest possible example.
Step 2: list the usual suspects: mixing sources that conflict, ignoring signature checks, and upgrading without reading the changes.
Step 3: revisit repositories and dependency resolution, since misunderstandings there cause many bugs.
Step 4: use apt or similar tools to look inside.
Step 5: write a test that fails because of the bug and passes after the fix.

Many bugs involving Package Managers in work such as installing system tools come down to the first suspect on the list. Check the simple causes before suspecting anything exotic.

Finally, update the package index before installing anything. It prevents a surprising number of repeat problems.
