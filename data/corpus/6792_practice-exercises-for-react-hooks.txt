Practice Exercises for React Hooks

These exercises build real understanding of React Hooks. Do them in order, and write down your answers.

Exercise 1: List three situations from your own experience that resemble managing form input or fetching data on load.
Exercise 2: Write a short paragraph describing React Hooks and include the term useState.
Exercise 3: Compare Vite and the ESLint hooks plugin for sharing logic between components and write down your conclusion.
Exercise 4: Pick React DevTools and complete its getting-started tutorial.
Exercise 5: Explain how dependency arrays and custom hooks differ, using a drawing.

When you finish, compare your answers with the definition: React Hooks is functions that let components use state and lifecycle features without writing classes.
