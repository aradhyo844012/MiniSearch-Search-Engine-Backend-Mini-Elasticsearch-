A Mini Project Idea Using Subqueries and CTEs

A small project is the fastest way to make Subqueries and CTEs stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Subqueries and CTEs at work on breaking complex reports into steps. Keep the scope small enough to finish.

Milestones:
1. Read about subqueries and WITH clauses.
2. Set up PostgreSQL and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as correlated subqueries that run slowly.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover filtering with computed results, or compare SQLite with dbt.

Finish by recording what surprised you. Writing it down is how knowledge about Subqueries and CTEs turns into something you can show others.
