Debugging Linux Boot Process: A Field Guide

When something goes wrong around Linux Boot Process, resist the urge to guess. Work through the problem in order.

Step 1: reproduce the problem with the smallest possible example.
Step 2: list the usual suspects: overwriting the bootloader, wrong kernel parameters, and ignoring recovery options.
Step 3: revisit firmware and bootloader, since misunderstandings there cause many bugs.
Step 4: use GRUB or similar tools to look inside.
Step 5: write a test that fails because of the bug and passes after the fix.

Many bugs involving Linux Boot Process in work such as troubleshooting machines that do not start come down to the first suspect on the list. Check the simple causes before suspecting anything exotic.

Finally, keep a recovery option available before editing boot settings. It prevents a surprising number of repeat problems.
