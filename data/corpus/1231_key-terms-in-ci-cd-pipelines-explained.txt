Key Terms in CI/CD Pipelines Explained

Clear vocabulary makes CI/CD Pipelines much easier to learn, so here are the key terms in plain language. If you build software for long enough, you will run into CI/CD Pipelines. The term refers to automated workflows that build, test and deliver code whenever it changes.

build stage: a key term in CI/CD Pipelines. You will meet it constantly in documentation and in code reviews.
test stage: a key term in CI/CD Pipelines. Practice with a small example to make the meaning stick.
artifacts: a key term in CI/CD Pipelines. You will meet it constantly in documentation and in code reviews.
deployment stage: a key term in CI/CD Pipelines. Beginners often confuse it with related terms, so define it in your own words early.

With steady practice, CI/CD Pipelines will stop feeling abstract and become a tool you reach for naturally.
