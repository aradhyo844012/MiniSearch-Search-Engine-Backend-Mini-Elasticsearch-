Learning Path: From Zero to Comfortable with Open Source Contribution

This path is for a learner who has never studied Open Source Contribution before. Move at your own speed.

Stage 1, the basics: read a short definition (Open Source Contribution is helping improve public software projects by fixing bugs, writing documentation or adding features) and learn forks and pull requests.

Stage 2, hands-on: install GitHub, follow a tutorial, and build a small example involving building a portfolio.

Stage 3, depth: study issues and contributing guides, then deliberately explore this problem: opening huge pull requests.

Stage 4, application: apply Open Source Contribution to learning from experienced maintainers, compare good first issue labels with Git, and write up your results.

Stage 5, review: teach Open Source Contribution to someone else, and then move on to Technical Writing.
