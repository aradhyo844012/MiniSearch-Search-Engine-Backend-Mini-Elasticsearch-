A Mini Project Idea Using Packet Switching

A small project is the fastest way to make Packet Switching stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Packet Switching at work on internet traffic. Keep the scope small enough to finish.

Milestones:
1. Read about packets and headers.
2. Set up Wireshark and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as packet loss.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover voice over IP, or compare tcpdump with iperf.

Finish by recording what surprised you. Writing it down is how knowledge about Packet Switching turns into something you can show others.
