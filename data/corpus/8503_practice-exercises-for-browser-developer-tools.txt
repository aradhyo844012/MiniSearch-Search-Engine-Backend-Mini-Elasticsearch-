Practice Exercises for Browser Developer Tools

These exercises build real understanding of Browser Developer Tools. Do them in order, and write down your answers.

Exercise 1: Compare Firefox Developer Edition and Lighthouse for finding slow scripts and write down your conclusion.
Exercise 2: Explain how the network panel and the performance profiler differ, using a drawing.
Exercise 3: Write a short paragraph describing Browser Developer Tools and include the term the elements panel.
Exercise 4: Create a small example that deliberately triggers this problem: editing the page and forgetting to copy the changes. Then fix it.
Exercise 5: Pick Chrome DevTools and complete its getting-started tutorial.

When you finish, compare your answers with the definition: Browser Developer Tools is built-in browser panels for inspecting, debugging and measuring web pages.
