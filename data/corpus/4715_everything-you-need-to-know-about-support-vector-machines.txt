Everything You Need to Know About Support Vector Machines

This page collects the essentials about Support Vector Machines in one place. In short, Support Vector Machines is models that classify data by finding the boundary with the widest margin between classes.

Core concepts:
- margin
- support vectors
- kernels
- regularization

Where it is used:
- text classification
- small high-dimensional datasets
- image recognition baselines

Common problems:
- slow training on large data
- poor kernel choices
- unscaled features

Tools to know:
- scikit-learn
- LIBSVM
- NumPy

Remember this above all: drawing the widest road between two neighborhoods is a good way to picture it, and the best habit is to scale features and try a linear kernel first.
