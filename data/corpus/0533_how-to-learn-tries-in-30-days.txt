How to Learn Tries in 30 Days

You do not need months to become comfortable with Tries. A focused plan of thirty days is enough to build a solid base. When people talk about Tries, they usually mean tree structures that store strings character by character so shared prefixes are stored once. It appears in almost every serious software project, whether or not developers notice it.

Week 1: learn prefix sharing and nodes and edges, and write a one-page summary.
Week 2: practice with Python dict-based tries on a small task such as autocomplete.
Week 3: build a mini project around spell checking.
Week 4: review common mistakes such as high memory use for sparse data, and explain Tries to a friend.

Popular tools and libraries include Python dict-based tries, Java TreeMap, and pygtrie.

Keep experimenting, keep notes, and revisit Tries whenever a new project gives you a reason.
