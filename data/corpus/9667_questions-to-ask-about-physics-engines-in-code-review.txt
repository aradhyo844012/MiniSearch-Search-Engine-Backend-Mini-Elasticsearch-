Questions to Ask About Physics Engines in Code Review

Reviewing code that involves Physics Engines is easier with a short list of questions. Keep these in mind as you read the diff.

- Have we considered variable time steps?
- Would a test catch unstable stacks of objects if it appeared later?
- Does the code handle the case of vehicles and ragdolls correctly?
- Could we use a fixed time step for stable results?
- Does this change respect rigid bodies, or does it work around it?
- Have we avoided this problem: extreme mass ratios?

Good reviews of work on Physics Engines are specific, kind and focused on constraints, not on personal style.
