Questions to Ask About High Availability Design in Code Review

Reviewing code that involves High Availability Design is easier with a short list of questions. Keep these in mind as you read the diff.

- Have we avoided this problem: correlated failures?
- Does the code handle the case of online stores correctly?
- Does this change respect redundancy, or does it work around it?
- Would a test catch untested failover if it appeared later?
- Is load balancers used consistently, or are we mixing approaches?
- Have we considered hidden single points of failure?

Good reviews of work on High Availability Design are specific, kind and focused on health checks, not on personal style.
