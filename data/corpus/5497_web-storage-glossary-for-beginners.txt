Web Storage Glossary for Beginners

New words can make Web Storage feel harder than it is. This glossary keeps the key ones in one place.

Web Storage: browser features for keeping small amounts of data on the user's device.
localStorage: a core term, most visible in saving user preferences.
sessionStorage: a core term that beginners often confuse with cookies.
cookies: a core term that connects to IndexedDB.
IndexedDB: a core term worth revisiting after you try a real example.
browser DevTools: a tool commonly used for remembering form drafts.

Come back to this Web Storage list whenever documentation for localForage uses a word you do not recognize.
