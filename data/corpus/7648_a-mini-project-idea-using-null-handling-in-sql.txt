A Mini Project Idea Using NULL Handling in SQL

A small project is the fastest way to make NULL Handling in SQL stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows NULL Handling in SQL at work on optional fields. Keep the scope small enough to finish.

Milestones:
1. Read about three-valued logic and IS NULL.
2. Set up PostgreSQL and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as comparing with equals instead of IS NULL.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover outer joins, or compare SQLite with DBeaver.

Finish by recording what surprised you. Writing it down is how knowledge about NULL Handling in SQL turns into something you can show others.
