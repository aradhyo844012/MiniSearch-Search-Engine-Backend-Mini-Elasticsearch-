Questions to Ask About Hashing vs Encryption in Code Review

Reviewing code that involves Hashing vs Encryption is easier with a short list of questions. Keep these in mind as you read the diff.

- Have we avoided this problem: confusing encoding with encryption?
- Is SHA-256 used consistently, or are we mixing approaches?
- Would a test catch using broken hash functions if it appeared later?
- Does the code handle the case of storing passwords correctly?
- Have we considered encrypting passwords instead of hashing them?
- Does this change respect one-way functions, or does it work around it?

Good reviews of work on Hashing vs Encryption are specific, kind and focused on collision resistance, not on personal style.
