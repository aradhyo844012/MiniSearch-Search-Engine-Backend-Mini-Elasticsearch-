Client-Side Routing Glossary for Beginners

New words can make Client-Side Routing feel harder than it is. This glossary keeps the key ones in one place.

Client-Side Routing: changing the visible page in the browser without a full page reload.
history API: a core term, most visible in single-page apps.
route matching: a core term that beginners often confuse with nested routes.
nested routes: a core term that connects to route guards.
route guards: a core term worth revisiting after you try a real example.
React Router: a tool commonly used for dashboards.

Come back to this Client-Side Routing list whenever documentation for Vue Router uses a word you do not recognize.
