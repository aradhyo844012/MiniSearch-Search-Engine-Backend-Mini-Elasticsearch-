npm and Package Registries Tips from Experienced Engineers

Engineers who work with npm and Package Registries regularly tend to repeat the same advice. Here it is.

1. Reach for npm first, and only then evaluate alternatives such as Yarn.
2. Be careful with this one: unpinned versions.
3. Test the case of installing JavaScript libraries early, before the design hardens.
4. When something behaves strangely, revisit semantic versions before anything else.
5. Write down why you chose npm and Package Registries so the next person understands the decision.

None of these tips needs special equipment, and all of them apply to sharing internal packages as well as to npm and Package Registries in general.
