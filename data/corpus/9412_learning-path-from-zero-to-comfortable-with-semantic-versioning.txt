Learning Path: From Zero to Comfortable with Semantic Versioning

This path is for a learner who has never studied Semantic Versioning before. Move at your own speed.

Stage 1, the basics: read a short definition (Semantic Versioning is a numbering scheme where major, minor and patch numbers signal how much changed) and learn major, minor and patch numbers and breaking changes.

Stage 2, hands-on: install semver.org, follow a tutorial, and build a small example involving publishing libraries.

Stage 3, depth: study pre-release tags and version ranges, then deliberately explore this problem: breaking changes in minor releases.

Stage 4, application: apply Semantic Versioning to declaring dependencies, compare npm semver with release notes, and write up your results.

Stage 5, review: teach Semantic Versioning to someone else, and then move on to Build Systems.
