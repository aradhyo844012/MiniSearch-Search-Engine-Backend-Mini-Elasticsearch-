Idempotency Tips from Experienced Engineers

Engineers who work with Idempotency regularly tend to repeat the same advice. Here it is.

1. Write down why you chose Idempotency so the next person understands the decision.
2. Make sure you can store the result with the key so retries return the same response.
3. Do not skip idempotency keys; everything else builds on it.
4. Be careful with this one: keys that expire too soon.
5. Test the case of payment APIs early, before the design hardens.

None of these tips needs special equipment, and all of them apply to message processing as well.
