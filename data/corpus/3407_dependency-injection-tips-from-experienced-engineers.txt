Dependency Injection Tips from Experienced Engineers

Engineers who work with Dependency Injection regularly tend to repeat the same advice. Here it is.

1. When something behaves strangely, revisit interfaces before anything else.
2. Do not skip constructor injection; everything else builds on it.
3. Write down why you chose Dependency Injection so the next person understands the decision.
4. Make sure you can inject interfaces so tests can use simple fakes.
5. Be careful with this one: hiding too much behind containers.

None of these tips needs special equipment, and all of them apply to swapping implementations as well.
