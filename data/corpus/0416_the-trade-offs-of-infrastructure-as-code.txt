The Trade-offs of Infrastructure as Code

Every design choice has a cost, and Infrastructure as Code is no exception. The term Infrastructure as Code refers to managing servers and cloud resources through version-controlled configuration files. This article explains the idea in plain language and points out where it fits in real projects.

On the positive side, Infrastructure as Code is well suited to recreating environments and reviewing infrastructure changes. On the other hand, it is not free. Keep these risks in mind: manual changes causing drift; hard-coded secrets; huge monolithic configurations. Whether the trade is worth it depends on how much declarative configuration and state matter to your project.
