Debugging Python Asyncio: A Field Guide

When something goes wrong around Python Asyncio, resist the urge to guess. Work through the problem in order.

Step 1: reproduce the problem with the smallest possible example.
Step 2: list the usual suspects: blocking calls inside coroutines, forgetting to await, and mixing threads and event loops carelessly.
Step 3: revisit event loop and coroutines, since misunderstandings there cause many bugs.
Step 4: use asyncio or similar tools to look inside.
Step 5: write a test that fails because of the bug and passes after the fix.

Many bugs involving Python Asyncio in work such as calling many APIs at once come down to the first suspect on the list. Check the simple causes before suspecting anything exotic.

Finally, never call blocking code directly inside a coroutine. It prevents a surprising number of repeat problems.
