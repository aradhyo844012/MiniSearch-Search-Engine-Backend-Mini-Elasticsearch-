Hands-On Tutorial: Getting Started with Database Replication

This hands-on tutorial takes you from zero to a small working experiment with Database Replication. If you build software for long enough, you will run into Database Replication. The term refers to copying data from one database server to others to improve availability and read capacity.

Step 1: Install or open PostgreSQL streaming replication and create a new empty project folder.
Step 2: Read about primary and replica and write down a definition in your own words.
Step 3: Build the smallest possible example that uses replication lag.
Step 4: Add one test or print statement that proves it works.
Step 5: Extend the example to handle a case such as surviving server failures.
Step 6: Break your example on purpose and see what happens. A good experiment: reading stale data from replicas.

Popular tools and libraries include PostgreSQL streaming replication, MySQL replication, and Patroni.

Watch out for these problems: reading stale data from replicas; untested failover plans; and split-brain situations.

Keep experimenting, keep notes, and revisit Database Replication whenever a new project gives you a reason.
