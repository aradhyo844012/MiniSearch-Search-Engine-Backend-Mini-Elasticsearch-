Practice Exercises for Progressive Web Apps

These exercises build real understanding of Progressive Web Apps. Do them in order, and write down your answers.

Exercise 1: Create a small example that deliberately triggers this problem: ignoring platform limitations. Then fix it.
Exercise 2: Write a short paragraph describing Progressive Web Apps and include the term web app manifest.
Exercise 3: Explain how installability and responsive design differ, using a drawing.
Exercise 4: Pick Lighthouse and complete its getting-started tutorial.
Exercise 5: Compare Workbox and PWABuilder for low-bandwidth markets and write down your conclusion.

When you finish, compare your answers with the definition: Progressive Web Apps is web applications that can be installed and work offline like native apps.
