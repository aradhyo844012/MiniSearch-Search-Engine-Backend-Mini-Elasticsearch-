Code Coverage: Core Concepts and Terminology

This page defines the vocabulary you need to read about Code Coverage with confidence. The subject itself is a measure of how much of the code is run by tests.

line coverage: one of the building blocks of Code Coverage. You should be able to explain it in a single sentence before moving on.
branch coverage: one of the building blocks of Code Coverage. You should be able to explain it in a single sentence before moving on.
coverage reports: one of the building blocks of Code Coverage. Documentation for coverage.py usually mentions it early.
thresholds: one of the building blocks of Code Coverage. Documentation for coverage.py usually mentions it early.
