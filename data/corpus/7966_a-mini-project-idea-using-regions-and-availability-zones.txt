A Mini Project Idea Using Regions and Availability Zones

A small project is the fastest way to make Regions and Availability Zones stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Regions and Availability Zones at work on placing services near users. Keep the scope small enough to finish.

Milestones:
1. Read about regions and availability zones.
2. Set up AWS Regions and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as putting everything in one zone.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover surviving data center failures, or compare Azure regions with Google Cloud regions.

Finish by recording what surprised you. Writing it down is how knowledge about Regions and Availability Zones turns into something you can show others.
