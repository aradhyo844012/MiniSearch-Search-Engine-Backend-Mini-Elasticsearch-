A Mini Project Idea Using Makefiles

A small project is the fastest way to make Makefiles stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Makefiles at work on compiling C projects. Keep the scope small enough to finish.

Milestones:
1. Read about targets and prerequisites.
2. Set up GNU Make and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as tabs versus spaces.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover shortcuts for common commands, or compare CMake with a text editor.

Finish by recording what surprised you. Writing it down is how knowledge about Makefiles turns into something you can show others.
