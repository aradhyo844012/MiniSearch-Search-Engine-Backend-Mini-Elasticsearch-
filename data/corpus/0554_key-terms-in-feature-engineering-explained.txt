Key Terms in Feature Engineering Explained

Clear vocabulary makes Feature Engineering much easier to learn, so here are the key terms in plain language. Put simply, Feature Engineering covers creating and transforming input variables so that models can learn from them more easily. Learning it well pays off across many areas of computing.

Results should always be checked on data the model has never seen.

scaling: a key term in Feature Engineering. Practice with a small example to make the meaning stick.
encoding categories: a key term in Feature Engineering. Practice with a small example to make the meaning stick.
interaction features: a key term in Feature Engineering. You will meet it constantly in documentation and in code reviews.
