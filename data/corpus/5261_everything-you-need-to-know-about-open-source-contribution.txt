Everything You Need to Know About Open Source Contribution

This page collects the essentials about Open Source Contribution in one place. In short, Open Source Contribution is helping improve public software projects by fixing bugs, writing documentation or adding features.

Core concepts:
- forks
- pull requests
- issues
- contributing guides

Where it is used:
- building a portfolio
- learning from experienced maintainers
- giving back to tools you use

Common problems:
- opening huge pull requests
- ignoring contribution rules
- expecting instant replies

Tools to know:
- GitHub
- good first issue labels
- Git

Remember this above all: helping repair a shared public library is a good way to picture it, and the best habit is to start with documentation fixes or small bugs.
