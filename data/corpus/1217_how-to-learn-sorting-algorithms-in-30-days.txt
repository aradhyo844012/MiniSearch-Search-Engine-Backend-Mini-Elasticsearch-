How to Learn Sorting Algorithms in 30 Days

You do not need months to become comfortable with Sorting Algorithms. A focused plan of thirty days is enough to build a solid base. If you build software for long enough, you will run into Sorting Algorithms. The term refers to methods for arranging items in a defined order.

Week 1: learn comparison sorts and stability, and write a one-page summary.
Week 2: practice with Python sorted on a small task such as ordering search results.
Week 3: build a mini project around preparing data for binary search.
Week 4: review common mistakes such as assuming every sort is stable, and explain Sorting Algorithms to a friend.

Popular tools and libraries include Python sorted, Java Arrays.sort, and C++ std::sort.

Keep experimenting, keep notes, and revisit Sorting Algorithms whenever a new project gives you a reason.
