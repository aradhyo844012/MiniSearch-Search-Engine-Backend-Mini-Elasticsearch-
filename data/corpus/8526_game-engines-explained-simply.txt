Game Engines Explained Simply

If Game Engines sounds intimidating, relax. It is software frameworks that provide graphics, physics, input and tools for building games, and the idea is simpler than the name suggests.

Think of Game Engines as a fully equipped workshop with the tools for building a game. Keep that picture in mind as you read on.

The vocabulary has four main pieces: scenes, assets, scripting, and build pipelines. You do not need to master them all at once. Start with scenes, then add assets.

You will meet Game Engines in work such as indie games, simulations, and interactive demos.

One practical tip is to build a tiny prototype in two engines before choosing.
