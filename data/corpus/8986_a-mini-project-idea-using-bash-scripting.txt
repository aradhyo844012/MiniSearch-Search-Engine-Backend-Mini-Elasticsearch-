A Mini Project Idea Using Bash Scripting

A small project is the fastest way to make Bash Scripting stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Bash Scripting at work on automating deployments. Keep the scope small enough to finish.

Milestones:
1. Read about variables and conditionals and loops.
2. Set up Bash and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as unquoted variables.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover processing text files, or compare ShellCheck with shfmt.

Finish by recording what surprised you. Writing it down is how knowledge about Bash Scripting turns into something you can show others.
