Learning Path: From Zero to Comfortable with Browser Developer Tools

This path is for a learner who has never studied Browser Developer Tools before. Move at your own speed.

Stage 1, the basics: read a short definition (Browser Developer Tools is built-in browser panels for inspecting, debugging and measuring web pages) and learn the elements panel and the console.

Stage 2, hands-on: install Chrome DevTools, follow a tutorial, and build a small example involving debugging layouts.

Stage 3, depth: study the network panel and the performance profiler, then deliberately explore this problem: editing the page and forgetting to copy the changes.

Stage 4, application: apply Browser Developer Tools to inspecting API calls, compare Firefox Developer Edition with Lighthouse, and write up your results.

Stage 5, review: teach Browser Developer Tools to someone else, and then move on to WebAssembly.
