Regression Testing Tips from Experienced Engineers

Engineers who work with Regression Testing regularly tend to repeat the same advice. Here it is.

1. Be careful with this one: slow suites that nobody runs.
2. Write down why you chose Regression Testing so the next person understands the decision.
3. Make sure you can add a test for every bug you fix.
4. When something behaves strangely, revisit automation before anything else.
5. Do not skip test suites; everything else builds on it.

None of these tips needs special equipment, and all of them apply to verifying bug fixes as well.
