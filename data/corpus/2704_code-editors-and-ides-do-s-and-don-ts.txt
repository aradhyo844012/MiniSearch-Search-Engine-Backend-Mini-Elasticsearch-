Code Editors and IDEs Do's and Don'ts

A quick list of habits for working with Code Editors and IDEs.

Do:
- Learn syntax highlighting before anything else.
- Try VS Code on a small example.
- Make it a habit to learn the shortcuts for the actions you repeat most.
- Test the case of daily development early.

Don't:
- Ignore this: installing too many extensions.
- Ignore this: ignoring keyboard shortcuts.
- Ignore this: relying on autocomplete blindly.
- Adopt Code Editors and IDEs just because it is fashionable.

Most of the Don'ts come from rushing. When you work with Code Editors and IDEs, a little patience with autocomplete pays off more than any clever shortcut.
