A Mini Project Idea Using Probability Basics

A small project is the fastest way to make Probability Basics stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Probability Basics at work on randomized algorithms. Keep the scope small enough to finish.

Milestones:
1. Read about events and conditional probability.
2. Set up Python random and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as confusing independent and exclusive events.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover machine learning, or compare NumPy with simulation notebooks.

Finish by recording what surprised you. Writing it down is how knowledge about Probability Basics turns into something you can show others.
