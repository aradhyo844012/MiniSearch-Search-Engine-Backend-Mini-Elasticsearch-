Questions to Ask About React Hooks in Code Review

Reviewing code that involves React Hooks is easier with a short list of questions. Keep these in mind as you read the diff.

- Does this change respect useState, or does it work around it?
- Have we considered missing dependencies in effects?
- Does the code handle the case of managing form input correctly?
- Have we avoided this problem: stale closures?
- Is React DevTools used consistently, or are we mixing approaches?
- Is useEffect clear to someone reading the code for the first time?

Good reviews of work on React Hooks are specific, kind and focused on dependency arrays, not on personal style.
