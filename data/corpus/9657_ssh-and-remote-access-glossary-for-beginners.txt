SSH and Remote Access Glossary for Beginners

New words can make SSH and Remote Access feel harder than it is. This glossary keeps the key ones in one place.

SSH and Remote Access: a secure protocol for logging in to and controlling remote machines.
key pairs: a core term, most visible in administering servers.
host keys: a core term that beginners often confuse with port forwarding.
port forwarding: a core term that connects to config files.
config files: a core term worth revisiting after you try a real example.
OpenSSH: a tool commonly used for copying files securely.

Come back to this SSH and Remote Access list whenever documentation for ssh-keygen uses a word you do not recognize.
