A Mini Project Idea Using Floating-Point Arithmetic

A small project is the fastest way to make Floating-Point Arithmetic stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Floating-Point Arithmetic at work on scientific computing. Keep the scope small enough to finish.

Milestones:
1. Read about mantissa and exponent and rounding.
2. Set up Python decimal and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as comparing floats with equality.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover graphics, or compare NumPy with IEEE 754 references.

Finish by recording what surprised you. Writing it down is how knowledge about Floating-Point Arithmetic turns into something you can show others.
