Hands-On Tutorial: Getting Started with Database Transactions

This hands-on tutorial takes you from zero to a small working experiment with Database Transactions. If you build software for long enough, you will run into Database Transactions. The term refers to groups of operations that succeed or fail together.

Step 1: Install or open PostgreSQL and create a new empty project folder.
Step 2: Read about atomicity and write down a definition in your own words.
Step 3: Build the smallest possible example that uses consistency.
Step 4: Add one test or print statement that proves it works.
Step 5: Extend the example to handle a case such as transferring money between accounts.
Step 6: Break your example on purpose and see what happens. A good experiment: holding transactions open too long.

Database Transactions and Relational Databases are closely related, so learning both gives a fuller picture of Databases.

Popular tools and libraries include PostgreSQL, SQLAlchemy, and JDBC.

Watch out for these problems: holding transactions open too long; ignoring isolation levels; and forgetting to roll back on errors.

None of this needs special hardware or expensive software. A laptop, curiosity and a few small experiments are enough to get comfortable with Database Transactions.
