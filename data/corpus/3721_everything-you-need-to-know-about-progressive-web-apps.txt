Everything You Need to Know About Progressive Web Apps

This page collects the essentials about Progressive Web Apps in one place. In short, Progressive Web Apps is web applications that can be installed and work offline like native apps.

Core concepts:
- web app manifest
- service worker
- installability
- responsive design

Where it is used:
- offline-friendly tools
- lightweight alternatives to native apps
- low-bandwidth markets

Common problems:
- ignoring platform limitations
- poor offline fallbacks
- heavy first loads

Tools to know:
- Lighthouse
- Workbox
- PWABuilder

Remember this above all: a website that packs its own suitcase so it still works when the network is gone is a good way to picture it, and the best habit is to test the app in airplane mode.
