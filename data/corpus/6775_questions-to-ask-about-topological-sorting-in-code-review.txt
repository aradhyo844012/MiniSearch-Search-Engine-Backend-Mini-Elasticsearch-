Questions to Ask About Topological Sorting in Code Review

Reviewing code that involves Topological Sorting is easier with a short list of questions. Keep these in mind as you read the diff.

- Does this change respect directed acyclic graphs, or does it work around it?
- Have we avoided this problem: mixing up edge directions?
- Is Python graphlib used consistently, or are we mixing approaches?
- Does the code handle the case of build systems correctly?
- Is in-degree counts clear to someone reading the code for the first time?
- Would a test catch assuming the order is unique if it appeared later?

Good reviews of work on Topological Sorting are specific, kind and focused on Kahn's algorithm, not on personal style.
