Questions to Ask About SQL Window Functions in Code Review

Reviewing code that involves SQL Window Functions is easier with a short list of questions. Keep these in mind as you read the diff.

- Is PostgreSQL used consistently, or are we mixing approaches?
- Could we start with ROW_NUMBER and LAG on a small table?
- Have we avoided this problem: slow sorts on huge partitions?
- Would a test catch confusing them with GROUP BY if it appeared later?
- Does this change respect the OVER clause, or does it work around it?
- Does the code handle the case of running totals correctly?

Good reviews of work on SQL Window Functions are specific, kind and focused on ordering, not on personal style.
