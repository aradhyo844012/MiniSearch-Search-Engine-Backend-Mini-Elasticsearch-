Dev Containers Glossary for Beginners

New words can make Dev Containers feel harder than it is. This glossary keeps the key ones in one place.

Dev Containers: containerized development environments that every teammate can start in the same way.
devcontainer.json: a core term, most visible in onboarding new developers.
images: a core term that beginners often confuse with mounted folders.
mounted folders: a core term that connects to extensions.
extensions: a core term worth revisiting after you try a real example.
VS Code Dev Containers: a tool commonly used for matching production tools.

Come back to this Dev Containers list whenever documentation for Docker uses a word you do not recognize.
