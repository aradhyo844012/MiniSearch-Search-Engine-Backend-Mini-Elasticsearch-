A/B Testing: Core Concepts and Terminology

This page defines the vocabulary you need to read about A/B Testing with confidence. The subject itself is an experiment that compares two versions of something to see which performs better.

control and variant: one of the building blocks of A/B Testing. Mixing it up with neighboring terms is a common source of confusion.
random assignment: one of the building blocks of A/B Testing. Documentation for Optimizely usually mentions it early.
metrics: one of the building blocks of A/B Testing. You should be able to explain it in a single sentence before moving on.
sample size: one of the building blocks of A/B Testing. You should be able to explain it in a single sentence before moving on.

Practice using these four terms in sentences about comparing ranking algorithms. If the sentences feel natural, the vocabulary has stuck.
