React Hooks: Core Concepts and Terminology

This page defines the vocabulary you need to read about React Hooks with confidence. The subject itself is functions that let components use state and lifecycle features without writing classes.

useState: one of the building blocks of React Hooks. You should be able to explain it in a single sentence before moving on.
useEffect: one of the building blocks of React Hooks. Mixing it up with neighboring terms is a common source of confusion.
dependency arrays: one of the building blocks of React Hooks. It shows up whenever you work on managing form input.
custom hooks: one of the building blocks of React Hooks. Mixing it up with neighboring terms is a common source of confusion.

Practice using these four terms in sentences about fetching data on load. If the sentences feel natural, the vocabulary has stuck.
