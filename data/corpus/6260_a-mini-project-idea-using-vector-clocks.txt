A Mini Project Idea Using Vector Clocks

A small project is the fastest way to make Vector Clocks stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Vector Clocks at work on detecting concurrent edits. Keep the scope small enough to finish.

Milestones:
1. Read about logical time and per-process counters.
2. Set up Riak and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as clocks that grow with many nodes.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover replicated databases, or compare the Amazon Dynamo paper with CRDT libraries.

Finish by recording what surprised you. Writing it down is how knowledge about Vector Clocks turns into something you can show others.
