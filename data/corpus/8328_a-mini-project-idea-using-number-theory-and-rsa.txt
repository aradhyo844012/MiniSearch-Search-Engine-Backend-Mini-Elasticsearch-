A Mini Project Idea Using Number Theory and RSA

A small project is the fastest way to make Number Theory and RSA stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Number Theory and RSA at work on public key cryptography. Keep the scope small enough to finish.

Milestones:
1. Read about prime numbers and modular arithmetic.
2. Set up Python pow and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as using small primes.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover hash functions, or compare OpenSSL with SageMath.

Finish by recording what surprised you. Writing it down is how knowledge about Number Theory and RSA turns into something you can show others.
