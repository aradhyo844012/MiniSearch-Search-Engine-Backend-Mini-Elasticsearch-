Questions to Ask About Property-Based Testing in Code Review

Reviewing code that involves Property-Based Testing is easier with a short list of questions. Keep these in mind as you read the diff.

- Is generators clear to someone reading the code for the first time?
- Does this change respect properties, or does it work around it?
- Could we save failing examples as regular tests?
- Would a test catch slow generators if it appeared later?
- Does the code handle the case of testing parsers correctly?
- Have we avoided this problem: ignoring random seed reports?

Good reviews of work on Property-Based Testing are specific, kind and focused on shrinking, not on personal style.
