A Mini Project Idea Using systemd Services

A small project is the fastest way to make systemd Services stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows systemd Services at work on starting services at boot. Keep the scope small enough to finish.

Milestones:
1. Read about unit files and targets.
2. Set up systemctl and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as editing unit files without reloading the daemon.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover restarting crashed programs, or compare journalctl with systemd-analyze.

Finish by recording what surprised you. Writing it down is how knowledge about systemd Services turns into something you can show others.
