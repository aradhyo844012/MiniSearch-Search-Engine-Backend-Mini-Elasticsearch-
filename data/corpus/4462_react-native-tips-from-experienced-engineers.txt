React Native Tips from Experienced Engineers

Engineers who work with React Native regularly tend to repeat the same advice. Here it is.

1. Do not skip components; everything else builds on it.
2. When something behaves strangely, revisit native modules before anything else.
3. Write down why you chose React Native so the next person understands the decision.
4. Make sure you can test on real devices for both platforms.
5. Test the case of cross-platform apps early, before the design hardens.

None of these tips needs special equipment, and all of them apply to rapid prototypes as well.
