A Mini Project Idea Using Managed Cloud Databases

A small project is the fastest way to make Managed Cloud Databases stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Managed Cloud Databases at work on launching apps quickly. Keep the scope small enough to finish.

Milestones:
1. Read about automated backups and read replicas.
2. Set up Amazon RDS and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as surprise costs.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover reducing database administration, or compare Cloud SQL with Azure Database.

Finish by recording what surprised you. Writing it down is how knowledge about Managed Cloud Databases turns into something you can show others.
