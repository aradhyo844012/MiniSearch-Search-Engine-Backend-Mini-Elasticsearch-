Combining Technical Writing with Code Editors and IDEs in One Project

Real projects rarely use one idea in isolation. This article shows how Technical Writing and Code Editors and IDEs can work together in a single project.

Technical Writing is explaining technical ideas clearly in writing for a chosen audience. Code Editors and IDEs is tools for writing, navigating and debugging code.

Imagine a project that involves documentation and daily development. Technical Writing brings audience, while Code Editors and IDEs brings syntax highlighting.

A sensible plan is to start with Markdown for the Technical Writing part and VS Code for the Code Editors and IDEs part, and to keep the two sides connected through a small, well-tested interface.

Be prepared for combined risks: burying the main point on one side, and ignoring keyboard shortcuts on the other.

Picture the whole as giving directions to a stranger, working alongside a well-organized workbench.

Two habits help: first, state the main point in the first two sentences; second, learn the shortcuts for the actions you repeat most.
