Reading Documentation for Students: A Study Guide

This study guide prepares you for exams, labs and interviews that cover Reading Documentation.

Learning goals:
1. Explain Reading Documentation in your own words.
2. Describe search, tutorials versus references, examples, and version numbers.
3. Give examples from learning new libraries and solving errors.
4. Name three problems to watch for.

Start with the definition: Reading Documentation is the skill of finding accurate answers in official guides and references. Then draw reading the manual before assembling the furniture on paper and label the four terms from the goals above.

Self-test questions: Why is reading the wrong version a problem? How does tutorials versus references relate to examples? When would you choose MDN Web Docs or the Python docs?

Study habit: check that the documentation version matches your installed version.

When you feel ready, compare Reading Documentation with Open Source Contribution and write down three differences.
