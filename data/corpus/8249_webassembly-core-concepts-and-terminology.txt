WebAssembly: Core Concepts and Terminology

This page defines the vocabulary you need to read about WebAssembly with confidence. The subject itself is a compact binary format that lets code written in many languages run fast in browsers.

modules: one of the building blocks of WebAssembly. It shows up whenever you work on running heavy computation in the browser.

imports and exports: one of the building blocks of WebAssembly. You should be able to explain it in a single sentence before moving on.
