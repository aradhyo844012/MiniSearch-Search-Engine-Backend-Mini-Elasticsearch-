A Mini Project Idea Using Compilers and Interpreters

A small project is the fastest way to make Compilers and Interpreters stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Compilers and Interpreters at work on running Python and JavaScript. Keep the scope small enough to finish.

Milestones:
1. Read about lexing and parsing.
2. Set up GCC and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as assuming interpreted means slow without measuring.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover building native programs, or compare LLVM with CPython.

Finish by recording what surprised you. Writing it down is how knowledge about Compilers and Interpreters turns into something you can show others.
