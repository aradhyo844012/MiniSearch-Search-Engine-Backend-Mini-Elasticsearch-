A Practical Checklist for Python Basics

Use this checklist before you rely on Python Basics in a project.

1. Document your decisions in the project README.
2. Review the core ideas: variables, lists and dictionaries, functions, and modules.
3. Pick a tool to start with, such as Python interpreter or pip.
4. Confirm that your team agrees on what Python Basics should accomplish.
5. Guard against this risk: confusing equality and identity.
6. Ask a teammate to review the work, focusing on lists and dictionaries.
7. Try the approach on a small case, for example scripting.
