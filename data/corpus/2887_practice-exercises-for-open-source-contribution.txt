Practice Exercises for Open Source Contribution

These exercises build real understanding of Open Source Contribution. Do them in order, and write down your answers.

Exercise 1: List three situations from your own experience that resemble building a portfolio or learning from experienced maintainers.
Exercise 2: Pick GitHub and complete its getting-started tutorial.
Exercise 3: Compare good first issue labels and Git for giving back to tools you use and write down your conclusion.
Exercise 4: Create a small example that deliberately triggers this problem: opening huge pull requests. Then fix it.
Exercise 5: Explain how issues and contributing guides differ, using a drawing.

When you finish, compare your answers with the definition: Open Source Contribution is helping improve public software projects by fixing bugs, writing documentation or adding features.
