Browser Developer Tools in 10 Minutes

You have ten minutes, so here is the fast route through Browser Developer Tools.

Minutes 1 and 2, the definition: Browser Developer Tools is built-in browser panels for inspecting, debugging and measuring web pages.

Minutes 3 and 4, the vocabulary: learn the elements panel, the console, the network panel, and the performance profiler.

Minutes 5 and 6, the picture: imagine an X-ray machine for web pages. That is the intuition.

Minutes 7 and 8, the use cases: skim through debugging layouts, inspecting API calls, and finding slow scripts.

Minutes 9 and 10, the traps and the tools: watch for editing the page and forgetting to copy the changes and leaving throttling on, then try Chrome DevTools for a first experiment.

If you have a spare minute, remember to keep the network panel open while testing features.
