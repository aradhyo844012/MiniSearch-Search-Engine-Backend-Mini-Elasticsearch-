A Mini Project Idea Using Garbage Collection

A small project is the fastest way to make Garbage Collection stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Garbage Collection at work on managed languages like Java and Python. Keep the scope small enough to finish.

Milestones:
1. Read about reachability and generations.
2. Set up JVM GC logs and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as creating huge numbers of short-lived objects.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover reducing memory bugs, or compare the Python gc module with VisualVM.

Finish by recording what surprised you. Writing it down is how knowledge about Garbage Collection turns into something you can show others.
