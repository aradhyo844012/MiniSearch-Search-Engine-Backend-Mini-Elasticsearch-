A Mini Project Idea Using Linear Algebra for Programmers

A small project is the fastest way to make Linear Algebra for Programmers stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Linear Algebra for Programmers at work on 3D graphics. Keep the scope small enough to finish.

Milestones:
1. Read about vectors and matrices.
2. Set up NumPy and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as mixing row and column conventions.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover machine learning, or compare MATLAB with the 3Blue1Brown video series.

Finish by recording what surprised you. Writing it down is how knowledge about Linear Algebra for Programmers turns into something you can show others.
