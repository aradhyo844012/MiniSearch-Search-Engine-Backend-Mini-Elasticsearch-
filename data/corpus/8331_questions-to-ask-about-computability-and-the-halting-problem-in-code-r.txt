Questions to Ask About Computability and the Halting Problem in Code Review

Reviewing code that involves Computability and the Halting Problem is easier with a short list of questions. Keep these in mind as you read the diff.

- Would a test catch confusing hard with undecidable if it appeared later?
- Is Turing machine simulators used consistently, or are we mixing approaches?
- Does this change respect Turing machines, or does it work around it?
- Does the code handle the case of understanding the limits of tools correctly?
- Have we avoided this problem: hand-wavy proofs?
- Could we learn the diagonal argument step by step?

Good reviews of work on Computability and the Halting Problem are specific, kind and focused on the halting problem, not on personal style.
