Embedded Systems Glossary for Beginners

New words can make Embedded Systems feel harder than it is. This glossary keeps the key ones in one place.

Embedded Systems: computers built into devices to perform dedicated tasks within tight limits.
microcontrollers: a core term, most visible in appliances.
firmware: a core term that beginners often confuse with real-time constraints.
real-time constraints: a core term that connects to memory limits.
memory limits: a core term worth revisiting after you try a real example.
C: a tool commonly used for medical devices.

Come back to this Embedded Systems list whenever documentation for FreeRTOS uses a word you do not recognize.
