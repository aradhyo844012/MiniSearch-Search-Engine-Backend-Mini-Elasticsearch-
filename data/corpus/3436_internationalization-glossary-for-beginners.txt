Internationalization Glossary for Beginners

New words can make Internationalization feel harder than it is. This glossary keeps the key ones in one place.

Internationalization: designing software so it can be adapted to different languages and regions.
locale detection: a core term, most visible in global products.
translation files: a core term that beginners often confuse with pluralization.
pluralization: a core term that connects to date and number formatting.
date and number formatting: a core term worth revisiting after you try a real example.
i18next: a tool commonly used for multi-language websites.

Come back to this Internationalization list whenever documentation for the Intl API uses a word you do not recognize.
