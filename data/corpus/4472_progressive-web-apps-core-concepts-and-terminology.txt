Progressive Web Apps: Core Concepts and Terminology

This page defines the vocabulary you need to read about Progressive Web Apps with confidence. The subject itself is web applications that can be installed and work offline like native apps.

web app manifest: one of the building blocks of Progressive Web Apps. Documentation for Lighthouse usually mentions it early.
service worker: one of the building blocks of Progressive Web Apps. It shows up whenever you work on offline-friendly tools.
installability: one of the building blocks of Progressive Web Apps. Documentation for Lighthouse usually mentions it early.
responsive design: one of the building blocks of Progressive Web Apps. Documentation for Lighthouse usually mentions it early.

Practice using these four terms in sentences about lightweight alternatives to native apps. If the sentences feel natural, the vocabulary has stuck.
