A Mini Project Idea Using Video Codecs

A small project is the fastest way to make Video Codecs stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Video Codecs at work on streaming services. Keep the scope small enough to finish.

Milestones:
1. Read about frames and motion compensation.
2. Set up FFmpeg and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as mismatched codec support.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover video calls, or compare H.264 with AV1.

Finish by recording what surprised you. Writing it down is how knowledge about Video Codecs turns into something you can show others.
