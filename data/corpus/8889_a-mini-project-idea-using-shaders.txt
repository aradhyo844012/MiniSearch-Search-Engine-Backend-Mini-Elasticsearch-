A Mini Project Idea Using Shaders

A small project is the fastest way to make Shaders stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Shaders at work on lighting effects. Keep the scope small enough to finish.

Milestones:
1. Read about vertex shaders and fragment shaders.
2. Set up GLSL and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as branches that slow the GPU.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover water and fire visuals, or compare Shadertoy with RenderDoc.

Finish by recording what surprised you. Writing it down is how knowledge about Shaders turns into something you can show others.
