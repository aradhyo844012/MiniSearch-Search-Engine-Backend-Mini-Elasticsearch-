Learning Path: From Zero to Comfortable with npm and Package Registries

This path is for a learner who has never studied npm and Package Registries before. Move at your own speed.

Stage 1, the basics: read a short definition (npm and Package Registries is services and tools for publishing and installing reusable code packages) and learn package.json and semantic versions.

Stage 2, hands-on: install npm, follow a tutorial, and build a small example involving installing JavaScript libraries.

Stage 3, depth: study lock files and registries, then deliberately explore this problem: unpinned versions.

Stage 4, application: apply npm and Package Registries to sharing internal packages, compare Yarn with pnpm, and write up your results.

Stage 5, review: teach npm and Package Registries to someone else, and then move on to Code Formatters.
