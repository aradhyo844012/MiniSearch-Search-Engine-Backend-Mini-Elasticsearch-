Questions to Ask About Memory Hierarchy in Code Review

Reviewing code that involves Memory Hierarchy is easier with a short list of questions. Keep these in mind as you read the diff.

- Does this change respect registers, or does it work around it?
- Is lscpu used consistently, or are we mixing approaches?
- Have we considered ignoring locality?
- Could we reduce how often your program goes down to the slower layers?
- Have we avoided this problem: treating all memory accesses as equal?
- Does the code handle the case of designing efficient programs correctly?

Good reviews of work on Memory Hierarchy are specific, kind and focused on main memory, not on personal style.
