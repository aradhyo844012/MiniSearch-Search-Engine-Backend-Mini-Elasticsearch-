Reading Documentation Quick Reference

A one-screen reminder for Reading Documentation. Bookmark it and return when the details fade.

What it is: the skill of finding accurate answers in official guides and references.
Key terms: search, tutorials versus references, examples, and version numbers.
Typical uses: learning new libraries, solving errors, and verifying answers from other sources.
Risks: reading the wrong version, skipping the overview, and copying examples blindly.
Tools: MDN Web Docs, the Python docs, and man pages.

Mental picture: reading the manual before assembling the furniture.

Habit to build: check that the documentation version matches your installed version.
