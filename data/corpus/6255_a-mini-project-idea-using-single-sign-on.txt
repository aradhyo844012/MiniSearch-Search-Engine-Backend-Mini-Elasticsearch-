A Mini Project Idea Using Single Sign-On

A small project is the fastest way to make Single Sign-On stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Single Sign-On at work on company intranets. Keep the scope small enough to finish.

Milestones:
1. Read about identity provider and SAML.
2. Set up Okta and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as a single point of failure.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover reducing password fatigue, or compare Keycloak with Azure AD.

Finish by recording what surprised you. Writing it down is how knowledge about Single Sign-On turns into something you can show others.
