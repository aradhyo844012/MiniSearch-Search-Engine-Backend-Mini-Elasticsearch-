Compilers and Interpreters Glossary for Beginners

New words can make Compilers and Interpreters feel harder than it is. This glossary keeps the key ones in one place.

Compilers and Interpreters: programs that translate or run source code written in a high-level language.
lexing: a core term, most visible in running Python and JavaScript.
parsing: a core term that beginners often confuse with code generation.
code generation: a core term that connects to bytecode.
bytecode: a core term worth revisiting after you try a real example.
GCC: a tool commonly used for building native programs.

Come back to this Compilers and Interpreters list whenever documentation for LLVM uses a word you do not recognize.
