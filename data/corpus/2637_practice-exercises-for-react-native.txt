Practice Exercises for React Native

These exercises build real understanding of React Native. Do them in order, and write down your answers.

Exercise 1: Create a small example that deliberately triggers this problem: heavy re-renders. Then fix it.
Exercise 2: Explain how styling with flexbox and navigation differ, using a drawing.
Exercise 3: List three situations from your own experience that resemble cross-platform apps or rapid prototypes.
Exercise 4: Compare Metro and React Native Debugger for sharing code with web teams and write down your conclusion.
Exercise 5: Pick Expo and complete its getting-started tutorial.

When you finish, compare your answers with the definition: React Native is a framework for building mobile apps for several platforms using JavaScript and React.
