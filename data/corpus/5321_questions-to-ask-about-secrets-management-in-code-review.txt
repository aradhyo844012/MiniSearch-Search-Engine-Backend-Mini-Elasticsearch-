Questions to Ask About Secrets Management in Code Review

Reviewing code that involves Secrets Management is easier with a short list of questions. Keep these in mind as you read the diff.

- Have we considered secrets in source control?
- Would a test catch long-lived shared credentials if it appeared later?
- Is HashiCorp Vault used consistently, or are we mixing approaches?
- Is rotation clear to someone reading the code for the first time?
- Does this change respect vaults, or does it work around it?
- Have we avoided this problem: no rotation plan?

Good reviews of work on Secrets Management are specific, kind and focused on access policies, not on personal style.
