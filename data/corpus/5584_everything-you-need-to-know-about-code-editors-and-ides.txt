Everything You Need to Know About Code Editors and IDEs

This page collects the essentials about Code Editors and IDEs in one place. In short, Code Editors and IDEs is tools for writing, navigating and debugging code.

Core concepts:
- syntax highlighting
- autocomplete
- debugger integration
- extensions

Where it is used:
- daily development
- navigating large codebases
- refactoring

Common problems:
- installing too many extensions
- ignoring keyboard shortcuts
- relying on autocomplete blindly

Tools to know:
- VS Code
- IntelliJ IDEA
- Neovim

Remember this above all: a well-organized workbench is a good way to picture it, and the best habit is to learn the shortcuts for the actions you repeat most.
