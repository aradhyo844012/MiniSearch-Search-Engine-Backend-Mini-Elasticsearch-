Browser Developer Tools Glossary for Beginners

New words can make Browser Developer Tools feel harder than it is. This glossary keeps the key ones in one place.

Browser Developer Tools: built-in browser panels for inspecting, debugging and measuring web pages.
the elements panel: a core term, most visible in debugging layouts.
the console: a core term that beginners often confuse with the network panel.
the network panel: a core term that connects to the performance profiler.
the performance profiler: a core term worth revisiting after you try a real example.
Chrome DevTools: a tool commonly used for inspecting API calls.

Come back to this Browser Developer Tools list whenever documentation for Firefox Developer Edition uses a word you do not recognize.
