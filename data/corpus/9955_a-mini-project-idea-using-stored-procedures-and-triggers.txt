A Mini Project Idea Using Stored Procedures and Triggers

A small project is the fastest way to make Stored Procedures and Triggers stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Stored Procedures and Triggers at work on enforcing rules close to the data. Keep the scope small enough to finish.

Milestones:
1. Read about procedures and triggers.
2. Set up PL/pgSQL and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as hidden logic that surprises developers.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover audit logging, or compare MySQL Workbench with pgTAP.

Finish by recording what surprised you. Writing it down is how knowledge about Stored Procedures and Triggers turns into something you can show others.
