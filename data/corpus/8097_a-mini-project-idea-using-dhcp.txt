A Mini Project Idea Using DHCP

A small project is the fastest way to make DHCP stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows DHCP at work on home and office networks. Keep the scope small enough to finish.

Milestones:
1. Read about leases and address pools.
2. Set up dnsmasq and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as rogue DHCP servers.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover guest Wi-Fi, or compare ISC Kea with Wireshark.

Finish by recording what surprised you. Writing it down is how knowledge about DHCP turns into something you can show others.
