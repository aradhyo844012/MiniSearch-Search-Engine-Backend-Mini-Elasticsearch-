Questions to Ask About Convolutional Neural Networks in Code Review

Reviewing code that involves Convolutional Neural Networks is easier with a short list of questions. Keep these in mind as you read the diff.

- Does the code handle the case of image classification correctly?
- Have we avoided this problem: overly deep models for simple tasks?
- Could we start from a pretrained model?
- Have we considered too little training data?
- Would a test catch ignoring data augmentation if it appeared later?
- Is pooling clear to someone reading the code for the first time?

Good reviews of work on Convolutional Neural Networks are specific, kind and focused on feature maps, not on personal style.
