Random Forests: Core Concepts and Terminology

This page defines the vocabulary you need to read about Random Forests with confidence. The subject itself is ensembles of many decision trees whose predictions are combined.

bagging: one of the building blocks of Random Forests. Mixing it up with neighboring terms is a common source of confusion.
feature randomness: one of the building blocks of Random Forests. Documentation for scikit-learn usually mentions it early.
voting: one of the building blocks of Random Forests. Documentation for scikit-learn usually mentions it early.
out-of-bag error: one of the building blocks of Random Forests. Mixing it up with neighboring terms is a common source of confusion.

Practice using these four terms in sentences about feature importance ranking. If the sentences feel natural, the vocabulary has stuck.
