API Design Principles Glossary for Beginners

New words can make API Design Principles feel harder than it is. This glossary keeps the key ones in one place.

API Design Principles: guidelines for making APIs consistent, predictable and easy to use.
consistent naming: a core term, most visible in public platforms.
clear errors: a core term that beginners often confuse with idempotent operations.
idempotent operations: a core term that connects to documentation.
documentation: a core term worth revisiting after you try a real example.
OpenAPI: a tool commonly used for internal service contracts.

Come back to this API Design Principles list whenever documentation for Postman uses a word you do not recognize.
