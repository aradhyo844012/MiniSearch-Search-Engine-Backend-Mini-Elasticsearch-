Bootstrap Cheat Sheet

Use this page as a quick reminder of the essentials of Bootstrap.

- Definition: a popular front-end toolkit with ready-made layout, components and utilities.
- Core ideas: grid system; components; utility classes; theming variables.
- Use it for: prototypes and dashboards; admin pages; responsive layouts.
- Watch out for: overriding styles with heavy custom CSS; loading unused components; copying markup without understanding it.
- Tools: Bootstrap CDN, Sass variables, Bootstrap Icons.
- Quick tip: write a tiny test for components before building anything large.
- Related topic: Browser Rendering.
