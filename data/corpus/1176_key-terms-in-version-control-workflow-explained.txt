Clear vocabulary makes Version Control Workflow much easier to learn, so here are the key terms in plain language. If you build software for long enough, you will run into Version Control Workflow. The term refers to the habits and rules a team uses to track and combine changes to code.

commits: a key term in Version Control Workflow. You will meet it constantly in documentation and in code reviews.
branches: a key term in Version Control Workflow. You will meet it constantly in documentation and in code reviews.
tags: a key term in Version Control Workflow. It matters because it shapes how you design, test and explain your solution.
release process: a key term in Version Control Workflow. Beginners often confuse it with related terms, so define it in your own words early.
