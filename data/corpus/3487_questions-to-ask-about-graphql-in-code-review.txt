Questions to Ask About GraphQL in Code Review

Reviewing code that involves GraphQL is easier with a short list of questions. Keep these in mind as you read the diff.

- Does this change respect schema, or does it work around it?
- Is queries and mutations clear to someone reading the code for the first time?
- Could we use a data loader to avoid N+1 queries?
- Is Apollo used consistently, or are we mixing approaches?
- Would a test catch unbounded query depth if it appeared later?
- Does the code handle the case of mobile apps with limited bandwidth correctly?

Good reviews of work on GraphQL are specific, kind and focused on resolvers, not on personal style.
