Questions to Ask About Python Decorators in Code Review

Reviewing code that involves Python Decorators is easier with a short list of questions. Keep these in mind as you read the diff.

- Would a test catch stacking decorators in the wrong order if it appeared later?
- Could we always apply functools.wraps inside your decorator?
- Is wrapper functions clear to someone reading the code for the first time?
- Have we avoided this problem: hiding side effects?
- Does this change respect higher-order functions, or does it work around it?
- Is functools used consistently, or are we mixing approaches?

Good reviews of work on Python Decorators are specific, kind and focused on functools.wraps, not on personal style.
