Questions to Ask About Reverse Proxies in Code Review

Reviewing code that involves Reverse Proxies is easier with a short list of questions. Keep these in mind as you read the diff.

- Does the code handle the case of hiding backend servers correctly?
- Have we avoided this problem: exposing internal paths?
- Does this change respect upstream servers, or does it work around it?
- Have we considered losing the client IP address?
- Could we forward the real client IP in a trusted header?
- Is proxy headers clear to someone reading the code for the first time?

Good reviews of work on Reverse Proxies are specific, kind and focused on TLS termination, not on personal style.
