Everything You Need to Know About Endianness

This page collects the essentials about Endianness in one place. In short, Endianness is the order in which a computer stores the bytes of a multi-byte number.

Core concepts:
- big-endian
- little-endian
- byte order marks
- network byte order

Where it is used:
- network protocols
- binary file formats
- cross-platform data exchange

Common problems:
- mixing byte orders
- assuming all machines are alike
- forgetting to convert before sending

Tools to know:
- Python struct
- htons and ntohl
- hexdump

Remember this above all: writing a date as day-month-year or as year-month-day is a good way to picture it, and the best habit is to always specify byte order in file and protocol formats.
