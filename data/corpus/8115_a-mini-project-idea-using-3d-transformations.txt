A Mini Project Idea Using 3D Transformations

A small project is the fastest way to make 3D Transformations stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows 3D Transformations at work on games. Keep the scope small enough to finish.

Milestones:
1. Read about translation and rotation.
2. Set up GLM and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as wrong multiplication order.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover modeling tools, or compare three.js with Blender.

Finish by recording what surprised you. Writing it down is how knowledge about 3D Transformations turns into something you can show others.
