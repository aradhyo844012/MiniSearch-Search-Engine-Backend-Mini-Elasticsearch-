Linux Command Line Cheat Sheet

Use this page as a quick reminder of the essentials of Linux Command Line.

- Definition: a text-based way of controlling a computer using commands and scripts.
- Core ideas: shell; pipes; permissions; environment variables.
- Use it for: automating tasks; managing servers; searching files and logs.
- Watch out for: running destructive commands carelessly; forgetting quotes around paths; ignoring exit codes.
- Tools: bash, grep, ssh.
- Related topic: Deadlocks.
- Quick tip: practice shell until it feels automatic.
