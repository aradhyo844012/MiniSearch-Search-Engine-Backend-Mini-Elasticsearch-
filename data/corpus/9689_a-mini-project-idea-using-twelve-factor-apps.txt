A Mini Project Idea Using Twelve-Factor Apps

A small project is the fastest way to make Twelve-Factor Apps stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Twelve-Factor Apps at work on building web services. Keep the scope small enough to finish.

Milestones:
1. Read about config in the environment and stateless processes.
2. Set up Heroku and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as storing state on local disks.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover deploying to platforms, or compare Docker with Cloud Foundry.

Finish by recording what surprised you. Writing it down is how knowledge about Twelve-Factor Apps turns into something you can show others.
