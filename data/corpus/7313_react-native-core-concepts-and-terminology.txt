React Native: Core Concepts and Terminology

This page defines the vocabulary you need to read about React Native with confidence. The subject itself is a framework for building mobile apps for several platforms using JavaScript and React.

components: one of the building blocks of React Native. You should be able to explain it in a single sentence before moving on.
native modules: one of the building blocks of React Native. Mixing it up with neighboring terms is a common source of confusion.
styling with flexbox: one of the building blocks of React Native. Documentation for Expo usually mentions it early.
navigation: one of the building blocks of React Native. Documentation for Expo usually mentions it early.

Practice using these four terms in sentences about rapid prototypes. If the sentences feel natural, the vocabulary has stuck.
