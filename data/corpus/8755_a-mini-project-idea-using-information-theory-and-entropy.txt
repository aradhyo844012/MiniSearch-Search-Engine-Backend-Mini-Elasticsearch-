A Mini Project Idea Using Information Theory and Entropy

A small project is the fastest way to make Information Theory and Entropy stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Information Theory and Entropy at work on data compression. Keep the scope small enough to finish.

Milestones:
1. Read about bits and entropy.
2. Set up the Python math module and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as confusing information with meaning.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover error-correcting codes, or compare NumPy with zlib.

Finish by recording what surprised you. Writing it down is how knowledge about Information Theory and Entropy turns into something you can show others.
