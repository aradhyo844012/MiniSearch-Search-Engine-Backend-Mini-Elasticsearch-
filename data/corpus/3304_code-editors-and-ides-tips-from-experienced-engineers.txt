Code Editors and IDEs Tips from Experienced Engineers

Engineers who work with Code Editors and IDEs regularly tend to repeat the same advice. Here it is.

1. Make sure you can learn the shortcuts for the actions you repeat most.
2. Test the case of daily development early, before the design hardens.
3. Write down why you chose Code Editors and IDEs so the next person understands the decision.
4. Be careful with this one: installing too many extensions.
5. When something behaves strangely, revisit autocomplete before anything else.

None of these tips needs special equipment, and all of them apply to navigating large codebases as well.
