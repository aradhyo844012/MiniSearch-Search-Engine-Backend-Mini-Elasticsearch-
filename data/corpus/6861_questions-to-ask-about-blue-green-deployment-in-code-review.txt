Questions to Ask About Blue-Green Deployment in Code Review

Reviewing code that involves Blue-Green Deployment is easier with a short list of questions. Keep these in mind as you read the diff.

- Could we keep the old environment running until the new one is proven?
- Is AWS CodeDeploy used consistently, or are we mixing approaches?
- Have we avoided this problem: forgetting to drain old connections?
- Is traffic switching clear to someone reading the code for the first time?
- Have we considered database schema mismatches?
- Would a test catch doubling infrastructure costs if it appeared later?

Good reviews of work on Blue-Green Deployment are specific, kind and focused on rollback, not on personal style.
