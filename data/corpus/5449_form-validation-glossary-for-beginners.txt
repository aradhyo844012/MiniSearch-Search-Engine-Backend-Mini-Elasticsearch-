Form Validation Glossary for Beginners

New words can make Form Validation feel harder than it is. This glossary keeps the key ones in one place.

Form Validation: checking user input for correctness before it is accepted.
client-side checks: a core term, most visible in sign-up forms.
server-side checks: a core term that beginners often confuse with error messages.
error messages: a core term that connects to constraint attributes.
constraint attributes: a core term worth revisiting after you try a real example.
HTML constraint validation: a tool commonly used for payment pages.

Come back to this Form Validation list whenever documentation for Zod uses a word you do not recognize.
