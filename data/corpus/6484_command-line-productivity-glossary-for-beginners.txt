Command Line Productivity Glossary for Beginners

New words can make Command Line Productivity feel harder than it is. This glossary keeps the key ones in one place.

Command Line Productivity: using shell tools and shortcuts to complete tasks faster.
aliases: a core term, most visible in automating repetitive tasks.
pipes: a core term that beginners often confuse with history search.
history search: a core term that connects to scripts.
scripts: a core term worth revisiting after you try a real example.
bash: a tool commonly used for exploring files and logs.

Come back to this Command Line Productivity list whenever documentation for tmux uses a word you do not recognize.
