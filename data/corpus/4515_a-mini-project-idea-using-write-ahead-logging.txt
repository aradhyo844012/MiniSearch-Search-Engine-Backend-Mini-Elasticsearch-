A Mini Project Idea Using Write-Ahead Logging

A small project is the fastest way to make Write-Ahead Logging stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Write-Ahead Logging at work on surviving crashes. Keep the scope small enough to finish.

Milestones:
1. Read about log records and checkpoints.
2. Set up PostgreSQL WAL and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as disabling fsync for speed.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover feeding replication streams, or compare SQLite journal with Apache Kafka.

Finish by recording what surprised you. Writing it down is how knowledge about Write-Ahead Logging turns into something you can show others.
