Debugging React Hooks: A Field Guide

When something goes wrong around React Hooks, resist the urge to guess. Work through the problem in order.

Step 1: reproduce the problem with the smallest possible example.
Step 2: list the usual suspects: missing dependencies in effects, calling hooks conditionally, and stale closures.
Step 3: revisit useState and useEffect, since misunderstandings there cause many bugs.
Step 4: use React DevTools or similar tools to look inside.
Step 5: write a test that fails because of the bug and passes after the fix.

Many bugs involving React Hooks in work such as managing form input come down to the first suspect on the list. Check the simple causes before suspecting anything exotic.

Finally, enable the hooks lint rules from the start. It prevents a surprising number of repeat problems.
