A Mini Project Idea Using Interrupts

A small project is the fastest way to make Interrupts stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Interrupts at work on keyboard and mouse input. Keep the scope small enough to finish.

Milestones:
1. Read about interrupt handlers and interrupt vectors.
2. Set up Linux /proc/interrupts and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as long handlers.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover timers, or compare logic analyzers with embedded debuggers.

Finish by recording what surprised you. Writing it down is how knowledge about Interrupts turns into something you can show others.
