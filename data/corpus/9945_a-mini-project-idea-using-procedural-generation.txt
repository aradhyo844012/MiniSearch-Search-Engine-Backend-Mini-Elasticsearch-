A Mini Project Idea Using Procedural Generation

A small project is the fastest way to make Procedural Generation stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Procedural Generation at work on roguelike dungeons. Keep the scope small enough to finish.

Milestones:
1. Read about random seeds and noise functions.
2. Set up Perlin noise and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as levels that are unfair or unwinnable.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover infinite terrain, or compare Wave Function Collapse with Unity.

Finish by recording what surprised you. Writing it down is how knowledge about Procedural Generation turns into something you can show others.
