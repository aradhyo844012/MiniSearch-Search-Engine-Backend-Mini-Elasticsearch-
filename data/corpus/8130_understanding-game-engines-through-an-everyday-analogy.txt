Understanding Game Engines Through an Everyday Analogy

Abstract ideas are easier to hold onto when you attach them to something familiar. So picture a fully equipped workshop with the tools for building a game.

In that picture, scenes is the first rule you follow, assets is the next step, and scripting and build pipelines keep everything running smoothly.

Every analogy breaks down eventually. Real Game Engines is software frameworks that provide graphics, physics, input and tools for building games, and it involves details such as choosing an engine by hype that no everyday picture captures.

Use the analogy to remember the shape of the idea, and use documentation for Unity to learn the exact behavior. The same picture helps when you explain indie games to a friend.
