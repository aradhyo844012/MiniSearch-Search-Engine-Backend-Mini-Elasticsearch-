Code Editors and IDEs Glossary for Beginners

New words can make Code Editors and IDEs feel harder than it is. This glossary keeps the key ones in one place.

Code Editors and IDEs: tools for writing, navigating and debugging code.
syntax highlighting: a core term, most visible in daily development.
autocomplete: a core term that beginners often confuse with debugger integration.
debugger integration: a core term that connects to extensions.
extensions: a core term worth revisiting after you try a real example.
VS Code: a tool commonly used for navigating large codebases.

Come back to this Code Editors and IDEs list whenever documentation for IntelliJ IDEA uses a word you do not recognize.
