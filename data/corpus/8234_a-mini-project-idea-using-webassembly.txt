A Mini Project Idea Using WebAssembly

A small project is the fastest way to make WebAssembly stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows WebAssembly at work on running heavy computation in the browser. Keep the scope small enough to finish.

Milestones:
1. Read about modules and linear memory.
2. Set up Emscripten and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as crossing the JavaScript boundary too often.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover porting existing C or Rust code, or compare wasm-pack with Wasmtime.

Finish by recording what surprised you. Writing it down is how knowledge about WebAssembly turns into something you can show others.
