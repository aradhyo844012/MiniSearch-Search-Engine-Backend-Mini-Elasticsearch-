Learning Path: From Zero to Comfortable with React Native

This path is for a learner who has never studied React Native before. Move at your own speed.

Stage 1, the basics: read a short definition (React Native is a framework for building mobile apps for several platforms using JavaScript and React) and learn components and native modules.

Stage 2, hands-on: install Expo, follow a tutorial, and build a small example involving cross-platform apps.

Stage 3, depth: study styling with flexbox and navigation, then deliberately explore this problem: heavy re-renders.

Stage 4, application: apply React Native to rapid prototypes, compare Metro with React Native Debugger, and write up your results.

Stage 5, review: teach React Native to someone else, and then move on to Flutter.
