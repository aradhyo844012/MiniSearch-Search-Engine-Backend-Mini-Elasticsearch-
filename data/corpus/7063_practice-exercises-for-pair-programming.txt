Practice Exercises for Pair Programming

These exercises build real understanding of Pair Programming. Do them in order, and write down your answers.

Exercise 1: List three situations from your own experience that resemble teaching new teammates or solving hard bugs.
Exercise 2: Explain how communication and shared ownership differ, using a drawing.
Exercise 3: Write a short paragraph describing Pair Programming and include the term driver and navigator.
Exercise 4: Create a small example that deliberately triggers this problem: one person dominating. Then fix it.
Exercise 5: Pick VS Code Live Share and complete its getting-started tutorial.

When you finish, compare your answers with the definition: Pair Programming is two developers working together at one computer on the same code.
