Learning Path: From Zero to Comfortable with Data Quality Checks

This path is for a learner who has never studied Data Quality Checks before. Move at your own speed.

Stage 1, the basics: read a short definition (Data Quality Checks is automated tests that verify data is complete, valid and consistent) and learn null checks and uniqueness.

Stage 2, hands-on: install Great Expectations, follow a tutorial, and build a small example involving protecting dashboards.

Stage 3, depth: study freshness and schema validation, then deliberately explore this problem: alerts nobody reads.

Stage 4, application: apply Data Quality Checks to validating ingestion, compare dbt tests with Deequ, and write up your results.

Stage 5, review: teach Data Quality Checks to someone else, and then move on to Data Anonymization.
