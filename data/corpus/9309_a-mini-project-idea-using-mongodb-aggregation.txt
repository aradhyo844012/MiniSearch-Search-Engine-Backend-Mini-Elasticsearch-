A Mini Project Idea Using MongoDB Aggregation

A small project is the fastest way to make MongoDB Aggregation stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows MongoDB Aggregation at work on summarizing orders. Keep the scope small enough to finish.

Milestones:
1. Read about pipeline stages and $match and $group.
2. Set up MongoDB Compass and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as putting $match late.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover building analytics queries, or compare mongosh with PyMongo.

Finish by recording what surprised you. Writing it down is how knowledge about MongoDB Aggregation turns into something you can show others.
