A Mini Project Idea Using Font Rendering

A small project is the fastest way to make Font Rendering stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Font Rendering at work on web pages. Keep the scope small enough to finish.

Milestones:
1. Read about glyphs and hinting.
2. Set up FreeType and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as missing font fallbacks.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover operating systems, or compare Google Fonts with font inspector tools.

Finish by recording what surprised you. Writing it down is how knowledge about Font Rendering turns into something you can show others.
