Learning Path: From Zero to Comfortable with Managed Cloud Databases

This path is for a learner who has never studied Managed Cloud Databases before. Move at your own speed.

Stage 1, the basics: read a short definition (Managed Cloud Databases is database services where the cloud provider handles backups, patching and failover) and learn automated backups and read replicas.

Stage 2, hands-on: install Amazon RDS, follow a tutorial, and build a small example involving launching apps quickly.

Stage 3, depth: study maintenance windows and scaling options, then deliberately explore this problem: surprise costs.

Stage 4, application: apply Managed Cloud Databases to reducing database administration, compare Cloud SQL with Azure Database, and write up your results.

Stage 5, review: teach Managed Cloud Databases to someone else, and then move on to Virtual Private Clouds.
