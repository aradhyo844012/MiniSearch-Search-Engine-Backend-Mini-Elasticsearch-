A Mini Project Idea Using Game AI Behavior Trees

A small project is the fastest way to make Game AI Behavior Trees stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Game AI Behavior Trees at work on enemy behavior. Keep the scope small enough to finish.

Milestones:
1. Read about selector nodes and sequence nodes.
2. Set up Unreal Engine behavior trees and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as trees that become tangled.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover companion characters, or compare py_trees with Behavior Designer.

Finish by recording what surprised you. Writing it down is how knowledge about Game AI Behavior Trees turns into something you can show others.
