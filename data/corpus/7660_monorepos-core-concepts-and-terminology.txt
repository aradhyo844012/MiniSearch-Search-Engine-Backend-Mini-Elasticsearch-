Monorepos: Core Concepts and Terminology

This page defines the vocabulary you need to read about Monorepos with confidence. The subject itself is single repositories that hold the code for many projects.

shared tooling: one of the building blocks of Monorepos. Mixing it up with neighboring terms is a common source of confusion.
