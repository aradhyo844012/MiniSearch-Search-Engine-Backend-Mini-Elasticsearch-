A Mini Project Idea Using Pair Programming

A small project is the fastest way to make Pair Programming stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Pair Programming at work on teaching new teammates. Keep the scope small enough to finish.

Milestones:
1. Read about driver and navigator and rotation.
2. Set up VS Code Live Share and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as one person dominating.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover solving hard bugs, or compare Tuple with shared terminals.

Finish by recording what surprised you. Writing it down is how knowledge about Pair Programming turns into something you can show others.
