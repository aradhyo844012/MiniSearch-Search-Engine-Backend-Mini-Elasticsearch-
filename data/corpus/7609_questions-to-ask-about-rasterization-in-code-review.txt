Questions to Ask About Rasterization in Code Review

Reviewing code that involves Rasterization is easier with a short list of questions. Keep these in mind as you read the diff.

- Have we considered aliasing along edges?
- Does this change respect triangles, or does it work around it?
- Could we draw simple shapes first to understand the pipeline?
- Does the code handle the case of real-time games correctly?
- Would a test catch overdraw if it appeared later?
- Is OpenGL used consistently, or are we mixing approaches?

Good reviews of work on Rasterization are specific, kind and focused on the depth buffer, not on personal style.
