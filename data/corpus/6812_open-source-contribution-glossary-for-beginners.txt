Open Source Contribution Glossary for Beginners

New words can make Open Source Contribution feel harder than it is. This glossary keeps the key ones in one place.

Open Source Contribution: helping improve public software projects by fixing bugs, writing documentation or adding features.
forks: a core term, most visible in building a portfolio.
pull requests: a core term that beginners often confuse with issues.
issues: a core term that connects to contributing guides.
contributing guides: a core term worth revisiting after you try a real example.
GitHub: a tool commonly used for learning from experienced maintainers.

Come back to this Open Source Contribution list whenever documentation for good first issue labels uses a word you do not recognize.
