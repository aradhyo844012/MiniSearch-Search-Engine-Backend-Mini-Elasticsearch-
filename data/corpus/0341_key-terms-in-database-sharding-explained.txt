Key Terms in Database Sharding Explained

Clear vocabulary makes Database Sharding much easier to learn, so here are the key terms in plain language. When people talk about Database Sharding, they usually mean splitting a large dataset across several databases so each holds only part of it. It appears in almost every serious software project, whether or not developers notice it.

shard keys: a key term in Database Sharding. You will meet it constantly in documentation and in code reviews.
routing: a key term in Database Sharding. Practice with a small example to make the meaning stick.
rebalancing: a key term in Database Sharding. Beginners often confuse it with related terms, so define it in your own words early.
cross-shard queries: a key term in Database Sharding. Practice with a small example to make the meaning stick.

With steady practice, Database Sharding will stop feeling abstract and become a tool you reach for naturally.
