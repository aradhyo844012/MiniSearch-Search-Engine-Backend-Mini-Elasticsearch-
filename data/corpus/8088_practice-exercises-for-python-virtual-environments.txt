Practice Exercises for Python Virtual Environments

These exercises build real understanding of Python Virtual Environments. Do them in order, and write down your answers.

Exercise 1: Pick venv and complete its getting-started tutorial.
Exercise 2: Compare pipx and Poetry for testing against different versions and write down your conclusion.
Exercise 3: Write a short paragraph describing Python Virtual Environments and include the term venv.
Exercise 4: List three situations from your own experience that resemble keeping projects separate or reproducing setups.
Exercise 5: Create a small example that deliberately triggers this problem: installing packages globally. Then fix it.

When you finish, compare your answers with the definition: Python Virtual Environments is isolated folders that hold a project's own Python packages.
