Open Source Contribution for Students: A Study Guide

This study guide prepares you for exams, labs and interviews that cover Open Source Contribution.

Learning goals:
1. Explain Open Source Contribution in your own words.
2. Describe forks, pull requests, issues, and contributing guides.
3. Give examples from building a portfolio and learning from experienced maintainers.
4. Name three problems to watch for.

Start with the definition: Open Source Contribution is helping improve public software projects by fixing bugs, writing documentation or adding features. Then draw helping repair a shared public library on paper and label the four terms from the goals above.

Self-test questions: Why is opening huge pull requests a problem? How does pull requests relate to issues? When would you choose GitHub or good first issue labels?

Study habit: start with documentation fixes or small bugs.

When you feel ready, compare Open Source Contribution with Reading Documentation and write down three differences.
