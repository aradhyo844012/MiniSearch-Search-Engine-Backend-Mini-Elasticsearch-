Test-Driven Development Glossary for Beginners

New words can make Test-Driven Development feel harder than it is. This glossary keeps the key ones in one place.

Test-Driven Development: a workflow where you write a failing test first and then write code to make it pass.
red, green, refactor: a core term, most visible in designing small modules.
small steps: a core term that beginners often confuse with test first.
test first: a core term that connects to fast feedback.
fast feedback: a core term worth revisiting after you try a real example.
pytest: a tool commonly used for preventing regressions.

Come back to this Test-Driven Development list whenever documentation for JUnit uses a word you do not recognize.
