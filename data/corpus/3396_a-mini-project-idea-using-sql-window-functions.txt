A Mini Project Idea Using SQL Window Functions

A small project is the fastest way to make SQL Window Functions stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows SQL Window Functions at work on running totals. Keep the scope small enough to finish.

Milestones:
1. Read about the OVER clause and partitions.
2. Set up PostgreSQL and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as forgetting ORDER BY inside the window.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover ranking rows, or compare SQLite with BigQuery.

Finish by recording what surprised you. Writing it down is how knowledge about SQL Window Functions turns into something you can show others.
