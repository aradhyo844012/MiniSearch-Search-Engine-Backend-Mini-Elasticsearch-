Statistical Significance: Core Concepts and Terminology

This page defines the vocabulary you need to read about Statistical Significance with confidence. The subject itself is a measure of how unlikely a result would be if there were no real effect.

p-values: one of the building blocks of Statistical Significance. It shows up whenever you work on judging experiment results.
the null hypothesis: one of the building blocks of Statistical Significance. Documentation for SciPy usually mentions it early.
confidence intervals: one of the building blocks of Statistical Significance. It shows up whenever you work on judging experiment results.
effect size: one of the building blocks of Statistical Significance. Mixing it up with neighboring terms is a common source of confusion.

Practice using these four terms in sentences about comparing model performance. If the sentences feel natural, the vocabulary has stuck.
