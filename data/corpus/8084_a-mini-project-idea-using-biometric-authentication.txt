A Mini Project Idea Using Biometric Authentication

A small project is the fastest way to make Biometric Authentication stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Biometric Authentication at work on phone unlock. Keep the scope small enough to finish.

Milestones:
1. Read about enrollment and matching.
2. Set up Android BiometricPrompt and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as spoofing attacks.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover building access, or compare Face ID APIs with FIDO2.

Finish by recording what surprised you. Writing it down is how knowledge about Biometric Authentication turns into something you can show others.
