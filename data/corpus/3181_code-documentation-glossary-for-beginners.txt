Code Documentation Glossary for Beginners

New words can make Code Documentation feel harder than it is. This glossary keeps the key ones in one place.

Code Documentation: written explanations that help others understand and use code.
README files: a core term, most visible in onboarding new developers.
docstrings: a core term that beginners often confuse with architecture notes.
architecture notes: a core term that connects to examples.
examples: a core term worth revisiting after you try a real example.
Sphinx: a tool commonly used for describing APIs.

Come back to this Code Documentation list whenever documentation for MkDocs uses a word you do not recognize.
