Progressive Web Apps Glossary for Beginners

New words can make Progressive Web Apps feel harder than it is. This glossary keeps the key ones in one place.

Progressive Web Apps: web applications that can be installed and work offline like native apps.
web app manifest: a core term, most visible in offline-friendly tools.
service worker: a core term that beginners often confuse with installability.
installability: a core term that connects to responsive design.
responsive design: a core term worth revisiting after you try a real example.
Lighthouse: a tool commonly used for lightweight alternatives to native apps.

Come back to this Progressive Web Apps list whenever documentation for Workbox uses a word you do not recognize.
