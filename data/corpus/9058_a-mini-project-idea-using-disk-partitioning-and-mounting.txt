A Mini Project Idea Using Disk Partitioning and Mounting

A small project is the fastest way to make Disk Partitioning and Mounting stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Disk Partitioning and Mounting at work on adding a new drive. Keep the scope small enough to finish.

Milestones:
1. Read about partitions and file system types.
2. Set up lsblk and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as wrong device names.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover separating data from the system, or compare fdisk with mount.

Finish by recording what surprised you. Writing it down is how knowledge about Disk Partitioning and Mounting turns into something you can show others.
