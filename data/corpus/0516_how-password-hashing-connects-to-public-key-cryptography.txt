How Password Hashing Connects to Public Key Cryptography

Password Hashing and Public Key Cryptography are closely connected parts of Security. Seeing how they fit together helps you learn both faster.

A project involving user login systems may also involve HTTPS. In such a project, salts and key pairs often influence each other.

Start with Password Hashing: the term refers to storing passwords as one-way hashes so the originals are never kept. Then look at Public Key Cryptography, which refers to encryption that uses a pair of keys, one public and one private.

A useful exercise is to take one example, such as protecting data after a breach, and explain how digital signatures would change the design.

Common problems are shared too. For Password Hashing, watch for this: reusing salts. For Public Key Cryptography, watch for this: trusting unverified keys. Security is a habit applied throughout development, not a feature added at the end.

Spend a few hours on each topic, then combine them in one small project using bcrypt or OpenSSL.
