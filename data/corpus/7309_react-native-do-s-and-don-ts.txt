React Native Do's and Don'ts

A quick list of habits for working with React Native.

Do:
- Learn components before anything else.
- Try Expo on a small example.
- Make it a habit to test on real devices for both platforms.
- Test the case of cross-platform apps early.

Don't:
- Ignore this: heavy re-renders.
- Ignore this: poorly tuned lists.
- Ignore this: relying on outdated native modules.
- Adopt React Native just because it is fashionable.

Most of the Don'ts come from rushing. When you work with React Native, a little patience with native modules pays off more than any clever shortcut.
