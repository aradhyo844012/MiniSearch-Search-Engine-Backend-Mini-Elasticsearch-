CSS Variables Glossary for Beginners

New words can make CSS Variables feel harder than it is. This glossary keeps the key ones in one place.

CSS Variables: custom properties that store values such as colors and spacing so they can be reused across styles.
custom properties: a core term, most visible in theme switching.
the var function: a core term that beginners often confuse with inheritance.
inheritance: a core term that connects to fallback values.
fallback values: a core term worth revisiting after you try a real example.
browser DevTools: a tool commonly used for design systems.

Come back to this CSS Variables list whenever documentation for Sass uses a word you do not recognize.
