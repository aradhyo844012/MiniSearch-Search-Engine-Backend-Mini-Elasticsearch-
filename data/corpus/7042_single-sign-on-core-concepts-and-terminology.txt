Single Sign-On: Core Concepts and Terminology

This page defines the vocabulary you need to read about Single Sign-On with confidence. The subject itself is letting users log in once and access several applications.

identity provider: one of the building blocks of Single Sign-On. You should be able to explain it in a single sentence before moving on.
SAML: one of the building blocks of Single Sign-On. It shows up whenever you work on company intranets.
OpenID Connect: one of the building blocks of Single Sign-On. It shows up whenever you work on company intranets.
session lifetime: one of the building blocks of Single Sign-On. Documentation for Okta usually mentions it early.

Practice using these four terms in sentences about reducing password fatigue. If the sentences feel natural, the vocabulary has stuck.
