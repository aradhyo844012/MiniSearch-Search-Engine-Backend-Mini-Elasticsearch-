Combining Python Asyncio with Go Goroutines in One Project

Real projects rarely use one idea in isolation. This article shows how Python Asyncio and Go Goroutines can work together in a single project.

Python Asyncio is a library for running many waiting tasks concurrently on a single thread. Go Goroutines is lightweight threads managed by the Go runtime that run functions concurrently.

Imagine a project that involves calling many APIs at once and servers handling many connections. Python Asyncio brings event loop, while Go Goroutines brings goroutines.

A sensible plan is to start with asyncio for the Python Asyncio part and the go command for the Go Goroutines part, and to keep the two sides connected through a small, well-tested interface.

Be prepared for combined risks: forgetting to await on one side, and data races on the other.

Picture the whole as a chef who starts several dishes and checks each one when its timer rings, working alongside a small crew of waiters passing notes through a serving hatch.

Two habits help: first, never call blocking code directly inside a coroutine; second, run your tests with the race detector turned on.
