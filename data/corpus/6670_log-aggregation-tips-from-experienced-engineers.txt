Log Aggregation Tips from Experienced Engineers

Engineers who work with Log Aggregation regularly tend to repeat the same advice. Here it is.

1. Be careful with this one: unbounded storage growth.
2. Write down why you chose Log Aggregation so the next person understands the decision.
3. Do not skip shippers; everything else builds on it.
4. Make sure you can use structured JSON logs so that fields are searchable.
5. When something behaves strangely, revisit indexing before anything else.

None of these tips needs special equipment, and all of them apply to security investigations as well.
