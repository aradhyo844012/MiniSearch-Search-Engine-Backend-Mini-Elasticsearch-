A Mini Project Idea Using Canary Releases

A small project is the fastest way to make Canary Releases stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Canary Releases at work on safer releases. Keep the scope small enough to finish.

Milestones:
1. Read about traffic percentages and health metrics.
2. Set up Argo Rollouts and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as too little traffic to reveal problems.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover testing with real traffic, or compare Istio with Flagger.

Finish by recording what surprised you. Writing it down is how knowledge about Canary Releases turns into something you can show others.
