How to Learn CSS Flexbox and Grid in 30 Days

You do not need months to become comfortable with CSS Flexbox and Grid. A focused plan of thirty days is enough to build a solid base. If you build software for long enough, you will run into CSS Flexbox and Grid. The term refers to two layout systems that arrange elements in rows, columns and two-dimensional grids.

Week 1: learn flex containers and grid tracks, and write a one-page summary.
Week 2: practice with browser grid inspector on a small task such as navigation bars.
Week 3: build a mini project around card layouts.
Week 4: review common mistakes such as mixing up main and cross axes, and explain CSS Flexbox and Grid to a friend.

Popular tools and libraries include browser grid inspector, Bootstrap utilities, and CSS-Tricks guides.

In short, careful study of CSS Flexbox and Grid pays off. Spend time on flex containers and grid tracks, and the rest will follow.
