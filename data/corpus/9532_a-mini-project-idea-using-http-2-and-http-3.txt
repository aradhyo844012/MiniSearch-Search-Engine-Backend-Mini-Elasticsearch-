A Mini Project Idea Using HTTP/2 and HTTP/3

A small project is the fastest way to make HTTP/2 and HTTP/3 stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows HTTP/2 and HTTP/3 at work on faster page loads. Keep the scope small enough to finish.

Milestones:
1. Read about multiplexing and header compression.
2. Set up curl with HTTP/3 support and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as assuming old tricks like sprite sheets still help.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover improving mobile performance, or compare Chrome DevTools with NGINX.

Finish by recording what surprised you. Writing it down is how knowledge about HTTP/2 and HTTP/3 turns into something you can show others.
