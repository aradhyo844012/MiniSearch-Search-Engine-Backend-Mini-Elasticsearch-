How Agile and Scrum Connects to Clean Code

Agile and Scrum and Clean Code are closely connected parts of Software Engineering. Seeing how they fit together helps you learn both faster.

A project involving student team projects may also involve team projects. In such a project, sprints and meaningful names often influence each other.

Start with Agile and Scrum: the term refers to iterative ways of planning and delivering software in short cycles. Then look at Clean Code, which refers to writing code that other people can read, understand and change easily.

A useful exercise is to take one example, such as product development, and explain how small functions would change the design.

Common problems are shared too. For Agile and Scrum, watch for this: overloading sprints. For Clean Code, watch for this: functions that do too much. Readable code saves more time than clever code over the long run.

Spend a few hours on each topic, then combine them in one small project using Jira or linters.
