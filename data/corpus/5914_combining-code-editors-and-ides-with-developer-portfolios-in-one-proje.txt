Combining Code Editors and IDEs with Developer Portfolios in One Project

Real projects rarely use one idea in isolation. This article shows how Code Editors and IDEs and Developer Portfolios can work together in a single project.

Code Editors and IDEs is tools for writing, navigating and debugging code. Developer Portfolios is a collection of projects and writing that shows what a developer can build.

Imagine a project that involves daily development and applying for internships. Code Editors and IDEs brings syntax highlighting, while Developer Portfolios brings projects.

A sensible plan is to start with VS Code for the Code Editors and IDEs part and GitHub Pages for the Developer Portfolios part, and to keep the two sides connected through a small, well-tested interface.

Be prepared for combined risks: ignoring keyboard shortcuts on one side, and no explanation of decisions on the other.

Picture the whole as a well-organized workbench, working alongside a shop window displaying your best work.

Two habits help: first, learn the shortcuts for the actions you repeat most; second, feature a few polished projects rather than many half-finished ones.
