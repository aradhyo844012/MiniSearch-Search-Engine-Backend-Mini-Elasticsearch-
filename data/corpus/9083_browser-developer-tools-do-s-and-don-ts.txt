Browser Developer Tools Do's and Don'ts

A quick list of habits for working with Browser Developer Tools.

Do:
- Learn the elements panel before anything else.
- Try Chrome DevTools on a small example.
- Make it a habit to keep the network panel open while testing features.
- Test the case of debugging layouts early.

Don't:
- Ignore this: editing the page and forgetting to copy the changes.
- Ignore this: leaving throttling on.
- Ignore this: ignoring console warnings.
- Adopt Browser Developer Tools just because it is fashionable.

Most of the Don'ts come from rushing. When you work with Browser Developer Tools, a little patience with the console pays off more than any clever shortcut.
