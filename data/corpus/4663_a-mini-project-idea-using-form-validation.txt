A Mini Project Idea Using Form Validation

A small project is the fastest way to make Form Validation stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Form Validation at work on sign-up forms. Keep the scope small enough to finish.

Milestones:
1. Read about client-side checks and server-side checks.
2. Set up HTML constraint validation and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as validating only on the client.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover payment pages, or compare Zod with Yup.

Finish by recording what surprised you. Writing it down is how knowledge about Form Validation turns into something you can show others.
