Combining Endianness with Compilers and Interpreters in One Project

Real projects rarely use one idea in isolation. This article shows how Endianness and Compilers and Interpreters can work together in a single project.

Endianness is the order in which a computer stores the bytes of a multi-byte number. Compilers and Interpreters is programs that translate or run source code written in a high-level language.

Imagine a project that involves network protocols and running Python and JavaScript. Endianness brings big-endian, while Compilers and Interpreters brings lexing.

A sensible plan is to start with Python struct for the Endianness part and GCC for the Compilers and Interpreters part, and to keep the two sides connected through a small, well-tested interface.

Be prepared for combined risks: assuming all machines are alike on one side, and ignoring compiler warnings on the other.

Picture the whole as writing a date as day-month-year or as year-month-day, working alongside a translator who either translates a whole book first or interprets sentence by sentence.

Two habits help: first, always specify byte order in file and protocol formats; second, turn on compiler warnings and treat them seriously.
