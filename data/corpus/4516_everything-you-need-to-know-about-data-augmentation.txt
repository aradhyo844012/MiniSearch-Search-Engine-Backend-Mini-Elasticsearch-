Everything You Need to Know About Data Augmentation

This page collects the essentials about Data Augmentation in one place. In short, Data Augmentation is creating modified copies of training data to help models generalize.

Core concepts:
- transformations
- label preservation
- synthetic samples
- augmentation pipelines

Where it is used:
- image models
- text classification
- small datasets

Common problems:
- changes that alter the label
- augmenting the test set
- unrealistic transformations

Tools to know:
- Albumentations
- torchvision
- nlpaug

Remember this above all: practicing a sport in different weather and on different fields is a good way to picture it, and the best habit is to augment only the training data.
