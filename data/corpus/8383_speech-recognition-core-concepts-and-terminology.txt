Speech Recognition: Core Concepts and Terminology

This page defines the vocabulary you need to read about Speech Recognition with confidence. The subject itself is converting spoken language into text using machine learning.

audio features: one of the building blocks of Speech Recognition. You should be able to explain it in a single sentence before moving on.
acoustic models: one of the building blocks of Speech Recognition. Documentation for Whisper usually mentions it early.
language models: one of the building blocks of Speech Recognition. You should be able to explain it in a single sentence before moving on.
word error rate: one of the building blocks of Speech Recognition. Mixing it up with neighboring terms is a common source of confusion.
