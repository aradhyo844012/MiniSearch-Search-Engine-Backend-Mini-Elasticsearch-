Penetration Testing Glossary for Beginners

New words can make Penetration Testing feel harder than it is. This glossary keeps the key ones in one place.

Penetration Testing: authorized attempts to find and exploit weaknesses in a system before real attackers do.
scoping: a core term, most visible in pre-launch security checks.
reconnaissance: a core term that beginners often confuse with exploitation.
exploitation: a core term that connects to reporting.
reporting: a core term worth revisiting after you try a real example.
OWASP ZAP: a tool commonly used for compliance audits.

Come back to this Penetration Testing list whenever documentation for Burp Suite uses a word you do not recognize.
