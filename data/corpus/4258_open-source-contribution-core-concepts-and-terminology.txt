Open Source Contribution: Core Concepts and Terminology

This page defines the vocabulary you need to read about Open Source Contribution with confidence. The subject itself is helping improve public software projects by fixing bugs, writing documentation or adding features.

forks: one of the building blocks of Open Source Contribution. It shows up whenever you work on building a portfolio.
pull requests: one of the building blocks of Open Source Contribution. Mixing it up with neighboring terms is a common source of confusion.
issues: one of the building blocks of Open Source Contribution. You should be able to explain it in a single sentence before moving on.
contributing guides: one of the building blocks of Open Source Contribution. You should be able to explain it in a single sentence before moving on.

Practice using these four terms in sentences about learning from experienced maintainers. If the sentences feel natural, the vocabulary has stuck.
