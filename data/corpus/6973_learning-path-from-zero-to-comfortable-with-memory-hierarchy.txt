Learning Path: From Zero to Comfortable with Memory Hierarchy

This path is for a learner who has never studied Memory Hierarchy before. Move at your own speed.

Stage 1, the basics: read a short definition (Memory Hierarchy is the layers of storage from registers to disks, trading speed for size) and learn registers and cache.

Stage 2, hands-on: install lscpu, follow a tutorial, and build a small example involving designing efficient programs.

Stage 3, depth: study main memory and disk, then deliberately explore this problem: ignoring locality.

Stage 4, application: apply Memory Hierarchy to explaining slow I/O, compare vmstat with Linux perf, and write up your results.

Stage 5, review: teach Memory Hierarchy to someone else, and then move on to Instruction Pipelines.
