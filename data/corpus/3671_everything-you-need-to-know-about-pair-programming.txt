Everything You Need to Know About Pair Programming

This page collects the essentials about Pair Programming in one place. In short, Pair Programming is two developers working together at one computer on the same code.

Core concepts:
- driver and navigator
- rotation
- communication
- shared ownership

Where it is used:
- teaching new teammates
- solving hard bugs
- improving code quality

Common problems:
- one person dominating
- fatigue from long sessions
- pairing on every task

Tools to know:
- VS Code Live Share
- Tuple
- shared terminals

Remember this above all: a pilot and co-pilot who check each other's decisions is a good way to picture it, and the best habit is to swap roles every twenty to thirty minutes.
