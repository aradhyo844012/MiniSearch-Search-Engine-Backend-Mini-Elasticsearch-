Connection Pooling Tips from Experienced Engineers

Engineers who work with Connection Pooling regularly tend to repeat the same advice. Here it is.

1. Test the case of web backends early, before the design hardens.
2. Make sure you can always return connections in a finally block.
3. Reach for PgBouncer first, and only then evaluate alternatives such as HikariCP.
4. Write down why you chose Connection Pooling so the next person understands the decision.
5. Do not skip pool size; everything else builds on it.

None of these tips needs special equipment, and all of them apply to serverless functions that call databases as well.
