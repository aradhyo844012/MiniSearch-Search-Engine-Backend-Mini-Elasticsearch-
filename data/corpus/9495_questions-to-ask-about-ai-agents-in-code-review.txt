Questions to Ask About AI Agents in Code Review

Reviewing code that involves AI Agents is easier with a short list of questions. Keep these in mind as you read the diff.

- Would a test catch unchecked tool permissions if it appeared later?
- Have we considered runaway loops?
- Does this change respect planning, or does it work around it?
- Have we avoided this problem: hard-to-debug behavior?
- Does the code handle the case of research assistants correctly?
- Is tool calls clear to someone reading the code for the first time?

Good reviews of work on AI Agents are specific, kind and focused on memory, not on personal style.
