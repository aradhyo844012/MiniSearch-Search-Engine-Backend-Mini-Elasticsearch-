A Mini Project Idea Using Fenwick Trees

A small project is the fastest way to make Fenwick Trees stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Fenwick Trees at work on counting inversions. Keep the scope small enough to finish.

Milestones:
1. Read about binary indexed trees and lowest set bit.
2. Set up C++ vectors and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as using zero-based indexes by mistake.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover maintaining running totals, or compare Python lists with LeetCode practice problems.

Finish by recording what surprised you. Writing it down is how knowledge about Fenwick Trees turns into something you can show others.
