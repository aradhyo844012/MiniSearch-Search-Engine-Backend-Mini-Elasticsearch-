Open Source Contribution Tips from Experienced Engineers

Engineers who work with Open Source Contribution regularly tend to repeat the same advice. Here it is.

1. When something behaves strangely, revisit pull requests before anything else.
2. Test the case of building a portfolio early, before the design hardens.
3. Be careful with this one: opening huge pull requests.
4. Reach for GitHub first, and only then evaluate alternatives such as good first issue labels.
5. Write down why you chose Open Source Contribution so the next person understands the decision.

None of these tips needs special equipment, and all of them apply to learning from experienced maintainers as well.
