Everything You Need to Know About Technical Writing

This page collects the essentials about Technical Writing in one place. In short, Technical Writing is explaining technical ideas clearly in writing for a chosen audience.

Core concepts:
- audience
- structure
- examples
- editing

Where it is used:
- documentation
- blog posts
- design proposals

Common problems:
- assuming too much knowledge
- burying the main point
- long unbroken paragraphs

Tools to know:
- Markdown
- Grammarly
- Vale

Remember this above all: giving directions to a stranger is a good way to picture it, and the best habit is to state the main point in the first two sentences.
