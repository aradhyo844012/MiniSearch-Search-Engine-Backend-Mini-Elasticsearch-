Penetration Testing: Core Concepts and Terminology

This page defines the vocabulary you need to read about Penetration Testing with confidence. The subject itself is authorized attempts to find and exploit weaknesses in a system before real attackers do.

scoping: one of the building blocks of Penetration Testing. Mixing it up with neighboring terms is a common source of confusion.
reconnaissance: one of the building blocks of Penetration Testing. Documentation for OWASP ZAP usually mentions it early.
exploitation: one of the building blocks of Penetration Testing. Mixing it up with neighboring terms is a common source of confusion.
reporting: one of the building blocks of Penetration Testing. You should be able to explain it in a single sentence before moving on.

Practice using these four terms in sentences about compliance audits. If the sentences feel natural, the vocabulary has stuck.
