Code Editors and IDEs for Students: A Study Guide

This study guide prepares you for exams, labs and interviews that cover Code Editors and IDEs.

Learning goals:
1. Explain Code Editors and IDEs in your own words.
2. Describe syntax highlighting, autocomplete, debugger integration, and extensions.
3. Give examples from daily development and navigating large codebases.
4. Name three problems to watch for.

Start with the definition: Code Editors and IDEs is tools for writing, navigating and debugging code. Then draw a well-organized workbench on paper and label the four terms from the goals above.

Self-test questions: Why is installing too many extensions a problem? How does autocomplete relate to debugger integration? When would you choose VS Code or IntelliJ IDEA?

Study habit: learn the shortcuts for the actions you repeat most.

When you feel ready, compare Code Editors and IDEs with Technical Writing and write down three differences.
