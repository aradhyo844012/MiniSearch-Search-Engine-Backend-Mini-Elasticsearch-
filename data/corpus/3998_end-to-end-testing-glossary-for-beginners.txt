End-to-End Testing Glossary for Beginners

New words can make End-to-End Testing feel harder than it is. This glossary keeps the key ones in one place.

End-to-End Testing: tests that drive an application through a real user journey from start to finish.
browser automation: a core term, most visible in checking login and checkout flows.
user flows: a core term that beginners often confuse with test data.
test data: a core term that connects to selectors.
selectors: a core term worth revisiting after you try a real example.
Playwright: a tool commonly used for release verification.

Come back to this End-to-End Testing list whenever documentation for Cypress uses a word you do not recognize.
