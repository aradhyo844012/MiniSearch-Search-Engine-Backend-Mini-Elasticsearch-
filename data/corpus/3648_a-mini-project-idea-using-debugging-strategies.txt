A Mini Project Idea Using Debugging Strategies

A small project is the fastest way to make Debugging Strategies stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Debugging Strategies at work on fixing production issues. Keep the scope small enough to finish.

Milestones:
1. Read about reproducing the bug and isolating the cause.
2. Set up debuggers and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as changing many things at once.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover learning unfamiliar code, or compare logging with git bisect.

Finish by recording what surprised you. Writing it down is how knowledge about Debugging Strategies turns into something you can show others.
