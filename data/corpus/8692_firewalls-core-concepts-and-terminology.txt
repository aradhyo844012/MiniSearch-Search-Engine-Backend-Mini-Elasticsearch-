Firewalls: Core Concepts and Terminology

This page defines the vocabulary you need to read about Firewalls with confidence. The subject itself is systems that allow or block network traffic according to rules.

rules: one of the building blocks of Firewalls. It shows up whenever you work on protecting servers.
stateful inspection: one of the building blocks of Firewalls. It shows up whenever you work on protecting servers.
default deny: one of the building blocks of Firewalls. Documentation for ufw usually mentions it early.
zones: one of the building blocks of Firewalls. Mixing it up with neighboring terms is a common source of confusion.

Practice using these four Firewalls terms in sentences about segmenting networks. If the sentences feel natural, the vocabulary has stuck.
