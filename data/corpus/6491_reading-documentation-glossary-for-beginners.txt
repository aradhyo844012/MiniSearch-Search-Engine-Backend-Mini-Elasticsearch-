Reading Documentation Glossary for Beginners

New words can make Reading Documentation feel harder than it is. This glossary keeps the key ones in one place.

Reading Documentation: the skill of finding accurate answers in official guides and references.
search: a core term, most visible in learning new libraries.
tutorials versus references: a core term that beginners often confuse with examples.
examples: a core term that connects to version numbers.
version numbers: a core term worth revisiting after you try a real example.
MDN Web Docs: a tool commonly used for solving errors.

Come back to this Reading Documentation list whenever documentation for the Python docs uses a word you do not recognize.
