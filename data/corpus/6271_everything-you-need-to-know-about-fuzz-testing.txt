Everything You Need to Know About Fuzz Testing

This page collects the essentials about Fuzz Testing in one place. In short, Fuzz Testing is feeding programs random or malformed input to uncover crashes and security bugs.

Core concepts:
- input generation
- coverage guidance
- crash triage
- corpora

Where it is used:
- testing parsers
- finding memory bugs
- security research

Common problems:
- running without sanitizers
- crashes that cannot be reproduced
- ignoring slow inputs

Tools to know:
- AFL++
- libFuzzer
- Atheris

Remember this above all: shaking a machine hard to see what rattles loose is a good way to picture it, and the best habit is to keep every crashing input as a regression test.
