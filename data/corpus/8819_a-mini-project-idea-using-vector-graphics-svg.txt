A Mini Project Idea Using Vector Graphics (SVG)

A small project is the fastest way to make Vector Graphics (SVG) stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Vector Graphics (SVG) at work on logos. Keep the scope small enough to finish.

Milestones:
1. Read about paths and the viewBox.
2. Set up Inkscape and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as overly complex paths.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover icons, or compare SVGO with Figma.

Finish by recording what surprised you. Writing it down is how knowledge about Vector Graphics (SVG) turns into something you can show others.
