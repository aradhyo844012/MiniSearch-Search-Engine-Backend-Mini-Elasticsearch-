Common Mistakes When Working with Bootstrap

Almost everyone makes a few avoidable errors when first working with Bootstrap. If you build software for long enough, you will run into Bootstrap. The term refers to a popular front-end toolkit with ready-made layout, components and utilities.

Watch out for these problems: overriding styles with heavy custom CSS; loading unused components; and copying markup without understanding it.

Consider the first problem: overriding styles with heavy custom CSS. A short test or a careful review comment usually catches it. The second problem is similar: loading unused components. The third problem is this: copying markup without understanding it. It tends to appear only once a project grows, so it is worth planning for early.
