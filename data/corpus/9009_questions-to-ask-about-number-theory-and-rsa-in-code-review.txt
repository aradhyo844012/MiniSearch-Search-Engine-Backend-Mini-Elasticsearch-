Questions to Ask About Number Theory and RSA in Code Review

Reviewing code that involves Number Theory and RSA is easier with a short list of questions. Keep these in mind as you read the diff.

- Could we use vetted crypto libraries instead of writing your own?
- Is modular arithmetic clear to someone reading the code for the first time?
- Is Python pow used consistently, or are we mixing approaches?
- Does this change respect prime numbers, or does it work around it?
- Would a test catch implementing crypto by hand in production if it appeared later?
- Have we considered using small primes?

Good reviews of work on Number Theory and RSA are specific, kind and focused on greatest common divisor, not on personal style.
