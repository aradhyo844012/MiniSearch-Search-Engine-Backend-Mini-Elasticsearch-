Questions to Ask About Elasticsearch Concepts in Code Review

Reviewing code that involves Elasticsearch Concepts is easier with a short list of questions. Keep these in mind as you read the diff.

- Is shards clear to someone reading the code for the first time?
- Does the code handle the case of site search correctly?
- Is Elasticsearch used consistently, or are we mixing approaches?
- Would a test catch mapping explosions if it appeared later?
- Could we define explicit mappings instead of relying on defaults?
- Have we considered too many shards?

Good reviews of work on Elasticsearch Concepts are specific, kind and focused on analyzers, not on personal style.
