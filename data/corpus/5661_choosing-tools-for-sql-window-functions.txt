Choosing Tools for SQL Window Functions

There is no single best tool for SQL Window Functions. The right choice depends on your project, your team and your timeline.

PostgreSQL is a common first choice, especially for running totals. SQLite suits teams that already work with similar technology, and BigQuery is worth a look when you need something different.

Judge any tool by four questions: Is the documentation clear? Is the community active? Does it handle ranking rows well? Can you leave it later if you need to?

Whichever tool you pick, test it on a small problem first, and watch for this: forgetting ORDER BY inside the window.

As a rule of thumb, start with ROW_NUMBER and LAG on a small table, no matter which tool you use.
