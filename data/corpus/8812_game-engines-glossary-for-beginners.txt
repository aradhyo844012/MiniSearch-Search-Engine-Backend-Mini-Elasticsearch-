Game Engines Glossary for Beginners

New words can make Game Engines feel harder than it is. This glossary keeps the key ones in one place.

Game Engines: software frameworks that provide graphics, physics, input and tools for building games.
scenes: a core term, most visible in indie games.
assets: a core term that beginners often confuse with scripting.
scripting: a core term that connects to build pipelines.
build pipelines: a core term worth revisiting after you try a real example.
Unity: a tool commonly used for simulations.

Come back to this Game Engines list whenever documentation for Godot uses a word you do not recognize.
