Questions to Ask About Virtual Private Clouds in Code Review

Reviewing code that involves Virtual Private Clouds is easier with a short list of questions. Keep these in mind as you read the diff.

- Could we keep databases in private subnets?
- Does this change respect subnets, or does it work around it?
- Does the code handle the case of separating public and private services correctly?
- Have we considered overlapping address ranges?
- Would a test catch databases in public subnets if it appeared later?
- Have we avoided this problem: missing routes?

Good reviews of work on Virtual Private Clouds are specific, kind and focused on security groups, not on personal style.
