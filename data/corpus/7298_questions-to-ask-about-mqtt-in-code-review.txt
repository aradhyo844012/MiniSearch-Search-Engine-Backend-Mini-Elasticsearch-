Questions to Ask About MQTT in Code Review

Reviewing code that involves MQTT is easier with a short list of questions. Keep these in mind as you read the diff.

- Does this change respect publish and subscribe, or does it work around it?
- Does the code handle the case of sensor networks correctly?
- Have we considered unsecured brokers?
- Would a test catch messy topic names if it appeared later?
- Is Mosquitto used consistently, or are we mixing approaches?
- Could we design topic names like a clear folder structure?

Good reviews of work on MQTT are specific, kind and focused on brokers, not on personal style.
