A Mini Project Idea Using Hashing vs Encryption

A small project is the fastest way to make Hashing vs Encryption stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Hashing vs Encryption at work on storing passwords. Keep the scope small enough to finish.

Milestones:
1. Read about one-way functions and keys.
2. Set up SHA-256 and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as encrypting passwords instead of hashing them.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover verifying file integrity, or compare AES with OpenSSL.

Finish by recording what surprised you. Writing it down is how knowledge about Hashing vs Encryption turns into something you can show others.
