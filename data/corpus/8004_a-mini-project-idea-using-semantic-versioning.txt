A Mini Project Idea Using Semantic Versioning

A small project is the fastest way to make Semantic Versioning stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Semantic Versioning at work on publishing libraries. Keep the scope small enough to finish.

Milestones:
1. Read about major, minor and patch numbers and breaking changes.
2. Set up semver.org and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as breaking changes in minor releases.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover declaring dependencies, or compare npm semver with release notes.

Finish by recording what surprised you. Writing it down is how knowledge about Semantic Versioning turns into something you can show others.
