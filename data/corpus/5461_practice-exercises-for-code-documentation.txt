Practice Exercises for Code Documentation

These exercises build real understanding of Code Documentation. Do them in order, and write down your answers.

Exercise 1: Explain how architecture notes and examples differ, using a drawing.
Exercise 2: Create a small example that deliberately triggers this problem: outdated docs. Then fix it.
Exercise 3: Compare MkDocs and Javadoc for recording design decisions and write down your conclusion.
Exercise 4: Write a short paragraph describing Code Documentation and include the term README files.
Exercise 5: List three situations from your own experience that resemble onboarding new developers or describing APIs.

When you finish, compare your answers with the definition: Code Documentation is written explanations that help others understand and use code.
