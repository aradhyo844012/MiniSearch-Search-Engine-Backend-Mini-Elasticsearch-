Open Source Contribution Quick Reference

A one-screen reminder for Open Source Contribution. Bookmark it and return when the details fade.

What it is: helping improve public software projects by fixing bugs, writing documentation or adding features.
Key terms: forks, pull requests, issues, and contributing guides.
Typical uses: building a portfolio, learning from experienced maintainers, and giving back to tools you use.
Risks: opening huge pull requests, ignoring contribution rules, and expecting instant replies.
Tools: GitHub, good first issue labels, and Git.

Mental picture: helping repair a shared public library.

Habit to build: start with documentation fixes or small bugs.
