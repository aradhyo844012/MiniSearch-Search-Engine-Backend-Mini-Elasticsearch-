SSH and Remote Access: Core Concepts and Terminology

This page defines the vocabulary you need to read about SSH and Remote Access with confidence. The subject itself is a secure protocol for logging in to and controlling remote machines.

key pairs: one of the building blocks of SSH and Remote Access. Mixing it up with neighboring terms is a common source of confusion.
host keys: one of the building blocks of SSH and Remote Access. It shows up whenever you work on administering servers.
port forwarding: one of the building blocks of SSH and Remote Access. It shows up whenever you work on administering servers.
config files: one of the building blocks of SSH and Remote Access. Documentation for OpenSSH usually mentions it early.
