Competitive Programming: Core Concepts and Terminology

This page defines the vocabulary you need to read about Competitive Programming with confidence. The subject itself is solving algorithmic problems under time limits to build speed and problem-solving skills.

problem patterns: one of the building blocks of Competitive Programming. Documentation for Codeforces usually mentions it early.
time limits: one of the building blocks of Competitive Programming. Documentation for Codeforces usually mentions it early.
contests: one of the building blocks of Competitive Programming. Mixing it up with neighboring terms is a common source of confusion.
upsolving: one of the building blocks of Competitive Programming. Mixing it up with neighboring terms is a common source of confusion.

Practice using these four terms in sentences about learning algorithms. If the sentences feel natural, the vocabulary has stuck.
