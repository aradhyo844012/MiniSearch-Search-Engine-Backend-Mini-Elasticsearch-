A Mini Project Idea Using Raft Consensus

A small project is the fastest way to make Raft Consensus stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Raft Consensus at work on configuration stores. Keep the scope small enough to finish.

Milestones:
1. Read about leader election and log replication.
2. Set up etcd and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as even-sized clusters.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover distributed locks, or compare Consul with HashiCorp Raft library.

Finish by recording what surprised you. Writing it down is how knowledge about Raft Consensus turns into something you can show others.
