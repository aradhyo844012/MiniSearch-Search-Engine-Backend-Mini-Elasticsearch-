A Mini Project Idea Using Dependency Vulnerabilities

A small project is the fastest way to make Dependency Vulnerabilities stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Dependency Vulnerabilities at work on auditing projects. Keep the scope small enough to finish.

Milestones:
1. Read about CVE identifiers and version pinning.
2. Set up Dependabot and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as ignoring transitive dependencies.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover automating updates, or compare pip-audit with npm audit.

Finish by recording what surprised you. Writing it down is how knowledge about Dependency Vulnerabilities turns into something you can show others.
