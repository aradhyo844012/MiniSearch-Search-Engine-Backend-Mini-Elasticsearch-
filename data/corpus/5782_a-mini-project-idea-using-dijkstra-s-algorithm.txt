A Mini Project Idea Using Dijkstra's Algorithm

A small project is the fastest way to make Dijkstra's Algorithm stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Dijkstra's Algorithm at work on route planning. Keep the scope small enough to finish.

Milestones:
1. Read about priority queue and distance table.
2. Set up Python heapq and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as using it with negative edge weights.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover network routing, or compare NetworkX with OSRM.

Finish by recording what surprised you. Writing it down is how knowledge about Dijkstra's Algorithm turns into something you can show others.
