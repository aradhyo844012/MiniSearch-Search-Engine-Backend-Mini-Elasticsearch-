A Mini Project Idea Using Environment Variables

A small project is the fastest way to make Environment Variables stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Environment Variables at work on storing configuration. Keep the scope small enough to finish.

Milestones:
1. Read about variable names and scope.
2. Set up env and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as committing secrets in dotfiles.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover selecting program paths, or compare printenv with dotenv files.

Finish by recording what surprised you. Writing it down is how knowledge about Environment Variables turns into something you can show others.
