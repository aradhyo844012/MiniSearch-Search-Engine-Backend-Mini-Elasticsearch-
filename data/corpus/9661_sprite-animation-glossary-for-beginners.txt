Sprite Animation Glossary for Beginners

New words can make Sprite Animation feel harder than it is. This glossary keeps the key ones in one place.

Sprite Animation: showing a sequence of 2D images quickly to make a character appear to move.
sprite sheets: a core term, most visible in 2D platformers.
frames: a core term that beginners often confuse with frame rate.
frame rate: a core term that connects to animation states.
animation states: a core term worth revisiting after you try a real example.
Aseprite: a tool commonly used for user interface effects.

Come back to this Sprite Animation list whenever documentation for Unity Animator uses a word you do not recognize.
