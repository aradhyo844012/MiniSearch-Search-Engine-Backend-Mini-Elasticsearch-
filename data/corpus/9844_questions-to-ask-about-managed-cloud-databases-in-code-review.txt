Questions to Ask About Managed Cloud Databases in Code Review

Reviewing code that involves Managed Cloud Databases is easier with a short list of questions. Keep these in mind as you read the diff.

- Have we considered surprise costs?
- Is read replicas clear to someone reading the code for the first time?
- Could we test restoring a backup before you need it?
- Have we avoided this problem: ignoring maintenance windows?
- Would a test catch limited configuration control if it appeared later?
- Does this change respect automated backups, or does it work around it?

Good reviews of work on Managed Cloud Databases are specific, kind and focused on maintenance windows, not on personal style.
