A Mini Project Idea Using CSRF

A small project is the fastest way to make CSRF stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows CSRF at work on protecting forms. Keep the scope small enough to finish.

Milestones:
1. Read about session cookies and anti-CSRF tokens.
2. Set up Django CSRF middleware and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as using GET requests for state changes.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover securing account settings, or compare Flask-WTF with OWASP guides.

Finish by recording what surprised you. Writing it down is how knowledge about CSRF turns into something you can show others.
