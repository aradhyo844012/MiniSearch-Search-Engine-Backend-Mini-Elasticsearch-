Jupyter Notebooks: Core Concepts and Terminology

This page defines the vocabulary you need to read about Jupyter Notebooks with confidence. The subject itself is interactive documents that combine code, results and notes.

cells: one of the building blocks of Jupyter Notebooks. Mixing it up with neighboring terms is a common source of confusion.
kernels: one of the building blocks of Jupyter Notebooks. Documentation for JupyterLab usually mentions it early.
markdown: one of the building blocks of Jupyter Notebooks. You should be able to explain it in a single sentence before moving on.
outputs: one of the building blocks of Jupyter Notebooks. Mixing it up with neighboring terms is a common source of confusion.

Practice using these four terms in sentences about teaching and demos. If the sentences feel natural, the vocabulary has stuck.
