SQL Basics Glossary for Beginners

New words can make SQL Basics feel harder than it is. This glossary keeps the key ones in one place.

SQL Basics: the core SQL commands for reading and changing data in tables.
SELECT: a core term, most visible in reading customer records.
WHERE: a core term that beginners often confuse with ORDER BY.
ORDER BY: a core term that connects to INSERT and UPDATE.
INSERT and UPDATE: a core term worth revisiting after you try a real example.
SQLite: a tool commonly used for building reports.

Come back to this SQL Basics list whenever documentation for PostgreSQL uses a word you do not recognize.
