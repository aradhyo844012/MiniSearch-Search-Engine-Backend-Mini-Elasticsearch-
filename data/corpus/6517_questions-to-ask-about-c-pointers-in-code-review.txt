Questions to Ask About C Pointers in Code Review

Reviewing code that involves C Pointers is easier with a short list of questions. Keep these in mind as you read the diff.

- Would a test catch memory leaks if it appeared later?
- Does this change respect addresses, or does it work around it?
- Have we considered dereferencing null pointers?
- Does the code handle the case of dynamic memory allocation correctly?
- Could we set pointers to NULL after freeing them?
- Is dereferencing clear to someone reading the code for the first time?

Good reviews of work on C Pointers are specific, kind and focused on pointer arithmetic, not on personal style.
