Questions to Ask About CPU Caches in Code Review

Reviewing code that involves CPU Caches is easier with a short list of questions. Keep these in mind as you read the diff.

- Could we access arrays in the order they are stored?
- Does this change respect cache lines, or does it work around it?
- Is hit and miss rates clear to someone reading the code for the first time?
- Does the code handle the case of speeding up loops correctly?
- Is perf used consistently, or are we mixing approaches?
- Have we avoided this problem: assuming memory is uniformly fast?

Good reviews of work on CPU Caches are specific, kind and focused on levels L1 to L3, not on personal style.
