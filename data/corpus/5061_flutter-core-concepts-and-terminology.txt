Flutter: Core Concepts and Terminology

This page defines the vocabulary you need to read about Flutter with confidence. The subject itself is a toolkit for building natively compiled apps from a single Dart codebase.

widgets: one of the building blocks of Flutter. Mixing it up with neighboring terms is a common source of confusion.
state: one of the building blocks of Flutter. Mixing it up with neighboring terms is a common source of confusion.
hot reload: one of the building blocks of Flutter. Documentation for Dart usually mentions it early.
the render tree: one of the building blocks of Flutter. Mixing it up with neighboring terms is a common source of confusion.

Practice using these four terms in sentences about desktop apps. If the sentences feel natural, the vocabulary has stuck.
