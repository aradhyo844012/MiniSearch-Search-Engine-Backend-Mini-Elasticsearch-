Questions to Ask About Python Asyncio in Code Review

Reviewing code that involves Python Asyncio is easier with a short list of questions. Keep these in mind as you read the diff.

- Is coroutines clear to someone reading the code for the first time?
- Does this change respect event loop, or does it work around it?
- Have we considered blocking calls inside coroutines?
- Is asyncio used consistently, or are we mixing approaches?
- Could we never call blocking code directly inside a coroutine?
- Does the code handle the case of calling many APIs at once correctly?

Good reviews of work on Python Asyncio are specific, kind and focused on await, not on personal style.
