Combining Jupyter Notebooks with Data Anonymization in One Project

Real projects rarely use one idea in isolation. This article shows how Jupyter Notebooks and Data Anonymization can work together in a single project.

Jupyter Notebooks is interactive documents that combine code, results and notes. Data Anonymization is removing or altering personal details in data so people cannot be identified.

Imagine a project that involves exploring data and sharing datasets with researchers. Jupyter Notebooks brings cells, while Data Anonymization brings masking.

A sensible plan is to start with JupyterLab for the Jupyter Notebooks part and ARX for the Data Anonymization part, and to keep the two sides connected through a small, well-tested interface.

Be prepared for combined risks: hidden state on one side, and removing too little on the other.

Picture the whole as a lab notebook that can run its own experiments, working alongside blurring faces in a crowd photo while keeping the scene.

Two habits help: first, restart the kernel and run all cells before sharing; second, test whether combining fields could identify a person.
