A Mini Project Idea Using SQL Basics

A small project is the fastest way to make SQL Basics stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows SQL Basics at work on reading customer records. Keep the scope small enough to finish.

Milestones:
1. Read about SELECT and WHERE.
2. Set up SQLite and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as forgetting the WHERE clause on updates.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover building reports, or compare PostgreSQL with DB Browser for SQLite.

Finish by recording what surprised you. Writing it down is how knowledge about SQL Basics turns into something you can show others.
