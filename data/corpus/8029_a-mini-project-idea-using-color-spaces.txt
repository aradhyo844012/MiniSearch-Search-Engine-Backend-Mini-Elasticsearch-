A Mini Project Idea Using Color Spaces

A small project is the fastest way to make Color Spaces stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Color Spaces at work on web design. Keep the scope small enough to finish.

Milestones:
1. Read about RGB and HSL.
2. Set up browser color pickers and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as ignoring gamma.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover photo editing, or compare ImageMagick with Coolors.

Finish by recording what surprised you. Writing it down is how knowledge about Color Spaces turns into something you can show others.
