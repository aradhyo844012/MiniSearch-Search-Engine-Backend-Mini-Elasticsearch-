Cloud-Native Applications Glossary for Beginners

New words can make Cloud-Native Applications feel harder than it is. This glossary keeps the key ones in one place.

Cloud-Native Applications: applications designed from the start to run in the cloud using containers and managed services.
containers: a core term, most visible in web platforms.
microservices: a core term that beginners often confuse with declarative configuration.
declarative configuration: a core term that connects to elastic scaling.
elastic scaling: a core term worth revisiting after you try a real example.
Kubernetes: a tool commonly used for data-heavy services.

Come back to this Cloud-Native Applications list whenever documentation for Docker uses a word you do not recognize.
