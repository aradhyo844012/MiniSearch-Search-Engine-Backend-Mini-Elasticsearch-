How to Learn JavaScript Promises in 30 Days

You do not need months to become comfortable with JavaScript Promises. A focused plan of thirty days is enough to build a solid base. When people talk about JavaScript Promises, they usually mean objects that represent a value that will be available later, after an asynchronous task finishes. It appears in almost every serious software project, whether or not developers notice it.

Week 1: learn pending and resolved states and then and catch, and write a one-page summary.
Week 2: practice with fetch API on a small task such as fetching data from APIs.
Week 3: build a mini project around reading files.
Week 4: review common mistakes such as forgetting to handle rejections, and explain JavaScript Promises to a friend.

Popular tools and libraries include fetch API, Node.js, and Promise.all.

In short, careful study of JavaScript Promises pays off. Spend time on pending and resolved states and then and catch, and the rest will follow.
