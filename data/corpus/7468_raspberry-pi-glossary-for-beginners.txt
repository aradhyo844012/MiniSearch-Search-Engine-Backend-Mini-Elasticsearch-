Raspberry Pi Glossary for Beginners

New words can make Raspberry Pi feel harder than it is. This glossary keeps the key ones in one place.

Raspberry Pi: a small, low-cost computer popular for learning, prototypes and home projects.
GPIO pins: a core term, most visible in home automation.
Linux: a core term that beginners often confuse with SD card storage.
SD card storage: a core term that connects to headless setup.
headless setup: a core term worth revisiting after you try a real example.
Raspberry Pi OS: a tool commonly used for learning Linux.

Come back to this Raspberry Pi list whenever documentation for Python GPIO libraries uses a word you do not recognize.
