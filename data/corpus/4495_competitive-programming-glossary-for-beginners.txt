Competitive Programming Glossary for Beginners

New words can make Competitive Programming feel harder than it is. This glossary keeps the key ones in one place.

Competitive Programming: solving algorithmic problems under time limits to build speed and problem-solving skills.
problem patterns: a core term, most visible in interview preparation.
time limits: a core term that beginners often confuse with contests.
contests: a core term that connects to upsolving.
upsolving: a core term worth revisiting after you try a real example.
Codeforces: a tool commonly used for learning algorithms.

Come back to this Competitive Programming list whenever documentation for LeetCode uses a word you do not recognize.
