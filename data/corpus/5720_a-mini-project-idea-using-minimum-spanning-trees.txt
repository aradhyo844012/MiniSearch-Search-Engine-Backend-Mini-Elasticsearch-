A Mini Project Idea Using Minimum Spanning Trees

A small project is the fastest way to make Minimum Spanning Trees stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Minimum Spanning Trees at work on designing cable networks. Keep the scope small enough to finish.

Milestones:
1. Read about weighted graphs and Kruskal's algorithm.
2. Set up NetworkX and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as using it on directed graphs.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover clustering data, or compare SciPy with Graphviz.

Finish by recording what surprised you. Writing it down is how knowledge about Minimum Spanning Trees turns into something you can show others.
