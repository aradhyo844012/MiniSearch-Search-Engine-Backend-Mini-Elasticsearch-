CSS Variables: Core Concepts and Terminology

This page defines the vocabulary you need to read about CSS Variables with confidence. The subject itself is custom properties that store values such as colors and spacing so they can be reused across styles.

custom properties: one of the building blocks of CSS Variables. You should be able to explain it in a single sentence before moving on.
the var function: one of the building blocks of CSS Variables. Documentation for browser DevTools usually mentions it early.
inheritance: one of the building blocks of CSS Variables. It shows up whenever you work on theme switching.
fallback values: one of the building blocks of CSS Variables. It shows up whenever you work on theme switching.

Practice using these four terms in sentences about design systems. If the sentences feel natural, the vocabulary has stuck.
