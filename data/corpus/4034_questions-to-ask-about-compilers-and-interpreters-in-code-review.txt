Questions to Ask About Compilers and Interpreters in Code Review

Reviewing code that involves Compilers and Interpreters is easier with a short list of questions. Keep these in mind as you read the diff.

- Would a test catch ignoring compiler warnings if it appeared later?
- Have we considered assuming interpreted means slow without measuring?
- Have we avoided this problem: confusing compile-time and run-time errors?
- Is parsing clear to someone reading the code for the first time?
- Is GCC used consistently, or are we mixing approaches?
- Does this change respect lexing, or does it work around it?

Good reviews of work on Compilers and Interpreters are specific, kind and focused on code generation, not on personal style.
