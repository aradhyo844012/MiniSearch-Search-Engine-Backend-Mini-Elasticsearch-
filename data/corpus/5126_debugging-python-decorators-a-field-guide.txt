Debugging Python Decorators: A Field Guide

When something goes wrong around Python Decorators, resist the urge to guess. Work through the problem in order.

Step 1: reproduce the problem with the smallest possible example.
Step 2: list the usual suspects: losing function metadata, stacking decorators in the wrong order, and hiding side effects.
Step 3: revisit higher-order functions and wrapper functions, since misunderstandings there cause many bugs.
Step 4: use functools or similar tools to look inside.
Step 5: write a test that fails because of the bug and passes after the fix.

Many bugs involving Python Decorators in work such as logging calls come down to the first suspect on the list. Check the simple causes before suspecting anything exotic.

Finally, always apply functools.wraps inside your decorator. It prevents a surprising number of repeat problems.
