Code Formatters Glossary for Beginners

New words can make Code Formatters feel harder than it is. This glossary keeps the key ones in one place.

Code Formatters: tools that automatically rewrite code to a consistent style.
style rules: a core term, most visible in ending style debates.
configuration: a core term that beginners often confuse with editor integration.
editor integration: a core term that connects to pre-commit hooks.
pre-commit hooks: a core term worth revisiting after you try a real example.
Prettier: a tool commonly used for cleaner diffs.

Come back to this Code Formatters list whenever documentation for Black uses a word you do not recognize.
