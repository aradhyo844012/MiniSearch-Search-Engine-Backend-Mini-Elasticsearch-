Code Editors and IDEs Quick Reference

A one-screen reminder for Code Editors and IDEs. Bookmark it and return when the details fade.

What it is: tools for writing, navigating and debugging code.
Key terms: syntax highlighting, autocomplete, debugger integration, and extensions.
Typical uses: daily development, navigating large codebases, and refactoring.
Risks: installing too many extensions, ignoring keyboard shortcuts, and relying on autocomplete blindly.
Tools: VS Code, IntelliJ IDEA, and Neovim.

Mental picture: a well-organized workbench.

Habit to build: learn the shortcuts for the actions you repeat most.
