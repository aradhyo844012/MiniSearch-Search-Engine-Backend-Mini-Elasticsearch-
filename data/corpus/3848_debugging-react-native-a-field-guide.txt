Debugging React Native: A Field Guide

When something goes wrong around React Native, resist the urge to guess. Work through the problem in order.

Step 1: reproduce the problem with the smallest possible example.
Step 2: list the usual suspects: heavy re-renders, poorly tuned lists, and relying on outdated native modules.
Step 3: revisit components and native modules, since misunderstandings there cause many bugs.
Step 4: use Expo or similar tools to look inside.
Step 5: write a test that fails because of the bug and passes after the fix.

Many bugs involving React Native in work such as cross-platform apps come down to the first suspect on the list. Check the simple causes before suspecting anything exotic.

Finally, test on real devices for both platforms. It prevents a surprising number of repeat problems.
