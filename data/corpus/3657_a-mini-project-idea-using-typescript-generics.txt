A Mini Project Idea Using TypeScript Generics

A small project is the fastest way to make TypeScript Generics stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows TypeScript Generics at work on reusable utility functions. Keep the scope small enough to finish.

Milestones:
1. Read about type parameters and constraints.
2. Set up tsc and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as overusing any.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover typed API clients, or compare the TypeScript Playground with ESLint.

Finish by recording what surprised you. Writing it down is how knowledge about TypeScript Generics turns into something you can show others.
