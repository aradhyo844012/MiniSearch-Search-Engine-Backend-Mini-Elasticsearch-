CSS Flexbox and Grid Cheat Sheet

Use this page as a quick reminder of the essentials of CSS Flexbox and Grid.

- Definition: two layout systems that arrange elements in rows, columns and two-dimensional grids.
- Core ideas: flex containers; grid tracks; alignment; gaps.
- Use it for: navigation bars; card layouts; page templates.
- Watch out for: mixing up main and cross axes; fixed widths that break on phones; nesting layouts too deeply.
- Tools: browser grid inspector, Bootstrap utilities, CSS-Tricks guides.
- Related topic: Responsive Design.
- Quick tip: practice flex containers until it feels automatic.
