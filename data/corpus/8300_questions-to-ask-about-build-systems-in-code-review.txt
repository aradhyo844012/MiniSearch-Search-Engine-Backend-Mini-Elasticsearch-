Questions to Ask About Build Systems in Code Review

Reviewing code that involves Build Systems is easier with a short list of questions. Keep these in mind as you read the diff.

- Is Make used consistently, or are we mixing approaches?
- Have we avoided this problem: machine-specific builds?
- Have we considered slow full rebuilds?
- Could we make builds reproducible on any machine?
- Does the code handle the case of compiling large projects correctly?
- Does this change respect targets, or does it work around it?

Good reviews of work on Build Systems are specific, kind and focused on incremental builds, not on personal style.
