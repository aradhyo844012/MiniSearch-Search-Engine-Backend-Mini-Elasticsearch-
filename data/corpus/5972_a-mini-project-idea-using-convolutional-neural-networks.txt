A Mini Project Idea Using Convolutional Neural Networks

A small project is the fastest way to make Convolutional Neural Networks stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Convolutional Neural Networks at work on image classification. Keep the scope small enough to finish.

Milestones:
1. Read about filters and pooling.
2. Set up PyTorch and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as too little training data.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover medical image analysis, or compare TensorFlow with Keras.

Finish by recording what surprised you. Writing it down is how knowledge about Convolutional Neural Networks turns into something you can show others.
