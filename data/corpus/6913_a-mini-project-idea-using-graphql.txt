A Mini Project Idea Using GraphQL

A small project is the fastest way to make GraphQL stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows GraphQL at work on mobile apps with limited bandwidth. Keep the scope small enough to finish.

Milestones:
1. Read about schema and queries and mutations.
2. Set up Apollo and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as the N+1 query problem.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover aggregating many services, or compare GraphQL Playground with Hasura.

Finish by recording what surprised you. Writing it down is how knowledge about GraphQL turns into something you can show others.
