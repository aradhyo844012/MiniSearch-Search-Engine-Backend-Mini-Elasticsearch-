Zero Trust Security: Core Concepts and Terminology

This page defines the vocabulary you need to read about Zero Trust Security with confidence. The subject itself is a model that treats every request as untrusted until it is verified.

identity verification: one of the building blocks of Zero Trust Security. It shows up whenever you work on remote work access.
least privilege: one of the building blocks of Zero Trust Security. Documentation for Okta usually mentions it early.
micro-segmentation: one of the building blocks of Zero Trust Security. It shows up whenever you work on remote work access.
continuous checks: one of the building blocks of Zero Trust Security. You should be able to explain it in a single sentence before moving on.

Practice using these four terms in sentences about protecting internal services. If the sentences feel natural, the vocabulary has stuck.
