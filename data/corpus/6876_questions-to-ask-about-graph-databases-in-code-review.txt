Questions to Ask About Graph Databases in Code Review

Reviewing code that involves Graph Databases is easier with a short list of questions. Keep these in mind as you read the diff.

- Could we limit traversal depth in every exploratory query?
- Is edges clear to someone reading the code for the first time?
- Have we considered using them for simple tabular data?
- Does this change respect nodes, or does it work around it?
- Is Neo4j used consistently, or are we mixing approaches?
- Does the code handle the case of social networks correctly?

Good reviews of work on Graph Databases are specific, kind and focused on properties, not on personal style.
