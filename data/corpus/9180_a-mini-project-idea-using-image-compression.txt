A Mini Project Idea Using Image Compression

A small project is the fastest way to make Image Compression stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Image Compression at work on web images. Keep the scope small enough to finish.

Milestones:
1. Read about lossy and lossless formats and quantization.
2. Set up ImageMagick and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as repeated recompression.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover photo storage, or compare mozjpeg with Squoosh.

Finish by recording what surprised you. Writing it down is how knowledge about Image Compression turns into something you can show others.
