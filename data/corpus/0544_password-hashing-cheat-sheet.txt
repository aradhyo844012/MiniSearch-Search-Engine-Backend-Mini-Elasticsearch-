Password Hashing Cheat Sheet

Use this page as a quick reminder of the essentials of Password Hashing.

- Definition: storing passwords as one-way hashes so the originals are never kept.
- Core ideas: salts; slow hash functions; work factors; verification.
- Use it for: user login systems; protecting data after a breach; migrating old accounts.
- Watch out for: using fast hashes like plain SHA-256; reusing salts; storing passwords in plain text.
- Tools: bcrypt, Argon2, scrypt.
- Quick tip: write a tiny test for slow hash functions before building anything large.
- Quick tip: practice salts until it feels automatic.
