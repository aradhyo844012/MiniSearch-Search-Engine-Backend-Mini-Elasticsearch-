Practice Exercises for Cloud-Native Applications

These exercises build real understanding of Cloud-Native Applications. Do them in order, and write down your answers.

Exercise 1: Pick Kubernetes and complete its getting-started tutorial.
Exercise 2: List three situations from your own experience that resemble web platforms or data-heavy services.
Exercise 3: Write a short paragraph describing Cloud-Native Applications and include the term containers.
Exercise 4: Explain how declarative configuration and elastic scaling differ, using a drawing.
Exercise 5: Create a small example that deliberately triggers this problem: treating the cloud like a data center. Then fix it.

When you finish, compare your answers with the definition: Cloud-Native Applications is applications designed from the start to run in the cloud using containers and managed services.
