Pair Programming Glossary for Beginners

New words can make Pair Programming feel harder than it is. This glossary keeps the key ones in one place.

Pair Programming: two developers working together at one computer on the same code.
driver and navigator: a core term, most visible in teaching new teammates.
rotation: a core term that beginners often confuse with communication.
communication: a core term that connects to shared ownership.
shared ownership: a core term worth revisiting after you try a real example.
VS Code Live Share: a tool commonly used for solving hard bugs.

Come back to this Pair Programming list whenever documentation for Tuple uses a word you do not recognize.
