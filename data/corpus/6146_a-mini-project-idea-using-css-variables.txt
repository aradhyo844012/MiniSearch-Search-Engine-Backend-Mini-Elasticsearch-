A Mini Project Idea Using CSS Variables

A small project is the fastest way to make CSS Variables stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows CSS Variables at work on theme switching. Keep the scope small enough to finish.

Milestones:
1. Read about custom properties and the var function.
2. Set up browser DevTools and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as missing fallbacks.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover design systems, or compare Sass with PostCSS.

Finish by recording what surprised you. Writing it down is how knowledge about CSS Variables turns into something you can show others.
