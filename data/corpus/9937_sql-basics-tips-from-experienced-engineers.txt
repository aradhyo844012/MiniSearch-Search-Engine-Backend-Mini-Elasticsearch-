SQL Basics Tips from Experienced Engineers

Engineers who work with SQL Basics regularly tend to repeat the same advice. Here it is.

1. Be careful with this one: forgetting the WHERE clause on updates.
2. Test the case of reading customer records early, before the design hardens.
3. Make sure you can run a SELECT with the same WHERE clause before any UPDATE or DELETE.
4. Do not skip SELECT; everything else builds on it.
5. Reach for SQLite first, and only then evaluate alternatives such as PostgreSQL.

None of these tips needs special equipment, and all of them apply to building reports as well as to SQL Basics in general.
