Practice Exercises for Dev Containers

These exercises build real understanding of Dev Containers. Do them in order, and write down your answers.

Exercise 1: Pick VS Code Dev Containers and complete its getting-started tutorial.
Exercise 2: Compare Docker and GitHub Codespaces for trying projects safely and write down your conclusion.
Exercise 3: List three situations from your own experience that resemble onboarding new developers or matching production tools.
Exercise 4: Create a small example that deliberately triggers this problem: slow image builds. Then fix it.
Exercise 5: Explain how mounted folders and extensions differ, using a drawing.

When you finish, compare your answers with the definition: Dev Containers is containerized development environments that every teammate can start in the same way.
