A Mini Project Idea Using Encryption at Rest

A small project is the fastest way to make Encryption at Rest stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows Encryption at Rest at work on protecting backups. Keep the scope small enough to finish.

Milestones:
1. Read about symmetric keys and key management.
2. Set up LUKS and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as storing keys next to the data.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover meeting compliance rules, or compare AWS KMS with BitLocker.

Finish by recording what surprised you. Writing it down is how knowledge about Encryption at Rest turns into something you can show others.
