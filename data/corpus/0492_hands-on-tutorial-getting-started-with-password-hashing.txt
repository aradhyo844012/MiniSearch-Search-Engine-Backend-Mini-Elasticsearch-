Hands-On Tutorial: Getting Started with Password Hashing

This hands-on tutorial takes you from zero to a small working experiment with Password Hashing. Put simply, Password Hashing covers storing passwords as one-way hashes so the originals are never kept. Learning it well pays off across many areas of computing.

Step 1: Install or open bcrypt and create a new empty project folder.
Step 2: Read about salts and write down a definition in your own words.
Step 3: Build the smallest possible example that uses slow hash functions.
Step 4: Add one test or print statement that proves it works.
Step 5: Extend the example to handle a case such as user login systems.
Step 6: Break your example on purpose and see what happens. A good experiment: using fast hashes like plain SHA-256.

Popular tools and libraries include bcrypt, Argon2, and scrypt.

Three issues come up again and again: using fast hashes like plain SHA-256; reusing salts; and storing passwords in plain text. Knowing them in advance saves hours of debugging.

Keep experimenting, keep notes, and revisit Password Hashing whenever a new project gives you a reason.
