Python Basics Cheat Sheet

Use this page as a quick reminder of the essentials of Python Basics.

- Definition: the core features of Python, including data types, control flow and functions.
- Core ideas: variables; lists and dictionaries; functions; modules.
- Use it for: scripting; data analysis; web backends.
- Watch out for: mutable default arguments; confusing equality and identity; ignoring virtual environments.
- Tools: Python interpreter, pip, VS Code.
- Quick tip: practice variables until it feels automatic.
- Quick tip: write a tiny test for lists and dictionaries before building anything large.
