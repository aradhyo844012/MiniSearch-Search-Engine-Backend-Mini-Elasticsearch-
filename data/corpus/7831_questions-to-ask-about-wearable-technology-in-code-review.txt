Questions to Ask About Wearable Technology in Code Review

Reviewing code that involves Wearable Technology is easier with a short list of questions. Keep these in mind as you read the diff.

- Have we considered battery drain?
- Does the code handle the case of fitness tracking correctly?
- Does this change respect sensors, or does it work around it?
- Could we design interactions that take only a few seconds?
- Is low-power design clear to someone reading the code for the first time?
- Is Wear OS used consistently, or are we mixing approaches?

Good reviews of work on Wearable Technology are specific, kind and focused on companion apps, not on personal style.
