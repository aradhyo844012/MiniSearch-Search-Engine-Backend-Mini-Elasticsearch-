Web Storage for Students: A Study Guide

This study guide prepares you for exams, labs and interviews that cover Web Storage.

Learning goals:
1. Explain Web Storage in your own words.
2. Describe localStorage, sessionStorage, cookies, and IndexedDB.
3. Give examples from saving user preferences and remembering form drafts.
4. Name three problems to watch for.

Start with the definition: Web Storage is browser features for keeping small amounts of data on the user's device. Then draw a sticky note on the fridge that only your household can read on paper and label the four terms from the goals above.

Self-test questions: Why is storing sensitive data a problem? How does sessionStorage relate to cookies? When would you choose browser DevTools or localForage?

Study habit worth keeping: wrap every read and write in error handling.

When you feel ready, compare Web Storage with Web Components and write down three differences.
