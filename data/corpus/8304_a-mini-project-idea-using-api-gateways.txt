A Mini Project Idea Using API Gateways

A small project is the fastest way to make API Gateways stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows API Gateways at work on exposing microservices. Keep the scope small enough to finish.

Milestones:
1. Read about routing and authentication.
2. Set up Kong and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as a single point of failure.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover securing public APIs, or compare AWS API Gateway with NGINX.

Finish by recording what surprised you. Writing it down is how knowledge about API Gateways turns into something you can show others.
