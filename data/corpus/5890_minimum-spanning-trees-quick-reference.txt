Minimum Spanning Trees Quick Reference

A one-screen reminder for Minimum Spanning Trees. Bookmark it and return when the details fade.

What it is: a set of edges that connects every node in a graph with the smallest possible total weight.
Key terms: weighted graphs, Kruskal's algorithm, Prim's algorithm, and the cut property.
Typical uses: designing cable networks, clustering data, and reducing infrastructure cost.
Risks: using it on directed graphs, forgetting that the graph must be connected, and treating ties as errors.
Tools: NetworkX, SciPy, and Graphviz.

Mental picture: laying the cheapest set of roads that still links every town.

Habit to build: sort the edges once and reuse the order when testing variations.
