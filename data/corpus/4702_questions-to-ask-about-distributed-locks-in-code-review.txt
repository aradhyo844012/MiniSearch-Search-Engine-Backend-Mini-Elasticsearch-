Questions to Ask About Distributed Locks in Code Review

Reviewing code that involves Distributed Locks is easier with a short list of questions. Keep these in mind as you read the diff.

- Does this change respect lease times, or does it work around it?
- Would a test catch clock drift if it appeared later?
- Have we avoided this problem: assuming the lock holder is still alive?
- Could we always use a timeout together with a fencing token?
- Is fencing tokens clear to someone reading the code for the first time?
- Have we considered locks that never expire?

Good reviews of work on Distributed Locks are specific, kind and focused on lock owners, not on personal style.
