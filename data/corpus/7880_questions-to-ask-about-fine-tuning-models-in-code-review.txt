Questions to Ask About Fine-Tuning Models in Code Review

Reviewing code that involves Fine-Tuning Models is easier with a short list of questions. Keep these in mind as you read the diff.

- Does this change respect pretrained weights, or does it work around it?
- Does the code handle the case of domain-specific language tasks correctly?
- Could we start with a small, clean dataset and a held-out test set?
- Would a test catch forgetting general abilities if it appeared later?
- Have we considered overfitting on small datasets?
- Have we avoided this problem: low-quality training data?

Good reviews of work on Fine-Tuning Models are specific, kind and focused on the learning rate, not on personal style.
