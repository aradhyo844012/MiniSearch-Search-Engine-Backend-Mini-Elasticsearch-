React Native for Students: A Study Guide

This study guide prepares you for exams, labs and interviews that cover React Native.

Learning goals:
1. Explain React Native in your own words.
2. Describe components, native modules, styling with flexbox, and navigation.
3. Give examples from cross-platform apps and rapid prototypes.
4. Name three problems to watch for.

Start with the definition: React Native is a framework for building mobile apps for several platforms using JavaScript and React. Then draw one script performed by actors on two different stages on paper and label the four terms from the goals above.

Self-test questions: Why is heavy re-renders a problem? How does native modules relate to styling with flexbox? When would you choose Expo or Metro?

Study habit worth keeping: test on real devices for both platforms.

When you feel ready, compare React Native with Arduino Basics and write down three differences.
