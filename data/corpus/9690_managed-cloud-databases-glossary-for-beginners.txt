Managed Cloud Databases Glossary for Beginners

New words can make Managed Cloud Databases feel harder than it is. This glossary keeps the key ones in one place.

Managed Cloud Databases: database services where the cloud provider handles backups, patching and failover.
automated backups: a core term, most visible in launching apps quickly.
read replicas: a core term that beginners often confuse with maintenance windows.
maintenance windows: a core term that connects to scaling options.
scaling options: a core term worth revisiting after you try a real example.
Amazon RDS: a tool commonly used for reducing database administration.

Come back to this Managed Cloud Databases list whenever documentation for Cloud SQL uses a word you do not recognize.
