A Mini Project Idea Using CPU Caches

A small project is the fastest way to make CPU Caches stick. This one takes a weekend and needs only a laptop.

The goal is to build a tiny program or demo that shows CPU Caches at work on speeding up loops. Keep the scope small enough to finish.

Milestones:
1. Read about cache lines and hit and miss rates.
2. Set up perf and run a hello-world example.
3. Add the core feature.
4. Handle one failure case, such as false sharing.
5. Write a short README explaining what you learned.

Stretch goals: extend the demo to cover explaining performance differences, or compare Valgrind cachegrind with Intel VTune.

Finish by recording what surprised you. Writing it down is how knowledge about CPU Caches turns into something you can show others.
